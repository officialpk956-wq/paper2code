# Neural Networks from First Principles

<Callout type="tip" title="Key Insight">
Neural networks are function approximators. Given enough neurons and the right training, they can learn to approximate *any* continuous function. That single fact explains why they work on images, text, audio, and almost everything else.
</Callout>

## What Is a Neuron?

Biologically, a neuron fires when its inputs exceed some threshold. Computationally, we model this very simply:

**output = activation(w · x + b)**

Where `w` are weights (how much each input matters), `x` is the input vector, `b` is a bias (how easy it is to fire), and `activation` is a non-linear function like ReLU or sigmoid.

<Callout type="info" title="What Each Term Means">
- **w** (weights) — learned parameters that scale each input feature
- **x** (inputs) — the data fed into this neuron
- **b** (bias) — a learned offset; lets the neuron fire even when all inputs are zero
- **activation** — introduces non-linearity; without it, stacking neurons is pointless
</Callout>

## From One Neuron to a Network

A single neuron can only draw one linear decision boundary. Stack them in layers and suddenly you can carve up any shape in input space.

<SVGDiagram src="/diagrams/neural-network-layers.svg" caption="3-layer network: input (3 nodes) → hidden (4 nodes) → output (2 nodes)" />

Each layer applies a linear transformation followed by an activation function:

```python
import numpy as np

def layer_forward(x, W, b, activation='relu'):
    z = x @ W + b          # linear: (batch, in) @ (in, out) = (batch, out)
    if activation == 'relu':
        return np.maximum(0, z)
    return 1 / (1 + np.exp(-z))   # sigmoid
```

## The Forward Pass

When you run an input through the network to get a prediction, that's the **forward pass**:

1. Feed input `x` into the first layer
2. Each layer computes `z = Wx + b`, then applies activation
3. The output layer produces the final prediction (logit or probability)
4. No weights change during a forward pass — this is pure inference

## Loss — How Wrong Are We?

Training requires a way to measure error. For classification, cross-entropy loss:

$$L = -\sum_{c} y_c \log(\hat{y}_c)$$

For regression, mean squared error:

$$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

## Backpropagation

Once we have a loss, we need to update weights to reduce it. Backpropagation applies the **chain rule** from calculus to propagate error gradients backward through every layer.

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z_2} \cdot \frac{\partial z_2}{\partial a_1} \cdot \frac{\partial a_1}{\partial z_1} \cdot \frac{\partial z_1}{\partial W_1}$$

Each term is local — each layer only needs to know the gradient flowing in from the next layer.

<Callout type="warning" title="Vanishing Gradients">
In very deep networks, gradients shrink exponentially as they flow backward. By layer 1, the gradient is near zero and weights barely update. This is why ReLU replaced sigmoid for hidden layers — its gradient is either 0 or 1, it doesn't shrink.
</Callout>

## Why It Actually Works

The **Universal Approximation Theorem** (Cybenko, 1989) proves that a single hidden layer with enough neurons can approximate any continuous function to arbitrary precision.

In practice:
- **Depth beats width** — deep networks learn hierarchical representations more efficiently than shallow wide ones
- **Regularization is essential** — dropout, weight decay, and batch norm prevent memorization
- **Initialization matters** — Xavier/He initialization keeps activations from exploding or vanishing at the start
