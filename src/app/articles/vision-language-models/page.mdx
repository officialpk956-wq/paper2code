# Vision-Language Models: CLIP, DALL-E, and GPT-4V

<Callout type="tip" title="Key Insight">
All modern vision-language AI traces to one idea: train an image encoder and a text encoder to produce compatible representations by matching images to their captions. CLIP (2021) did this at scale. Once you have a shared embedding space, you can generate images from text, answer questions about images, search by description, and build models that understand both modalities. The shared embedding space is the foundation everything else builds on.
</Callout>

## CLIP: The Foundation

**CLIP (Contrastive Language-Image Pre-training, Radford et al., 2021)** trained two encoders — a Vision Transformer for images and a text Transformer for captions — on 400 million image-caption pairs collected from the internet.

The training objective is **contrastive**: for a batch of N image-text pairs, maximize the cosine similarity of the N correct pairs while minimizing similarity of the N²−N incorrect pairings:

$$\mathcal{L} = -\frac{1}{N}\sum_i \log \frac{\exp(\text{sim}(v_i, t_i)/\tau)}{\sum_j \exp(\text{sim}(v_i, t_j)/\tau)}$$

Where $v_i$ and $t_i$ are the image and text embeddings, and $\tau$ is a learned temperature. The model learns to map images and their descriptions to nearby points in a shared 512-dimensional embedding space.

The result: a rich semantic space where "a photo of a dog" is close to images of dogs, "a dog sitting on grass" is close to outdoor dog photos but farther from indoor ones, and the direction "dog → cat" in text space has a similar geometric relationship to the corresponding image direction.

## Zero-Shot Classification with CLIP

CLIP's most immediately useful capability: **zero-shot image classification** without any task-specific training. For each class, create a text prompt: "a photo of a {class}." Encode all class prompts and the query image. Assign the image to the class whose text embedding is most similar.

On ImageNet with zero examples per class, CLIP matches the accuracy of a supervised ResNet-50 trained on 1.2 million labeled images. On more unusual datasets (satellite imagery, medical X-rays, pathology slides), CLIP transfers better than supervised models because natural language descriptions capture concepts that labeled training sets may never contain.

The prompting matters: "a photo of a {class}" consistently outperforms just "{class}" — the phrase anchors the embedding in the visual domain rather than the abstract conceptual domain.

## DALL-E and Stable Diffusion: Generating from CLIP

CLIP's text encoder became the natural conditioning signal for text-to-image generation.

**DALL-E 2 (OpenAI, 2022)** uses CLIP in two stages: a **prior** model maps CLIP text embeddings to CLIP image embeddings (learning the distribution of images consistent with a given text), followed by a **DDPM decoder** that generates a pixel image from the CLIP image embedding. The prior bridges the text-to-image gap; the decoder handles high-quality pixel generation.

**Stable Diffusion (Rombach et al., 2022)** takes a simpler path: use the CLIP text encoder directly as cross-attention conditioning for a Latent Diffusion Model. No prior needed — the U-Net's cross-attention layers attend to CLIP text token embeddings at every denoising step. Each spatial position in the image can attend to relevant text tokens, producing strong alignment between prompt and output.

**Prompt engineering** exploits the CLIP embedding geometry. Negative prompts ("blurry, low quality, watermark") move the generation away from specific regions. Style suffixes ("in the style of Monet, impressionist, oil painting") move toward artistic stylistic regions. Combination prompts ("a corgi wearing a top hat, photorealistic, 8K") compose concept embeddings.

<Callout type="info" title="Why CLIP Embeddings Are So Useful">
CLIP training on 400M image-caption pairs exposes the model to essentially every visual concept described in text on the internet. The resulting embeddings are not just visual features — they are semantic features that align with how humans describe images. This alignment is what makes them useful for downstream tasks: an image embedding close to "red" truly means something about redness, not just a particular pattern of pixels.
</Callout>

## LLaVA: Connecting CLIP to Language Models

The key question for visual question answering: how do you let a language model "see" an image?

**LLaVA (Liu et al., 2023)** uses the simplest possible approach: encode the image with CLIP's ViT encoder, project the resulting patch embeddings into the LLM's token embedding space with a learned linear layer, and prepend these "visual tokens" to the text tokens before passing everything to the LLM decoder.

Training is two-stage: (1) train only the projection layer with image-caption pairs (the LLM and CLIP stay frozen), then (2) fine-tune the projection layer + LLM on instruction-following visual QA data. The LLM (Vicuna 13B in the original) learns to interpret visual tokens just like text tokens.

LLaVA-1.5 and LLaVA-NeXT improved by: higher-resolution images (448×448 instead of 224×224), replacing the linear projection with a 2-layer MLP, and mixing visual instruction data with standard language tasks to avoid catastrophic forgetting. LLaVA-NeXT matches GPT-4V on several benchmarks.

**InstructBLIP** interjects a **Q-Former** (querying transformer) between the CLIP encoder and the LLM — a Transformer with a fixed set of learnable query tokens that attend to CLIP features and extract a fixed number of "visual tokens" regardless of image resolution. This makes the interface between vision and language more compact.

## SAM: Segment Anything with Prompts

**SAM (Segment Anything Model, Kirillov et al., Meta AI, 2023)** addresses a different vision-language problem: interactive image segmentation.

SAM consists of three components:
1. **Image encoder** — a heavyweight ViT-H (632M parameters) run once per image, producing a feature embedding
2. **Prompt encoder** — encodes prompts: points (foreground/background clicks), bounding boxes, or free-form masks
3. **Mask decoder** — a lightweight Transformer that attends to the image embedding and prompt embedding to produce 3 candidate masks (small/medium/large) with confidence scores

SAM was trained on 1 billion masks from 11 million images using a three-stage pipeline that progressively iterated between manual annotation and model-assisted labeling.

The key property: **prompt composability**. Click a point → get the object under the point segmented. Click another point → refine. Draw a box → get everything inside segmented. Text prompting is possible via CLIP integration (SAM + CLIP = segment what matches a text description).

## GPT-4V and Native Multimodality

**LLaVA and similar models** are fundamentally LLMs with bolted-on vision via a projection layer. The image encoder and language model were pretrained separately.

**GPT-4V (2023), Gemini 1.5 (2024), GPT-4o (2024)** take a different approach: train a single model on interleaved sequences of images and text from the start. The model processes image patches and text tokens through the same Transformer, with no separation between "vision" and "language" — they are one modality.

This enables capabilities that projection-based models struggle with:
- **Spatial reasoning**: counting objects, understanding relative positions, comparing diagrams
- **Interleaved understanding**: "In the first image, X happens; in the second image, Y happens; how do they relate?"
- **Chart and document reading**: structured visual data that requires understanding layout, not just semantics
- **Fine-grained detail**: reading text in images, identifying specific UI elements, reading code from a screenshot

GPT-4o extends this to audio — the same architecture accepts audio, image, and text tokens, producing outputs in any modality.

## Practice

<Callout type="info">
The most educational vision-language experiment: use the `transformers` library to load CLIP, embed 10 images and 10 text descriptions, compute the 10×10 similarity matrix, and visualize it as a heatmap. You should see a strong diagonal (correct image-text pairs) and interesting off-diagonal structure (semantically similar pairs score higher). This matrix is exactly what CLIP's training loss optimizes.
</Callout>
