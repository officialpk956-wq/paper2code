# Self-Supervised Learning: SimCLR, BYOL, and Masked Autoencoders

<Callout type="tip" title="Key Insight">
BERT, GPT, and every modern foundation model are self-supervised learners. The insight: you don't need human labels to learn good representations. Instead, create a pretext task from the data itself — predict masked tokens (BERT), predict next tokens (GPT), predict which augmentation produced an image (SimCLR). Models trained to solve these pretext tasks develop rich internal representations that transfer to downstream tasks. SSL has made labeled data largely optional for pretraining.
</Callout>

## The Representation Learning Problem

Before self-supervised learning, training a visual model required labeled data. ImageNet has 1.2 million labeled images — a massive human labeling effort. But the internet has billions of unlabeled images. How do you exploit them?

The key insight: **labels are a proxy for structure**. A "cat" label teaches the model that certain visual patterns belong together. But the same information could be derived from the data itself: the same object photographed from different angles should have similar representations. A model forced to maintain this invariance learns to represent semantic content, not just pixel patterns.

Self-supervised learning creates artificial supervision from unlabeled data by defining a **pretext task** — a task with automatic labels derived from the data structure. Good pretext tasks force the model to learn semantically meaningful representations as a byproduct.

## Contrastive Learning: SimCLR

**SimCLR (Chen et al., Google, 2020)** is the clearest formulation of contrastive self-supervised learning:

1. **Augment** each image twice with random crops, color jitter, Gaussian blur, and grayscale. Each augmentation is a "view" of the same image.
2. **Encode** both views with the same encoder $f(\cdot)$ (ResNet-50 by default), producing embeddings $h_i, h_j$.
3. **Project** to a lower-dimensional space: $z_i = g(h_i)$ where $g$ is a 2-layer MLP.
4. **Minimize NT-Xent loss** (normalized temperature-scaled cross-entropy): for a batch of $N$ images (producing $2N$ augmented views), maximize agreement between the two views of the same image while pushing away all $2(N-1)$ views from different images.

$$\ell_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k=1}^{2N} \mathbf{1}_{k \neq i} \exp(\text{sim}(z_i, z_k)/\tau)}$$

**Critical finding**: large batch sizes dramatically improve SimCLR. With 4096 images per batch, the model sees $2 \times 4095$ negative examples per positive pair — a rich signal. SimCLR requires 128 TPUs for 8 hours with batch size 4096.

SimCLR-v2 with ResNet-152 achieves 79.8% top-1 linear evaluation on ImageNet — better than many supervised models trained on the same data.

**The projection head is crucial but temporary**: after training, the projection head $g$ is discarded. Only the encoder $h$ is kept for downstream tasks. This was a surprising finding: the representation in $h$ is better than in $z$ for transfer, even though the loss is computed in $z$ space.

## MoCo: Memory Bank for Large Negatives

**MoCo (Momentum Contrast, He et al., Facebook, 2019)** solved the large-batch problem differently. Instead of a large batch, maintain a **queue** (memory bank) of encoded representations from recent mini-batches:

- **Online encoder** $f_q$: updated by gradient descent
- **Momentum encoder** $f_k$: updated as exponential moving average (EMA) of $f_q$: $\theta_k \leftarrow m \theta_k + (1-m) \theta_q$

Query $q$ is encoded with $f_q$; keys $k$ are encoded with $f_k$ and pushed to the queue. Contrastive loss pulls $q$ toward the matching key and away from all keys in the queue (65,536 negatives in MoCo v1).

The EMA momentum encoder ensures queue keys are consistent — they come from slightly different parameter snapshots but all from the same stable encoder, not a wildly varying online encoder.

MoCo-v3 combined the momentum encoder with ViT backbones and achieved 83.2% linear evaluation on ImageNet.

## BYOL: No Negatives Required

A troubling theoretical question: contrastive methods need negatives to prevent collapse (if the encoder outputs the same vector for everything, the contrastive loss is 0 but the representation is useless). **BYOL (Bootstrap Your Own Latent, Grill et al., DeepMind, 2020)** showed negatives aren't actually necessary.

BYOL trains two networks:
- **Online network** $\theta$: encoder + projector + predictor MLP
- **Target network** $\xi$: encoder + projector (no predictor), updated as EMA of online: $\xi \leftarrow \tau \xi + (1-\tau) \theta$

Loss: minimize the MSE between the online network's prediction and the target network's projection of the other view. No negative samples.

$$\mathcal{L} = \left\|\bar{q}_\theta(z_\theta^{(1)}) - z_\xi^{(2)}\right\|^2_2$$

Why doesn't it collapse? The EMA creates a small lag between online and target networks. The predictor MLP is applied only to the online path, creating asymmetry. Together, these prevent the trivial constant solution — the online network must produce moving targets rather than a fixed point.

## MAE: Masked Autoencoders for Vision

**MAE (Masked Autoencoders, He et al., Meta, 2021)** brought the masking approach of BERT to vision. The setup:

1. Divide a 224×224 image into 16×16 patches (196 patches total)
2. Randomly mask 75% of patches — remove them from the input entirely
3. **Encoder** (ViT-L/16): process only the 25% visible patches
4. **Decoder** (lightweight Transformer): take encoder outputs + learned mask tokens, reconstruct pixel values for all 196 patches
5. Loss: MSE on masked patches only

The 75% masking ratio is much higher than BERT's 15% — this was a key insight. For images, a high masking ratio creates a challenging task (predict large missing regions) that forces semantic understanding. Low masking ratios can be solved by simple interpolation.

The encoder processes only 25% of patches — 4× fewer than a standard ViT — making MAE pretraining 3× faster than previous SSL methods at equivalent quality.

After pretraining, the lightweight decoder is discarded. Fine-tuning the encoder on labeled ImageNet data achieves 87.8% top-1 accuracy — better than supervised ViT-L trained from scratch (86.6%).

<Callout type="info" title="Why Augmentation Defines What SSL Learns">
SSL learns what the pretext task makes invariant. SimCLR crops, flips, and color-jitters — so it learns representations invariant to crop position, orientation, and color. This makes it great for object classification but poor for tasks where position and color matter (depth estimation, medical imaging). MAE learns to predict local texture from context — it learns spatial structure. BERT learns to predict word meaning from context — it learns semantic relationships. The pretext task is the implicit objective function.
</Callout>

## Foundation Models: SSL at Scale

Every major foundation model is built on SSL pretraining:

**Language**: GPT and its successors use next-token prediction (a variant of SSL where the future tokens provide the supervision). BERT uses masked token prediction. Both are SSL tasks — no human labels needed for pretraining.

**Vision**: CLIP uses contrastive learning between images and text captions (alt-text from the web provides free supervision). DINOv2 (Meta, 2023) combined BYOL, SwAV, and iBOT objectives to produce visual features that match CLIP's versatility without requiring paired text.

**Biology**: ESM (Evolutionary Scale Modeling, Meta, 2023) pretrained on 250 million protein sequences using masked language modeling, learning protein structure representations without any labeled structural data. ESM-2 can predict protein structures competitive with AlphaFold from sequence alone.

The pattern is consistent: large unlabeled datasets + SSL pretext task → rich representations → efficient fine-tuning on labeled downstream tasks. The bottleneck shifted from labeled data to compute.

## Practice

<Callout type="info">
Implement a minimal SimCLR in PyTorch: define two random augmentation pipelines (crop + jitter + blur), pass both views through a ResNet-18 encoder + 2-layer MLP projector, compute the NT-Xent loss with a temperature of 0.5. Train on STL-10 (unlabeled split) for 100 epochs. Then freeze the encoder and train a linear classifier on the labeled split. Compare to a randomly initialized ResNet-18 with linear probing — the SSL encoder should outperform random features by 20+ percentage points.
