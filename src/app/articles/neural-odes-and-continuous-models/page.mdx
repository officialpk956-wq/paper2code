# Neural ODEs and Continuous Models

<Callout type="tip" title="Key Insight">
Traditional neural networks are discrete—they process data layer by layer in a rigid sequence. Neural ODEs treat the network as a continuous dynamical system, modeling how the hidden state evolves over time using differential equations.
</Callout>

## The Connection to ResNets

To understand a Neural ODE, you must look at a standard Residual Network (ResNet). 

A ResNet updates its hidden state $h$ at layer $t$ using a skip connection:
$h_{t+1} = h_t + f(h_t, \theta_t)$

Mathematicians realized this equation is exactly the Euler method for solving an Ordinary Differential Equation (ODE). If you make the steps between layers infinitely small, the discrete layers disappear, replaced by a continuous differential equation:
$\frac{dh(t)}{dt} = f(h(t), t, \theta)$

Instead of specifying the number of layers (e.g., ResNet-50), a Neural ODE defines the *derivative* of the hidden state. To find the output, you simply pass the initial input into a black-box ODE Solver (like the Runge-Kutta method).

## The Adjoint Method (Backpropagation)

The biggest challenge with Neural ODEs was training them. If you run an ODE solver forward, keeping track of every intermediate calculation to perform standard backpropagation requires massive amounts of memory.

The breakthrough in 2018 (which won Best Paper at NeurIPS) was applying the **Adjoint Sensitivity Method**. Instead of tracing the forward pass, you can compute the gradients by running a *second, separate ODE solver backward in time*. This means a Neural ODE uses exactly $O(1)$ constant memory during training, regardless of how complex the solver's path is.

## Continuous Normalizing Flows

Because Neural ODEs define a continuous transformation of space, they are incredibly powerful for generative models, specifically **Continuous Normalizing Flows (CNFs)**.

In discrete Normalizing Flows, you must carefully design layers that are mathematically invertible (which is highly restrictive). With a CNF, you can use almost any standard neural network architecture to define the ODE. By simply running the ODE solver backward, the process is guaranteed to be perfectly invertible. 

## Applications in Time Series

Most real-world data (like patient health records in a hospital) is not sampled at rigid, discrete intervals. A patient might have a blood test at 9:00 AM, a heart rate check at 9:14 AM, and nothing else for three days.

Standard Recurrent Neural Networks (RNNs) struggle with irregularly sampled data. **Latent ODEs** solve this beautifully. The hidden state of the network evolves continuously in time according to the ODE. When a new data point arrives at an arbitrary time $t$, the solver simply integrates up to that exact moment to update the state.
