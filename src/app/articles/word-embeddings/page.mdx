# Word Embeddings: Word2Vec, GloVe, FastText, and Contextual Representations

<Callout type="tip" title="Key Insight">
Neural networks require numeric inputs. Words are discrete symbols. The bridge is an embedding: a learned function that maps each word to a dense vector of real numbers. The key insight is that you can learn these vectors from unlabeled text using a prediction task — predict missing words — and the learned vectors will encode semantic meaning as a side effect. "king" and "queen" end up near each other in vector space. "Paris" and "France" have the same relationship as "Berlin" and "Germany". This structure emerges from learning to predict language, not from any explicit definition of meaning.
</Callout>

## The Embedding Idea

Before Word2Vec (2013), words were encoded as one-hot vectors: a vector of zeros with a single 1 at the word's index in the vocabulary. A vocabulary of 100,000 words required 100,000-dimensional vectors. These vectors encode no information about meaning — "cat" is no more similar to "kitten" than to "automobile".

Distributed representations (embeddings) solve both problems. Each word is mapped to a dense vector of 100–300 dimensions. Semantically related words have similar vectors. The embedding matrix $W \in \mathbb{R}^{|V| \times d}$ contains one row per word; looking up a word's embedding is just selecting that row (an efficient matrix multiply with a one-hot vector).

The question is how to learn $W$ without labeled data about meaning. The answer: define a prediction task on text, and let the embeddings emerge as the parameters that make the task easy.

## Word2Vec: Predict the Context

**Word2Vec (Mikolov et al., Google, 2013)** defines two prediction tasks on a sliding window over text:

**CBOW (Continuous Bag of Words)**: given the surrounding context words, predict the center word. If the window is "the ___ quick brown fox" with k=2, the model sees ["the", "quick"] and must predict "brown" (the center word). The model averages the context word embeddings and predicts the target via a softmax over the vocabulary.

**Skip-gram**: reverse direction — given the center word, predict each surrounding context word. Given "brown", predict "the", "quick", "fox", "jumps". Skip-gram treats each (center, context) pair as a separate training example.

**Why this learns meaning**: words that appear in similar contexts will have similar embeddings, because the model must predict the same set of context words for them. "cat" and "dog" both appear near "the", "is", "my", "a", "running" — so their embeddings converge to similar regions of the space. This is the distributional hypothesis: words with similar distributions have similar meanings.

**Negative sampling**: computing softmax over 100K words is slow. Word2Vec approximates it by training a binary classifier: is this (word, context) pair real, or a randomly sampled "negative" pair? For each real pair, sample 5–20 random words. Optimize logistic loss. The model must assign high probability to real pairs and low probability to noise pairs — which pushes embeddings toward semantic coherence.

## Vector Arithmetic: The Famous Property

The most surprising property of trained word embeddings:

$$\text{king} - \text{man} + \text{woman} \approx \text{queen}$$

More examples:
- Paris − France + Germany ≈ Berlin (capital-country relationship)
- walked − walk + swim ≈ swam (verb tense)
- bigger − big + cold ≈ colder (comparative adjective)

This linear structure emerges without supervision about relationships. The analogy works because the embedding encodes the relationship as a direction in vector space — the "capital city" direction, the "plural" direction, the "past tense" direction. These directions are consistent across word pairs with the same relationship.

The precision of analogy arithmetic is limited — the nearest neighbor is not always exact. But the structure is real and useful: it enables transfer learning (train embeddings on a large corpus, use them in any NLP task), and it reveals that language structure is encoded geometrically.

## GloVe: Global Co-occurrence

**GloVe (Pennington, Socher, Manning, Stanford, 2014)** takes a different approach. Instead of a local prediction task on a sliding window, GloVe fits a log-bilinear model to the entire global co-occurrence matrix:

$$X_{ij} = \text{number of times word } j \text{ appears in the context of word } i$$

The model learns word vectors $w_i$ and context vectors $\tilde{w}_j$ such that:

$$w_i^\top \tilde{w}_j + b_i + \tilde{b}_j \approx \log X_{ij}$$

The loss is:

$$J = \sum_{i,j} f(X_{ij}) (w_i^\top \tilde{w}_j + b_i + \tilde{b}_j - \log X_{ij})^2$$

where $f(X_{ij})$ is a weighting function that reduces the contribution of very frequent pairs (the, a, is appear everywhere — their co-occurrence statistics are noisy signals about meaning).

GloVe's advantage: by using global statistics rather than local windows, it captures long-range co-occurrence patterns that sliding window methods miss. In practice, GloVe and Word2Vec perform similarly on word analogy tasks. GloVe is faster to train (one pass over the co-occurrence matrix vs many passes over the corpus).

Pre-trained GloVe vectors are available at 50, 100, 200, and 300 dimensions, trained on 840 billion tokens from Common Crawl.

## FastText: Character N-grams

**FastText (Bojanowski et al., Facebook, 2017)** extends Word2Vec with character n-gram subword representations.

Instead of learning one vector per word, FastText represents each word as the sum of vectors for all its character n-grams (n=3 to 6):

```
"eating" → <ea, eat, ati, tin, ing, ng>, <eat, atin, ting, ing>, ...
           (3-grams)                     (4-grams)
```

Each n-gram has its own embedding. The word "eating" is represented as the sum of all its n-gram embeddings. The word-level embedding is then used exactly as in skip-gram.

**Key advantages**:

1. **Out-of-vocabulary words**: if "tokenization" is not in the training vocabulary, FastText can still embed it by summing the embeddings of its n-grams (which appeared in other words). Word2Vec and GloVe must return a random or zero vector for OOV words.

2. **Morphologically rich languages**: in German, Turkish, Finnish, and Arabic, a single root spawns many word forms. FastText shares representations across "run", "running", "runner", "ran" via the shared substrings — capturing morphological relationships that word-level models treat as entirely separate words.

3. **Misspellings**: "tomato" and "tomatto" share most n-grams and will have similar vectors.

FastText is particularly valuable for low-resource languages and domain-specific text with many rare technical terms.

## Contextual Embeddings: One Vector Per Occurrence

A fundamental limitation of Word2Vec, GloVe, and FastText: each word has one fixed vector regardless of context. "bank" has the same embedding in "the river bank" and "the bank account". The model can't resolve polysemy (multiple meanings).

**ELMo (Peters et al., AllenNLP, 2018)**: train a bidirectional LSTM language model on a large corpus. Each word's representation is a learned combination of the hidden states from all LSTM layers (2 layers + embedding layer). Different combinations suit different tasks: the lower layers capture syntax, upper layers capture semantics. ELMo was a major breakthrough — adding ELMo embeddings to task-specific models improved state-of-the-art across 6 NLP benchmarks.

**BERT (Devlin et al., Google, 2018)**: a Transformer encoder trained with masked language modeling on 3.3B tokens. Each word's representation is computed by attending to the entire context simultaneously. The "bank" vector in "river bank" context is entirely different from "bank account" context — the Transformer attention allows each token to incorporate context from the full sentence.

The shift from static to contextual embeddings is analogous to the shift from looking up a word in a dictionary (one meaning) to understanding it from how it's used in a sentence. Modern NLP uses contextual embeddings exclusively.
