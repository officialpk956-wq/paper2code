# The Softmax Function

Softmax converts a vector of arbitrary real scores into a probability distribution. It appears twice in every Transformer: inside attention (normalizing scores) and at the output (next-token probabilities).

## Definition

$$
\sigma(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}
$$

Properties:

- Every output is in $(0, 1)$ and the outputs sum to $1$.
- Order-preserving: larger scores get larger probabilities.
- **Exponential amplification**: a score 2 points higher gets $e^2 \approx 7.4\times$ the probability.

## Numerical Stability

$e^{1000}$ overflows. Subtracting the max first changes nothing mathematically (softmax is shift-invariant) but keeps exponents safe:

```python
import numpy as np

def softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)  # shift-invariance trick
    e = np.exp(z)
    return e / e.sum(axis=axis, keepdims=True)
```

:::warning
Every production framework applies the max-subtraction trick. If you implement softmax naively in an interview, expect to be asked about overflow.
:::

## Temperature

Dividing scores by a temperature $T$ controls the sharpness of the distribution:

$$
\sigma(z/T)_i = \frac{e^{z_i/T}}{\sum_j e^{z_j/T}}
$$

- $T \to 0$: approaches argmax (greedy, deterministic)
- $T = 1$: standard softmax
- $T \to \infty$: approaches uniform (random)

This is exactly the `temperature` parameter in LLM APIs.

## In Attention

The $\sqrt{d_k}$ scaling in attention exists *because of* softmax: dot products grow with dimension, and large inputs push softmax into saturated regions where gradients vanish:

$$
\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)
$$
