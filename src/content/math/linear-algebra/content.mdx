# Linear Algebra Foundations

Every forward pass of every neural network is a chain of matrix multiplications and element-wise nonlinearities. This topic covers the minimum linear algebra you need to read and implement modern architectures.

## Vectors as Representations

In deep learning, a vector $x \in \mathbb{R}^d$ *is* the representation — a word embedding, an image patch, a hidden state. Two operations matter constantly:

**Dot product** — measures alignment, the basis of attention scores:

$$
x \cdot y = \sum_{i=1}^{d} x_i y_i = \|x\| \|y\| \cos\theta
$$

**Norm** — measures magnitude, the basis of normalization layers:

$$
\|x\|_2 = \sqrt{\sum_i x_i^2}
$$

## Matrix Multiplication

The single most executed operation in AI:

$$
C_{ij} = \sum_{k} A_{ik} B_{kj}
$$

A linear layer `y = W @ x + b` transforms a $d_{in}$-vector into a $d_{out}$-vector. Shapes are your best debugging tool:

```python
import numpy as np

X = np.random.randn(32, 512)    # batch of 32 tokens, dim 512
W = np.random.randn(512, 2048)  # weight: d_in=512 → d_out=2048
Y = X @ W                       # (32, 2048)
```

:::warning
The #1 beginner bug is shape mismatch. Before writing any layer, write the expected shapes as comments — `(batch, seq, d_model)` — and assert them.
:::

## Where This Appears in the Transformer

| Operation | Linear algebra |
| --- | --- |
| Q, K, V projections | Matrix multiply |
| Attention scores $QK^T$ | Matrix multiply + dot products |
| Attention output | Weighted sum (matrix multiply) |
| LayerNorm | Vector norm + scaling |
