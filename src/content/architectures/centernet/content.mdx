# CenterNet

## 1. Overview
CenterNet (Objects as Points), introduced in 2019 by Xingyi Zhou, Dequan Wang, and Philipp Krähenbühl from UT Austin, simplified object detection to its absolute fundamental limit. While earlier keypoint-based detectors (like CornerNet) detected multiple corners and required computationally expensive pairing algorithms (associative embeddings), CenterNet models an object as a **single point**—the center point of its bounding box. CenterNet uses a fully convolutional network (such as DLA-34 or Hourglass-104) to predict a keypoint heatmap of object centers. At each detected center point, CenterNet directly regresses the object's width, height, and sub-pixel discretization offset. Because every object has exactly one center point, CenterNet **completely eliminates anchor boxes, keypoint pairing, and Non-Maximum Suppression (NMS) post-processing**, running at 1.4 ms per image (142 FPS for ResNet-18) while achieving competitive accuracy on MS COCO.

:::tip
CenterNet's core principle: "Represent objects as single center points on a keypoint heatmap, and regress box width and height directly at the center location. One object = One center point. Zero anchors, zero pairing, zero NMS."
:::

## 2. Historical Context
In 2019, keypoint-based detection had emerged as a promising alternative to anchor boxes:
- **CornerNet (2018):** Detected top-left and bottom-right corners, but required complex 1D associative embedding vectors to pair corners. In dense scenes, corner pairing often failed, creating false positive boxes across separate objects.
- **ExtremeNet (2019):** Detected 5 keypoints per object (top, bottom, left, right, center), requiring expensive geometric grouping.

Xingyi Zhou et al. realized that keypoint pairing was an artificial problem introduced by detecting boundaries. By shifting the target to the **Center Point**, every object map contains a single unique center. From this single center point, standard 2D convolutions can directly regress width $w$ and height $h$. This simple formulation unified object detection, 3D bounding box estimation, and human pose keypoint estimation under a single point-based framework.

## 3. Problem It Solves
### Why Removing Anchors Simplifies the Object Detection Pipeline
CenterNet represents the ultimate simplification of single-stage object detection:
1. **Eliminating Keypoint Pairing & Associative Embeddings:** Unlike CornerNet (which requires $O(N^2)$ distance matching between corner embeddings), CenterNet detects a single center point per object, eliminating pairing algorithms completely.
2. **Eliminating Non-Maximum Suppression (NMS):** Traditional anchor-based detectors output multiple overlapping boxes for a single object, requiring NMS filtering. CenterNet extracts local peak maxima on the keypoint heatmap using a simple $3 \times 3$ max-pooling operation (`MaxPool2d(3, stride=1)`), replacing non-differentiable NMS with a fast 1-line PyTorch tensor comparison.
3. **Removing Anchor Hyperparameters:** Zero anchor box scales, zero aspect ratios, zero IoU assignment thresholds.

## 5. Layer-by-Layer Breakdown
CenterNet consists of a high-resolution feature extractor and 3 parallel 1x1 conv prediction heads:

**1. High-Resolution Backbone (DLA-34 / Hourglass / ResNet-18):**
- Extracts a high-resolution feature map at $1/4$ scale: $C \times H/4 \times W/4$ (e.g., $64 \times 128 \times 128$ for a $512 \times 512$ image).
- Uses deformable convolutions in upsampling layers (DLA-34) to expand the receptive field.

**2. Keypoint Center Heatmap Head ($\hat{Y}$):**
- A $3 \times 3$ Conv (256 filters, ReLU) followed by a $1 \times 1$ Conv to $C$ channels (where $C$ is the number of classes).
- Applies Sigmoid activation to output probability maps $\hat{Y} \in (0, 1)^{C \times H/4 \times W/4}$.

**3. Width and Height Regression Head ($\hat{S}$):**
- A $3 \times 3$ Conv (256 filters, ReLU) followed by a $1 \times 1$ Conv to 2 channels.
- Predicts bounding box size $\hat{S}_{x,y} = (\hat{w}, \hat{h})$ directly at center point $(x, y)$.

**4. Sub-Pixel Offset Head ($\hat{O}$):**
- A $3 \times 3$ Conv (256 filters, ReLU) followed by a $1 \times 1$ Conv to 2 channels.
- Predicts discretization offset $\hat{O}_{x,y} = (\Delta x, \Delta y) = (\frac{p_x}{4} - \lfloor \frac{p_x}{4} \rfloor, \frac{p_y}{4} - \lfloor \frac{p_y}{4} \rfloor)$ to fix $1/4$-scale downsampling coordinate rounding.

## 6. Tensor Flow Walkthrough
Let's trace tensors for input `(B, 3, 512, 512)` and $C=80$ COCO classes.

1. **Backbone Feature Map:**
   - DLA-34 Output: `(B, 64, 128, 128)`
2. **Head Predictions:**
   - **Center Heatmap:** Conv3x3(64 $\rightarrow 256$) $\rightarrow$ Conv1x1(256 $\rightarrow 80$) $\rightarrow$ Sigmoid $\rightarrow$ `(B, 80, 128, 128)`
   - **Width & Height:** Conv3x3(64 $\rightarrow 256$) $\rightarrow$ Conv1x1(256 $\rightarrow 2$) $\rightarrow$ `(B, 2, 128, 128)`
   - **Sub-Pixel Offsets:** Conv3x3(64 $\rightarrow 256$) $\rightarrow$ Conv1x1(256 $\rightarrow 2$) $\rightarrow$ `(B, 2, 128, 128)`
3. **NMS-Free Peak Extraction (Inference):**
   - MaxPool2d(3x3, stride=1, padding=1) on Heatmap `(B, 80, 128, 128)`.
   - Keep pixels where `Heatmap == MaxPool(Heatmap)` $\rightarrow$ Filters non-peak neighbors!
   - Gather top 100 peaks $\rightarrow$ Read $(\hat{w}, \hat{h})$ from Size map and $(\Delta x, \Delta y)$ from Offset map at peak indices.

## 7. Mathematical Foundations

### 1. Keypoint Heatmap Penalty-Reduced Focal Loss
For each ground-truth center point $p \in \mathbb{R}^2$ of class $c$, its location on the downsampled $1/4$ grid is $\tilde{p} = \lfloor p / 4 \rfloor$.
Ground-truth targets are rendered using a 2D Gaussian kernel $Y_{cxy} = \exp\left(-\frac{(x - \tilde{p}_x)^2 + (y - \tilde{p}_y)^2}{2\sigma_p^2}\right)$.

The center keypoint loss is:

$$\mathcal{L}_k = -\frac{1}{N} \sum_{c=1}^C \sum_{x=1}^{H/4} \sum_{y=1}^{W/4} \begin{cases} (1 - \hat{Y}_{cxy})^\alpha \log(\hat{Y}_{cxy}) & \text{if } Y_{cxy} = 1 \\ (1 - Y_{cxy})^\beta (\hat{Y}_{cxy})^\alpha \log(1 - \hat{Y}_{cxy}) & \text{otherwise} \end{cases}$$

where $\alpha=2, \beta=4$.

### 2. Width/Height Size Loss & Offset Loss
For $N$ ground-truth center points $\{p_k\}_{k=1}^N$ with sizes $s_k = (w_k, h_k)$:

- **Size Regression Loss (L1):**
  $$\mathcal{L}_{\text{size}} = \frac{1}{N} \sum_{k=1}^N \left| \hat{S}_{\tilde{p}_k} - s_k \right|$$

- **Sub-Pixel Offset Loss (L1):**
  $$\mathcal{L}_{\text{off}} = \frac{1}{N} \sum_{k=1}^N \left| \hat{O}_{\tilde{p}_k} - \left( \frac{p_k}{4} - \tilde{p}_k \right) \right|$$

- **Total Objective:** $\mathcal{L}_{\text{total}} = \mathcal{L}_k + \lambda_{\text{size}} \mathcal{L}_{\text{size}} + \lambda_{\text{off}} \mathcal{L}_{\text{off}}$ where $\lambda_{\text{size}} = 0.1, \lambda_{\text{off}} = 1$.

## 8. Training Procedure
- **Optimizer:** Adam, learning rate $1.25 \times 10^{-4}$, dropped by $10\times$ at epoch 90 and 120. Trained for 140 epochs.
- **Data Augmentation:** Random flipping, random scaling (0.6 to 1.4), color jittering, random cropping.

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of **CenterNet NMS-Free Peak Extraction**.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def extract_centernet_peaks(heatmap, kernel=3):
    """
    Replaces NMS using a 3x3 MaxPool operation!
    heatmap: (B, C, H, W)
    """
    pad = (kernel - 1) // 2
    # Apply 3x3 MaxPool
    hmax = F.max_pool2d(heatmap, kernel_size=kernel, stride=1, padding=pad)
    # Keep only local maxima (peaks)
    keep = (heatmap == hmax).float()
    return heatmap * keep

class CenterNetHead(nn.Module):
    def __init__(self, in_channels=64, num_classes=80):
        super().__init__()
        # 1. Keypoint Heatmap Head
        self.heatmap_head = nn.Sequential(
            nn.Conv2d(in_channels, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(256, num_classes, kernel_size=1),
            nn.Sigmoid()
        )
        # 2. Width & Height Head
        self.wh_head = nn.Sequential(
            nn.Conv2d(in_channels, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(256, 2, kernel_size=1)
        )
        # 3. Sub-pixel Offset Head
        self.offset_head = nn.Sequential(
            nn.Conv2d(in_channels, 256, kernel_size=3, padding=1),
            nn.ReLU(inplace=True),
            nn.Conv2d(256, 2, kernel_size=1)
        )

    def forward(self, x):
        heatmap = self.heatmap_head(x) # (B, C, H/4, W/4)
        wh = self.wh_head(x)           # (B, 2, H/4, W/4)
        offset = self.offset_head(x)   # (B, 2, H/4, W/4)
        
        # Suppress non-peak features via MaxPool NMS
        peak_heatmap = extract_centernet_peaks(heatmap)
        return peak_heatmap, wh, offset

if __name__ == "__main__":
    B, C, H, W = 2, 64, 128, 128
    head = CenterNetHead(in_channels=C, num_classes=80)
    
    dummy_feat = torch.randn(B, C, H, W)
    peak_map, wh, offset = head(dummy_feat)
    
    print(f"Peak Heatmap Shape: {peak_map.shape}")
    print(f"Width/Height Shape: {wh.shape}")
    print(f"Offset Shape:       {offset.shape}")
    
    assert peak_map.shape == (B, 80, H, W)
    assert wh.shape == (B, 2, H, W)
    print("CenterNet NMS-Free Head verification successful!")
```

## 10. Strengths
- **Zero Anchor Boxes & Zero Pairing:** Eliminates anchor box hyperparameter tuning and keypoint pairing overhead completely.
- **NMS-Free Peak Extraction:** Replaces non-differentiable NMS post-processing with a fast $3 \times 3$ max-pooling operation.
- **Universal Multi-Task Framework:** Easily extends to 3D bounding box estimation and 17-keypoint human pose estimation by adding parallel regression heads.

## 11. Weaknesses
- **Single Center Per Grid Cell Constraint:** If two distinct objects share the exact same center pixel on the $1/4$-scale feature map, CenterNet can only detect one object.
- **High Resolution Memory Demand:** Operating at $1/4$ feature scale ($128 \times 128$) requires high VRAM during training.

## 12. Research Evolution
CenterNet established the "Objects as Points" paradigm. It directly influenced **FCOS**, **CenterNet2**, and anchor-free 3D perception networks in autonomous driving.

## 13. Interview Questions

**Q1: How does CenterNet replace Non-Maximum Suppression (NMS) during inference?**
**A1:** CenterNet applies a $3 \times 3$ max-pooling operation (`MaxPool2d(3, stride=1, padding=1)`) directly to the predicted keypoint heatmap. A cell is identified as a local peak if `Heatmap[x,y] == MaxPool(Heatmap)[x,y]`. The top 100 peak centers are selected directly, eliminating non-differentiable NMS algorithms.

**Q2: What are the three prediction heads in CenterNet?**
**A2:** (1) **Center Heatmap Head:** Predicts $C$-channel keypoint probability maps $\hat{Y} \in (0, 1)^{C \times H/4 \times W/4}$; (2) **Width & Height Head:** Predicts bounding box dimensions $(\hat{w}, \hat{h})$ at each center location; (3) **Sub-Pixel Offset Head:** Predicts discretization offset $(\Delta x, \Delta y)$ to fix downsampling rounding errors.

**Q3: Compare CenterNet with CornerNet.**
**A3:** CornerNet predicts 2 keypoints per object (top-left and bottom-right corners) and requires 1D associative embeddings to pair corners via $O(N^2)$ distance checks. CenterNet predicts a single center point per object, regressing box size directly at the center, eliminating keypoint pairing completely.

**Q4: How does CenterNet extend to 3D Bounding Box Estimation?**
**A4:** For 3D detection, CenterNet retains the 2D center heatmap and adds three additional parallel regression heads at the 2D center location: 3D depth $d$, 3D dimensions $(h, w, l)$, and 8-channel orientation angles $(\alpha)$.

**Q5: What is the purpose of sub-pixel offsets in CenterNet?**
**A5:** Downsampling an image by $4\times$ maps continuous ground-truth center coordinate $(p_x, p_y)$ to integer grid $(\lfloor p_x/4 \rfloor, \lfloor p_y/4 \rfloor)$. Sub-pixel offsets predict fractional error $(\Delta x, \Delta y) = (p_x/4 - \lfloor p_x/4 \rfloor, p_y/4 - \lfloor p_y/4 \rfloor)$ to restore exact continuous box boundaries.
