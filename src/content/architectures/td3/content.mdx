# TD3

## 1. Overview
Twin Delayed Deep Deterministic Policy Gradient (TD3), introduced in 2018 by Scott Fujimoto, Herke van Hoof, and David Meger (McGill University & MILA), solved the primary failure modes that plagued DDPG: **severe Q-value overestimation bias and high variance during training**. Fujimoto et al. proved that overestimation bias is not unique to discrete Q-learning—it is even more severe in continuous actor-critic algorithms like DDPG, where the actor continuously pushes action predictions toward overestimated Q-values. TD3 introduced three key algorithmic techniques that stabilized continuous off-policy actor-critic training:
1. **Clipped Double Q-Learning (Twin Critics):** Uses two independent Critic networks ($Q_{\phi_1}, Q_{\phi_2}$) and takes the **minimum** of their predictions ($\min(Q_{\phi_1}, Q_{\phi_2})$) to form the target value, preventing overestimation.
2. **Delayed Policy Updates:** Updates the Actor network and target networks less frequently than Critic networks (e.g., 1 actor update for every 2 critic updates) to allow the Critic to stabilize.
3. **Target Action Smoothing:** Adds small, clipped Gaussian noise to the target action ($\tilde{a} = \mu_{\theta^-}(s') + \epsilon$) to prevent the actor from exploiting narrow Q-value peaks.

:::tip
TD3's core formula: "Three tricks to stabilize DDPG: Twin Critics $\min(Q_1, Q_2)$ + Delayed Actor Updates (update G every 2 steps) + Target Action Smoothing Noise."
:::

## 2. Historical Context
In 2015, DDPG was celebrated as the continuous counterpart to DQN. However, in practice, DDPG was notoriously brittle. Researchers often experienced sudden performance drops where trained policies degraded rapidly to zero reward mid-training.

Scott Fujimoto et al. conducted an in-depth analysis of DDPG's failure modes. They demonstrated that because the Actor updates its parameters using the Critic's gradient ($\nabla_\theta Q(s, \mu_\theta(s))$), any overestimation in $Q$ is immediately exploited by the Actor. The Actor chooses actions that maximize the Critic's errors, causing a catastrophic feedback loop. TD3 established a reliable, highly stable baseline for continuous control.

## 3. Problem It Solves
TD3 addresses three specific flaws of standard continuous Actor-Critic models:
1. **Unbounded Overestimation in Continuous Action Spaces:** Twin Critics take the minimum score $\min(Q_1, Q_2)$, bounding Q-values and eliminating overestimation bias.
2. **Actor Update Instability on Poor Critics:** Updating the Actor when the Critic is inaccurate leads to policy divergence. **Delayed Policy Updates** ensure the Critic is well-optimized before updating the Actor.
3. **Overfitting to Spurious Q-Peaks:** Target Action Smoothing adds noise to target actions, enforcing the intuition that similar actions should yield similar values.

## 5. Layer-by-Layer Breakdown

**1. Twin Critics ($Q_{\phi_1}, Q_{\phi_2}$):**
- Two completely independent Critic networks sharing the exact same architecture (2 FC layers, 400 and 300 units).
- Each Critic takes state $s$ and action $a$ as input and outputs a scalar Q-value estimate.

**2. Actor Network ($\mu_\theta$):**
- Standard continuous actor network (2 FC layers, Tanh output scaled to action limits).

**3. Target Noise Generator:**
- Generates Gaussian noise $\epsilon \sim \text{clip}\left(\mathcal{N}(0, \tilde{\sigma}), -c, +c\right)$ (e.g., $\tilde{\sigma} = 0.2, c = 0.5$).

## 6. Tensor Flow Walkthrough
Let's trace tensors through TD3 for batch size $B=64$, state dim 17, action dim 6.

1. **Target Action Smoothing:**
   - Next State $s'$: `(64, 17)` $\xrightarrow{\text{Target Actor}} a_{\text{raw}}'$: `(64, 6)`
   - Add Clipped Noise: $\tilde{a} = \text{clip}(a_{\text{raw}}' + \text{clip}(\mathcal{N}(0, 0.2), -0.5, 0.5), a_{\min}, a_{\max}) \to$ `(64, 6)`
2. **Twin Target Critic Evaluation:**
   - Target Critic 1: $Q_{\phi_1^-}(s', \tilde{a}) \to$ `(64, 1)`
   - Target Critic 2: $Q_{\phi_2^-}(s', \tilde{a}) \to$ `(64, 1)`
   - Take Min Target: $y = r + \gamma (1-d) \min(Q_1^-, Q_2^-) \to$ `(64, 1)`
3. **Update Twin Critics:**
   - Compute MSE for $Q_1(s, a)$ and $Q_2(s, a)$ against target $y$.
4. **Delayed Actor Update (If Step % 2 == 0):**
   - Actor Loss: $-\frac{1}{B} \sum Q_1(s, \mu_\theta(s)) \to$ Scalar gradient update for $\theta$.

## 7. Mathematical Foundations

### 1. Clipped Double Q-Learning Target
To prevent overestimation, TD3 uses the minimum prediction between twin target critics:

$$y = r + \gamma (1 - d) \min_{i=1,2} Q_{\phi_i^-}\left(s', \; \tilde{a}\right)$$

Taking the minimum bounds the target, preventing positive error propagation.

### 2. Target Action Smoothing
Target actions are smoothed by adding clipped noise:

$$\tilde{a} = \text{clip}\left( \mu_{\theta^-}(s') + \epsilon, \; a_{\text{low}}, \; a_{\text{high}} \right), \quad \epsilon \sim \text{clip}\left( \mathcal{N}(0, \sigma^2), \; -c, \; +c \right)$$

This fits a value function over a smooth region in action space, preventing the actor from exploiting isolated sharp peaks.

### 3. Delayed Policy Updates
The Actor $\theta$ is updated once every $d$ steps (e.g., $d=2$). This lowers update variance and ensures the Critic evaluates actions against a stable baseline.

## 8. Training Procedure
- Sample mini-batch $(s, a, r, s', d) \sim \mathcal{D}$.
- Calculate smoothed target action $\tilde{a}$ and TD target $y = r + \gamma (1-d) \min(Q_1^-, Q_2^-)$.
- Update $Q_{\phi_1}$ and $Q_{\phi_2}$ using MSE loss.
- **Every $d=2$ steps:**
  - Update Actor $\theta$ using $-\mathbb{E}[Q_1(s, \mu_\theta(s))]$.
  - Soft update targets: $\theta^- \leftarrow \tau \theta + (1-\tau)\theta^-$ and $\phi_i^- \leftarrow \tau \phi_i + (1-\tau)\phi_i^-$.

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of the **TD3 Twin Critic and Delayed Actor Module**.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class TD3TwinCritic(nn.Module):
    """ Twin Critic Network for TD3 """
    def __init__(self, state_dim=17, action_dim=6):
        super().__init__()
        # Critic 1
        self.q1_l1 = nn.Linear(state_dim + action_dim, 400)
        self.q1_l2 = nn.Linear(400, 300)
        self.q1_l3 = nn.Linear(300, 1)
        
        # Critic 2
        self.q2_l1 = nn.Linear(state_dim + action_dim, 400)
        self.q2_l2 = nn.Linear(400, 300)
        self.q2_l3 = nn.Linear(300, 1)

    def forward(self, state, action):
        sa = torch.cat([state, action], dim=1)
        
        q1 = F.relu(self.q1_l1(sa))
        q1 = F.relu(self.q1_l2(q1))
        q1 = self.q1_l3(q1)
        
        q2 = F.relu(self.q2_l1(sa))
        q2 = F.relu(self.q2_l2(q2))
        q2 = self.q2_l3(q2)
        return q1, q2

    def Q1(self, state, action):
        sa = torch.cat([state, action], dim=1)
        q1 = F.relu(self.q1_l1(sa))
        q1 = F.relu(self.q1_l2(q1))
        return self.q1_l3(q1)

if __name__ == "__main__":
    B, state_dim, action_dim = 64, 17, 6
    twin_critic = TD3TwinCritic(state_dim=state_dim, action_dim=action_dim)
    
    state = torch.randn(B, state_dim)
    action = torch.randn(B, action_dim)
    
    q1, q2 = twin_critic(state, action)
    min_q = torch.min(q1, q2)
    
    print(f"Critic 1 Q-Value Shape: {q1.shape}")
    print(f"Critic 2 Q-Value Shape: {q2.shape}")
    print(f"Min Q-Value Shape:      {min_q.shape}")
    assert q1.shape == (B, 1) and q2.shape == (B, 1)
    print("TD3 Twin Critic verification successful!")
```

## 10. Strengths
- **Eliminates Q-Overestimation:** Twin Critics take $\min(Q_1, Q_2)$, stabilizing continuous off-policy learning.
- **Higher Training Stability:** Delayed policy updates prevent actor updates on poor critic baselines.
- **Robust Against Spurious Q-Peaks:** Target action smoothing regularizes action space.

## 11. Weaknesses
- **Slight Underestimation Bias:** Taking the minimum can occasionally cause mild underestimation of action values.

## 12. Research Evolution
TD3 fixed DDPG's core flaws, serving as the continuous deterministic foundation alongside **Soft Actor-Critic (SAC)**.

## 13. Interview Questions

**Q1: What are the three core innovations introduced in TD3?**
**A1:** (1) **Clipped Double Q-Learning (Twin Critics):** Takes $\min(Q_1^-, Q_2^-)$ to bound target values; (2) **Delayed Policy Updates:** Updates Actor and target networks less frequently than Critics (every 2 steps); (3) **Target Action Smoothing:** Adds clipped noise to target actions to prevent exploiting narrow Q-peaks.

**Q2: Why does DDPG suffer from severe overestimation bias?**
**A2:** The Actor optimizes parameters using the Critic's gradient ($\nabla_\theta Q(s, \mu(s))$). Any positive noise or overestimation error in the Critic is immediately exploited by the Actor, creating an overestimation feedback loop.

**Q3: Why does TD3 update the Actor network less frequently than the Critic networks?**
**A3:** Updating the Actor when the Critic is inaccurate leads to divergent policy updates. Delaying policy updates (e.g., 1 actor step for every 2 critic steps) ensures the Critic is well-optimized before evaluating actor gradients.

**Q4: Write out the TD3 Target Value equation.**
**A4:** $y = r + \gamma (1 - d) \min\left( Q_1^-(s', \tilde{a}), \; Q_2^-(s', \tilde{a}) \right)$ where $\tilde{a} = \text{clip}\left(\mu^-(s') + \text{clip}(\mathcal{N}(0, \sigma^2), -c, c), a_{\text{low}}, a_{\text{high}}\right)$.

**Q5: What is the purpose of Target Action Smoothing noise?**
**A5:** Adding clipped Gaussian noise to the target action $\tilde{a}$ enforces value function smoothness across neighboring action space points, preventing the Actor from exploiting narrow, non-generalizable Q-value spikes.
