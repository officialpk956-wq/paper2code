# YOLO v3

## 1. Overview
YOLO v3, introduced in 2018 by Joseph Redmon and Ali Farhadi in their famous tech report *YOLOv3: An Incremental Improvement*, brought single-stage object detection to modern architectural standards. While YOLO v2 made significant leaps via anchor boxes and Passthrough layers, it still struggled with detecting small objects because predictions were made from a single spatial resolution ($13 \times 13$). YOLO v3 solved this by adopting an **FPN-like Multi-Scale Prediction Architecture** that predicts bounding boxes across three distinct spatial resolutions ($13 \times 13$, $26 \times 26$, and $52 \times 52$). Powered by a new 53-layer residual backbone (**Darknet-53**) and replacing multi-class softmax with **Independent Sigmoid Classifiers** for multi-label classification, YOLO v3 achieved accuracy comparable to SSD and RetinaNet while running significantly faster (30 FPS at $608 \times 608$).

:::note
YOLO v3's core innovation: "Predict bounding boxes at 3 different scale levels ($1/32, 1/16, 1/4$) using feature pyramid connections, and replace softmax with independent logistic classifiers for multi-label classification."
:::

## 2. Historical Context
### The YOLO Evolution Story: Linear Progression (Part 3 - Multi-Scale Feature Pyramids & Residual Backbones)
The evolution of YOLO demonstrates a clear trajectory of architectural refinement:

- **YOLO v1 (2015):** Frame detection as single-pass regression ($7 \times 7$ grid, 45 FPS), but suffered from high localization error and low recall.
- **YOLO v2 (2016):** Replaced FC layers with anchor boxes, added Batch Normalization, used k-means anchor clustering, introduced Darknet-19, and added a single Passthrough layer for fine-grained features.
- **YOLO v3 (2018):** Addressed YOLO v2's remaining weakness: small object detection.

By 2018, Feature Pyramid Networks (FPN) had proven that multi-scale feature fusion was essential for small object detection. Joseph Redmon redesigned YOLO v3 to incorporate an FPN-style top-down feature aggregation pathway. He replaced Darknet-19 with **Darknet-53**—a powerful backbone incorporating residual skip connections (inspired by ResNet) that was significantly faster than ResNet-101 and ResNet-152. Furthermore, Redmon recognized that real-world objects often belong to overlapping categories (e.g., "Woman" and "Person"). He replaced the rigid single-softmax classifier with **independent logistic (sigmoid) classifiers**, allowing multi-label classification.

This model served as Joseph Redmon's final contribution to YOLO research before he stepped away from computer vision over ethical concerns regarding military applications and privacy surveillance, opening the door for Alexey Bochkovskiy (YOLO v4) and Ultralytics (YOLO v5 & v8).

## 3. Problem It Solves
YOLO v3 resolves three critical limitations of YOLO v2:
1. **Poor Small Object Detection:** Predicting solely at $13 \times 13$ resolution erased small objects. YOLO v3 predicts at three scales ($13 \times 13, 26 \times 26, 52 \times 52$), dramatically boosting Small Object AP.
2. **Multi-Label Class Exclusion:** Softmax forces mutually exclusive classes (e.g., an object cannot be both "Pedestrian" and "Person"). Independent sigmoid classifiers enable multi-label classification.
3. **Gradient Vanishing in Deep Backbones:** Darknet-19 lacked residual connections. Darknet-53 integrates 23 residual blocks, enabling deeper representation learning without gradient degradation.

## 5. Layer-by-Layer Breakdown
YOLO v3 consists of Darknet-53 and an FPN-style 3-scale detection head:

**1. Darknet-53 Backbone:**
- Consists of 53 convolutional layers utilizing $1 \times 1$ and $3 \times 3$ filters with residual skip connections.
- Downsamples spatial resolution via strided convolutions (no max-pooling).
- Extracts three intermediate feature maps:
  - $C_3$ (Stride 8): Shape $(B, 256, 52, 52)$
  - $C_4$ (Stride 16): Shape $(B, 512, 26, 26)$
  - $C_5$ (Stride 32): Shape $(B, 1024, 13, 13)$

**2. Scale 1 Head (Large Objects, Stride 32):**
- Processes $C_5$ ($13 \times 13 \times 1024$) through 5 Darknet-Conv-Layer-BatchNorm-LeakyReLU (DBL) layers.
- Predicts bounding boxes on a $13 \times 13$ grid using 3 large anchors.
- Output shape: $(B, 3 \times (5 + C), 13, 13) = (B, 255, 13, 13)$ for $C=80$ COCO classes.

**3. Scale 2 Head (Medium Objects, Stride 16):**
- Takes the $13 \times 13$ feature map, applies $1 \times 1$ conv + $2\times$ bilinear upsampling to $(B, 256, 26, 26)$.
- Concatenates upsampled features with backbone feature map $C_4$ ($26 \times 26 \times 512$).
- Processes fused features and predicts bounding boxes on a $26 \times 26$ grid using 3 medium anchors.
- Output shape: $(B, 255, 26, 26)$.

**4. Scale 3 Head (Small Objects, Stride 8):**
- Takes the $26 \times 26$ feature map, applies $1 \times 1$ conv + $2\times$ bilinear upsampling to $(B, 128, 52, 52)$.
- Concatenates upsampled features with backbone feature map $C_3$ ($52 \times 52 \times 256$).
- Predicts bounding boxes on a $52 \times 52$ grid using 3 small anchors.
- Output shape: $(B, 255, 52, 52)$.

## 6. Tensor Flow Walkthrough
Let's trace tensors through YOLO v3 for input `(B, 3, 416, 416)` and $C=80$ COCO classes ($3 \times (5 + 80) = 255$ output channels).

1. **Input Tensor:** `(B, 3, 416, 416)`
2. **Darknet-53 Processing:**
   - Feature Map $C_3$ (Stride 8): `(B, 256, 52, 52)`
   - Feature Map $C_4$ (Stride 16): `(B, 512, 26, 26)`
   - Feature Map $C_5$ (Stride 32): `(B, 1024, 13, 13)`
3. **Scale 1 Prediction ($13 \times 13$):**
   - 5x Conv Block on $C_5 \rightarrow$ `(B, 512, 13, 13)`
   - Conv1x1(512 $\rightarrow 255$) $\rightarrow$ **Scale 1 Output:** `(B, 255, 13, 13)`
4. **Scale 2 Prediction ($26 \times 26$):**
   - Conv1x1(512 $\rightarrow 256$) + Upsample2x $\rightarrow$ `(B, 256, 26, 26)`
   - Concat with $C_4(512) \rightarrow$ `(B, 768, 26, 26)`
   - 5x Conv Block + Conv1x1(256 $\rightarrow 255$) $\rightarrow$ **Scale 2 Output:** `(B, 255, 26, 26)`
5. **Scale 3 Prediction ($52 \times 52$):**
   - Conv1x1(256 $\rightarrow 128$) + Upsample2x $\rightarrow$ `(B, 128, 52, 52)`
   - Concat with $C_3(256) \rightarrow$ `(B, 384, 52, 52)`
   - 5x Conv Block + Conv1x1(128 $\rightarrow 255$) $\rightarrow$ **Scale 3 Output:** `(B, 255, 52, 52)`

## 7. Mathematical Foundations

### 1. 9 Anchors Clustered Across 3 Scales
YOLO v3 runs k-means clustering on COCO bounding box dimensions to extract $k=9$ prior anchor shapes. These 9 anchors are divided equally across the 3 prediction scales:

- **Scale 1 ($13 \times 13$, Large Objects):** $(116 \times 90), (156 \times 198), (373 \times 326)$
- **Scale 2 ($26 \times 26$, Medium Objects):** $(30 \times 61), (62 \times 45), (59 \times 119)$
- **Scale 3 ($52 \times 52$, Small Objects):** $(10 \times 13), (16 \times 30), (33 \times 23)$

### 2. Multi-Label Binary Cross-Entropy Loss
YOLO v3 drops Softmax cross-entropy in favor of independent binary cross-entropy (BCE) loss for class predictions.

For each anchor $i$ and class $c$:
$$\mathcal{L}_{\text{class}} = -\sum_{i \in \text{pos}} \sum_{c=1}^C \left[ y_{i,c} \log \hat{y}_{i,c} + (1 - y_{i,c}) \log (1 - \hat{y}_{i,c}) \right]$$

where $\hat{y}_{i,c} = \sigma(s_{i,c})$ is the sigmoid probability for class $c$.

### 3. Total Multi-Scale Loss Formulation
$$\mathcal{L}_{\text{YOLOv3}} = \sum_{\text{scale} \in \{13, 26, 52\}} \left( \mathcal{L}_{\text{box}} + \mathcal{L}_{\text{obj}} + \mathcal{L}_{\text{noobj}} + \mathcal{L}_{\text{class}} \right)$$

where:
$$\mathcal{L}_{\text{box}} = \lambda_{\text{coord}} \sum_{i \in \text{pos}} \left[ (t_x - \hat{t}_x)^2 + (t_y - \hat{t}_y)^2 + (t_w - \hat{t}_w)^2 + (t_h - \hat{t}_h)^2 \right]$$
$$\mathcal{L}_{\text{obj}} = -\sum_{i \in \text{pos}} \log \sigma(\hat{t}_o), \quad \mathcal{L}_{\text{noobj}} = -\lambda_{\text{noobj}} \sum_{i \in \text{neg}} \log(1 - \sigma(\hat{t}_o))$$

## 8. Training Procedure
- **Darknet-53 Pre-Training:** Backbone pre-trained on ImageNet-1K.
- **Data Augmentation:** Random cropping, scaling, horizontal flipping, and HSV color jittering.
- **Optimizer:** Adam or SGD with momentum 0.9, weight decay $5 \times 10^{-4}$.
- **Multi-Scale Training:** Randomly resizes input dimensions between $320 \times 320$ and $608 \times 608$ every 10 batches.

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of the **YOLO v3 Multi-Scale Prediction Head**.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ConvBlock(nn.Module):
    def __init__(self, in_c, out_c, kernel_size, stride=1, padding=0):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_c, out_c, kernel_size, stride, padding, bias=False),
            nn.BatchNorm2d(out_c),
            nn.LeakyReLU(0.1, inplace=True)
        )
    def forward(self, x):
        return self.conv(x)

class YOLOv3MultiScaleHead(nn.Module):
    def __init__(self, num_classes=80, num_anchors_per_scale=3):
        super().__init__()
        self.num_classes = num_classes
        out_c = num_anchors_per_scale * (5 + num_classes) # 3 * (5 + 80) = 255
        
        # Scale 1 ($13 \times 13$)
        self.head1 = nn.Sequential(
            ConvBlock(1024, 512, 3, padding=1),
            nn.Conv2d(512, out_c, kernel_size=1)
        )
        
        # Scale 2 ($26 \times 26$)
        self.up1 = nn.Sequential(
            ConvBlock(1024, 256, 1),
            nn.Upsample(scale_factor=2, mode='nearest')
        )
        self.head2 = nn.Sequential(
            ConvBlock(256 + 512, 256, 3, padding=1),
            nn.Conv2d(256, out_c, kernel_size=1)
        )
        
        # Scale 3 ($52 \times 52$)
        self.up2 = nn.Sequential(
            ConvBlock(256 + 512, 128, 1),
            nn.Upsample(scale_factor=2, mode='nearest')
        )
        self.head3 = nn.Sequential(
            ConvBlock(128 + 256, 128, 3, padding=1),
            nn.Conv2d(128, out_c, kernel_size=1)
        )

    def forward(self, c3, c4, c5):
        """
        c3: (B, 256, 52, 52)  - Stride 8
        c4: (B, 512, 26, 26)  - Stride 16
        c5: (B, 1024, 13, 13) - Stride 32
        """
        # Scale 1 (13x13)
        out1 = self.head1(c5) # (B, 255, 13, 13)
        
        # Scale 2 (26x26)
        c5_up = self.up1(c5)  # (B, 256, 26, 26)
        concat1 = torch.cat([c5_up, c4], dim=1) # (B, 768, 26, 26)
        out2 = self.head2(concat1) # (B, 255, 26, 26)
        
        # Scale 3 (52x52)
        c4_up = self.up2(concat1) # (B, 128, 52, 52)
        concat2 = torch.cat([c4_up, c3], dim=1) # (B, 384, 52, 52)
        out3 = self.head3(concat2) # (B, 255, 52, 52)
        
        return out1, out2, out3

if __name__ == "__main__":
    B = 2
    num_classes = 80
    head = YOLOv3MultiScaleHead(num_classes=num_classes)
    
    # Dummy Darknet-53 feature maps
    c3 = torch.randn(B, 256, 52, 52)
    c4 = torch.randn(B, 512, 26, 26)
    c5 = torch.randn(B, 1024, 13, 13)
    
    out1, out2, out3 = head(c3, c4, c5)
    
    print(f"Scale 1 (13x13) Shape: {out1.shape}")
    print(f"Scale 2 (26x26) Shape: {out2.shape}")
    print(f"Scale 3 (52x52) Shape: {out3.shape}")
    
    assert out1.shape == (B, 255, 13, 13)
    assert out2.shape == (B, 255, 26, 26)
    assert out3.shape == (B, 255, 52, 52)
    print("YOLO v3 Multi-Scale Head verification successful!")
```

## 10. Strengths
- **Dramatic Small Object Accuracy Gain:** Multi-scale feature fusion ($52 \times 52$ grid) dramatically improved small object detection AP compared to YOLO v2.
- **Multi-Label Classification:** Independent logistic classifiers allow predictions for overlapping category taxonomies.
- **Efficient Residual Backbone:** Darknet-53 is $2\times$ faster than ResNet-101 while achieving equivalent classification accuracy.

## 11. Weaknesses
- **Slower than YOLO v2:** Predicting across 3 scales with Darknet-53 reduced speed from 67 FPS to 30 FPS.
- **Struggles on Medium/Large Objects vs RetinaNet:** RetinaNet with Focal Loss achieved slightly higher AP on medium/large objects.

## 12. Research Evolution
YOLO v3 brought single-stage detection to feature-pyramid parity with two-stage detectors. It served as Joseph Redmon's final paper, laying the foundation for **YOLO v4** (Bochkovskiy et al., 2020), which added CSP darknet backbones and PANet path aggregation.

## 13. Interview Questions

**Q1: How does YOLO v3 assign its 9 anchor boxes across its 3 prediction scales?**
**A1:** The 9 anchor boxes are sorted by area and divided into 3 groups of 3 anchors:
- Largest 3 anchors assigned to Scale 1 ($13 \times 13$, Stride 32) for large objects.
- Medium 3 anchors assigned to Scale 2 ($26 \times 26$, Stride 16) for medium objects.
- Smallest 3 anchors assigned to Scale 3 ($52 \times 52$, Stride 8) for small objects.

**Q2: Why did YOLO v3 replace Softmax with Sigmoid binary cross-entropy for class prediction?**
**A2:** Softmax enforces mutual exclusivity (an object can belong to only one class). Real-world data often has complex multi-label taxonomies (e.g., "Woman" and "Person"). Independent logistic (sigmoid) classifiers evaluate $P(\text{Class}_i)$ separately for each class, enabling multi-label prediction.

**Q3: Compare Darknet-19 (YOLO v2) with Darknet-53 (YOLO v3).**
**A3:** Darknet-19 had 19 conv layers with no skip connections. Darknet-53 has 53 conv layers utilizing 23 residual skip blocks (similar to ResNet). Darknet-53 is significantly more accurate than Darknet-19 and $1.5\times$ faster than ResNet-101.

**Q4: What is the total number of bounding boxes evaluated by YOLO v3 on a $416 \times 416$ image?**
**A4:** 
- Scale 1: $13 \times 13 \times 3 = 507$ boxes
- Scale 2: $26 \times 26 \times 3 = 2,028$ boxes
- Scale 3: $52 \times 52 \times 3 = 8,112$ boxes
- Total = $507 + 2028 + 8112 = 10,647$ bounding boxes (vs. YOLO v2's 845 boxes).

**Q5: How does YOLO v3 construct its top-down feature fusion pathway?**
**A5:** It takes features from the deepest scale ($13 \times 13$), applies a $1 \times 1$ conv + $2\times$ nearest-neighbor upsampling to $26 \times 26$, and concatenates them with $C_4$ features ($26 \times 26$). This process repeats for the $52 \times 52$ scale.
