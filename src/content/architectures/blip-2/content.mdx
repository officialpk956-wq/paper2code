# BLIP-2

## 1. Overview
BLIP-2 (Querying Transformer / Q-Former), introduced in 2023 by Junnan Li, Dongxu Li, Silvio Savarese, and Steven Hoi (Salesforce Research), introduced a revolutionary compute-efficient vision-language alignment paradigm. Prior to BLIP-2, building Multimodal LLMs required either end-to-end fine-tuning of multi-billion parameter models (which was computationally prohibitive and caused language degradation) or training simple linear projection layers that provided poor visual-linguistic alignment. BLIP-2 achieved state-of-the-art vision-language performance while keeping **both the Vision Encoder (EVA-CLIP ViT) and the Large Language Model (Flan-T5 / Vicuna) completely frozen**. The core innovation of BLIP-2 is the **Querying Transformer (Q-Former)**: a lightweight 188M parameter module that uses **32 learned query tokens** to extract visual features from the frozen ViT via cross-attention and project them into the frozen LLM's text embedding space.

:::note
BLIP-2 core contribution: "Bridge frozen Vision Encoder and frozen LLM using a 188M Q-Former. 32 learned query tokens extract visual features via cross-attention and project them into the LLM context space."
:::

## 2. Historical Context
In 2023, LLMs reached 11B–70B parameters (Flan-T5, LLaMA, Vicuna). Fine-tuning a 70B model on vision-language data required massive supercomputing clusters.

Li et al. realized that pre-trained visual encoders and pre-trained LLMs already possessed incredible individual capabilities. The challenge was simply **representation alignment**. BLIP-2 created a 2-stage pre-training strategy that uses a 32-query Q-Former as a lightweight neural bridge, reducing multimodal alignment compute by $10\times$ to $100\times$.

## 3. Problem It Solves
BLIP-2 resolves three primary computational and architectural barriers in VLM research:
1. **Enormous Pre-Training Compute Cost:** Eliminates full model fine-tuning by **freezing** both the Vision Encoder and the LLM.
2. **Visual Feature Dimension Mismatch:** Compresses $N=257$ visual patch tokens into **32 compact query tokens**, reducing LLM context window consumption.
3. **Modality Representation Gap:** Aligns visual representations with LLM text token space using 2-stage Q-Former training.

## 5. Layer-by-Layer Breakdown

**1. Frozen Vision Encoder:**
- Takes input image $I \in \mathbb{R}^{3 \times 224 \times 224}$. Extracts visual patch embeddings $Z_v \in \mathbb{R}^{257 \times 1408}$ using a frozen EVA-CLIP ViT-g/14.

**2. Trainable Q-Former Architecture:**
- Initializes $N_q = 32$ learnable query embedding vectors $Q_{\text{learn}} \in \mathbb{R}^{32 \times 768}$.
- **Self-Attention Layers:** The 32 query tokens attend to each other, sharing context.
- **Cross-Attention Layers:** Queries attend to frozen visual patch embeddings $Z_v$ every 2 Transformer layers.
- **Text Transformer Layers:** Shares self-attention parameters with a BERT-base text encoder for joint text-image training.

**3. Linear Projection to Frozen LLM:**
- Projects the 32 Q-Former output vectors to LLM embedding dimension $d_{\text{llm}}$ via a linear layer: $Z_{\text{prefix}} = Z_q W_{\text{proj}} \in \mathbb{R}^{32 \times d_{\text{llm}}}$.
- Prepends $Z_{\text{prefix}}$ to user text tokens in the frozen LLM (Flan-T5 or Vicuna).

## 6. Tensor Flow Walkthrough
Let's trace tensors through BLIP-2 for batch size $B=4$, 32 query tokens, ViT patch count $N=257$, Q-Former dim $d=768$, LLM dim $d_{\text{llm}}=4096$.

1. **Frozen ViT Pass:**
   - Image $I$: `(4, 3, 224, 224)` $\xrightarrow{\text{Frozen ViT}} Z_v$: `(4, 257, 1408)`
2. **Q-Former Dual Attention Pass:**
   - 32 Learned Queries: `(4, 32, 768)`
   - Self-Attention over 32 Queries $\to$ `(4, 32, 768)`
   - Cross-Attention($Q=32\text{ Queries}, K=Z_v, V=Z_v$) $\to Z_q$: `(4, 32, 768)`
3. **Linear Projection & LLM Generation:**
   - Linear Projection $Z_q W_{\text{proj}} \to Z_{\text{prefix}}$: `(4, 32, 4096)`
   - Prepend to User Prompt (e.g., 20 text tokens) $\to$ Full LLM Input: `(4, 52, 4096)`
   - Pass through Frozen LLM $\to$ Generated Text Response.

## 7. Mathematical Foundations

### 1. The Two-Stage Q-Former Pre-Training Strategy

#### Stage 1: Vision-Language Representation Learning (Frozen ViT)
Q-Former is pre-trained on three joint objectives using 32 query tokens:
1. **Representation Contrastive Learning ($\mathcal{L}_{\text{ITC}}$):** Aligns highest similarity query token representation with text $[CLS]$ token.
2. **Image-Grounded Text Generation ($\mathcal{L}_{\text{LM}}$):** Autoregressively generates text conditioned on 32 queries.
3. **Image-Text Matching ($\mathcal{L}_{\text{ITM}}$):** Binary classification matching queries with text.

#### Stage 2: Vision-to-Language Generative Pre-Training (Frozen LLM)
Connects Q-Former output $Z_q \in \mathbb{R}^{32 \times 768}$ to frozen LLM via Linear Layer $W_{\text{proj}}$:

$$Z_{\text{prefix}} = Z_q W_{\text{proj}} \in \mathbb{R}^{32 \times d_{\text{llm}}}$$

Optimizes language generation loss over frozen LLM targets:

$$\mathcal{L}_{\text{LLM}} = -\sum_{i=1}^M \log P_{\text{LLM}}\left( y_i \;\middle|\; y_{<i}, \; Z_{\text{prefix}}, \; X_{\text{prompt}} \right)$$

## 8. Training Procedure
- **Stage 1 (Representation Pre-training):** Freeze EVA-CLIP ViT. Train Q-Former on 129M images (COCO, LAION, SBU) for 250k steps using ITC + ITM + LM losses.
- **Stage 2 (Generative Pre-training):** Freeze ViT AND LLM (Flan-T5 or Vicuna). Train linear projection layer $W_{\text{proj}}$ and Q-Former for 80k steps using language modeling loss.
- Total training time: ~6 days on 16 $\times$ A100 (80GB) GPUs.

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of the **BLIP-2 Q-Former Module**.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class QFormer(nn.Module):
    """ BLIP-2 Q-Former: 32 Query Tokens Attending to Image Features via Cross-Attention """
    def __init__(self, visual_dim=1408, query_dim=768, num_queries=32, llm_dim=4096):
        super().__init__()
        self.num_queries = num_queries
        self.query_dim = query_dim
        
        # 32 Learnable Query Vectors
        self.query_tokens = nn.Parameter(torch.randn(1, num_queries, query_dim))
        
        # Self-Attention for Queries
        self.self_attn = nn.MultiheadAttention(embed_dim=query_dim, num_heads=8, batch_first=True)
        
        # Cross-Attention: Queries attend to Visual Features
        self.vis_proj = nn.Linear(visual_dim, query_dim)
        self.cross_attn = nn.MultiheadAttention(embed_dim=query_dim, num_heads=8, batch_first=True)
        
        # Linear Projection to Frozen LLM Embedding Dimension
        self.llm_proj = nn.Linear(query_dim, llm_dim)

    def forward(self, visual_feats):
        """ visual_feats: (B, N_patches, visual_dim) """
        B = visual_feats.shape[0]
        
        # 1. Expand 32 Query Tokens for Batch Size B
        queries = self.query_tokens.repeat(B, 1, 1) # (B, 32, 768)
        
        # 2. Self-Attention (Queries attend to each other)
        q_self, _ = self.self_attn(queries, queries, queries) # (B, 32, 768)
        
        # 3. Cross-Attention (Queries attend to Visual Features)
        v_proj = self.vis_proj(visual_feats) # (B, N_patches, 768)
        q_cross, _ = self.cross_attn(query=q_self, key=v_proj, value=v_proj) # (B, 32, 768)
        
        # 4. Project to LLM Embedding Dimension
        z_prefix = self.llm_proj(q_cross) # (B, 32, 4096)
        return z_prefix

if __name__ == "__main__":
    B, N_patches, vis_dim, llm_dim = 4, 257, 1408, 4096
    qformer = QFormer(visual_dim=vis_dim, query_dim=768, num_queries=32, llm_dim=llm_dim)
    
    vis_feats = torch.randn(B, N_patches, vis_dim)
    llm_prefix = qformer(vis_feats)
    
    print(f"Q-Former LLM Prefix Tokens Output Shape: {llm_prefix.shape}")
    assert llm_prefix.shape == (B, 32, llm_dim)
    print("BLIP-2 Q-Former verification successful!")
```

## 10. Strengths
- **Compute Efficiency:** Trains in days on 16 GPUs by keeping Vision Encoder and LLM frozen.
- **Compact 32-Token Bottleneck:** Compresses $N=257$ visual patches into 32 tokens, preserving LLM context length.
- **Zero-Shot VQA Superiority:** Outperforms Flamingo-80B on zero-shot VQA while using $54\times$ fewer trainable parameters.

## 11. Weaknesses
- **Fixed 32 Token Resolution Limitation:** Struggles with detailed spatial grounding or fine-grained OCR text recognition (addressed by LLaVA 1.5).

## 12. Research Evolution
BLIP-2 created the Q-Former paradigm, directly inspiring **InstructBLIP**, **MiniGPT-4**, and **Video-LLaVA**.

## 13. Interview Questions

**Q1: What is the main innovation of BLIP-2 compared to prior Vision-Language Models?**
**A1:** BLIP-2 introduced the **Q-Former** (Querying Transformer), a lightweight 188M parameter bridge that aligns visual features with LLM text space using 32 learned query tokens while keeping **both the Vision Encoder and LLM completely frozen**.

**Q2: How does the Q-Former cross-attention mechanism work?**
**A2:** The 32 learned query tokens attend to each other via self-attention, and attend to visual patch features from the frozen ViT via cross-attention ($Q = \text{Queries}, K, V = \text{Visual Features}$), extracting 32 task-relevant visual prefix tokens.

**Q3: What are the two training stages of BLIP-2?**
**A3:** (1) **Stage 1 (Representation Pre-training):** Trains Q-Former with frozen ViT on ITC, ITM, and LM losses; (2) **Stage 2 (Generative Pre-training):** Connects Q-Former to frozen LLM (Flan-T5/Vicuna) via a linear layer and trains using language modeling loss.

**Q4: Why does BLIP-2 freeze both the Vision Encoder and the LLM?**
**A4:** Freezing both models preserves their pre-trained capabilities (visual perception and text reasoning), prevents catastrophic forgetting, and reduces multimodal alignment compute costs by over $10\times$.

**Q5: How many tokens does BLIP-2 consume in the LLM context window?**
**A5:** Exactly **32 tokens**, regardless of input image resolution or initial ViT patch count.
