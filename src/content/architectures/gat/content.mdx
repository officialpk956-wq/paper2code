# Graph Attention Network (GAT)

## 1. Overview
Graph Attention Network (GAT), introduced in 2017 by Petar Veličković, Guillem Cucurull, Arantxa Casanova, Adriana Romero, Pietro Liò, and Yoshua Bengio (University of Cambridge & MILA), revolutionized Graph Neural Networks by introducing **Anisotropic Attention-Weighted Neighborhood Aggregation**. Prior to GAT, standard Graph Convolutional Networks (GCNs) and GraphSAGE treated all edges connected to a node as structurally equal (or scaled them by static node degree numbers $\frac{1}{\sqrt{d_i d_j}}$). Veličković et al. recognized that in real-world graphs (e.g., social networks, protein interactions), different neighbors carry vastly different importance depending on their feature content. GAT introduced a self-attention mechanism that dynamically computes pairwise attention coefficients $\alpha_{i,j}$ for every edge $(i, j)$. By weighting neighbor messages dynamically according to feature relevance and extending to **Multi-Head Attention**, GAT operates on both transductive and inductive graphs without requiring expensive matrix inversions.

:::note
GAT innovation: "Anisotropic attention-weighted GNN aggregation: $\alpha_{ij} = \text{softmax}_j\left( \text{LeakyReLU}\left( \mathbf{a}^T [W h_i \;\Vert\; W h_j] \right) \right)$. Dynamically learns edge importance using Multi-Head Attention."
:::

## 2. Historical Context
In 2017, GCN established isotropic spectral-based graph convolutions. However, GCN possessed two major limitations: it assigned fixed, static degree weights to all neighbors, and it required knowing the entire graph structure during training.

Veličković et al. adapted Bahdanau's self-attention mechanism to graph structures. They designed GAT to evaluate pairwise attention coefficients between neighboring node feature vectors. Because attention coefficients depend purely on node feature content, GAT operates dynamically, enabling inductive generalization to completely unseen graphs without static graph structure constraints.

## 3. Problem It Solves
GAT resolves three fundamental limitations of prior GNN models:
1. **Isotropic Aggregation Uniformity:** Eliminates the assumption that all neighbors are equally important. GAT assigns higher attention weights $\alpha_{i,j}$ to highly relevant neighbors.
2. **Static Degree Weight Rigidity:** Replaces static degree scalings $\frac{1}{\sqrt{d_i d_j}}$ with feature-dependent self-attention weights learned end-to-end.
3. **Graph Topology Dependence:** Operates on local 1-hop neighborhoods without requiring global adjacency matrix structures or Laplacian eigen-decompositions.

## 5. Layer-by-Layer Breakdown

**1. Shared Linear Feature Transformation:**
- Given node features $h = \{h_1, h_2, \dots, h_N\} \subset \mathbb{R}^F$.
- Applies a shared linear transformation matrix $W \in \mathbb{R}^{F' \times F}$ to every node: $h_i' = W h_i \in \mathbb{R}^{F'}$.

**2. Pairwise Attention Coefficient Calculation:**
- Computes unnormalized attention score $e_{i,j}$ between node $i$ and neighbor $j \in \mathcal{N}_i$:
  $$e_{i,j} = \text{LeakyReLU}\left( \mathbf{a}^T \left[ W h_i \;\|\; W h_j \right] \right)$$
  where $\mathbf{a} \in \mathbb{R}^{2F'}$ is a learnable attention weight vector.

**3. Softmax Normalization across Neighborhood:**
- Normalizes attention scores across node $i$'s 1-hop neighborhood using Softmax:
  $$\alpha_{i,j} = \text{Softmax}_j(e_{i,j}) = \frac{\exp\left( \text{LeakyReLU}\left( \mathbf{a}^T [W h_i \,\|\, W h_j] \right) \right)}{\sum_{k \in \mathcal{N}_i} \exp\left( \text{LeakyReLU}\left( \mathbf{a}^T [W h_i \,\|\, W h_k] \right) \right)}$$

**4. Multi-Head Attention Aggregation:**
- Employs $K$ independent attention heads.
- **Hidden Layers (Concatenation):**
  $$h_i' = \Vert_{k=1}^K \sigma\left( \sum_{j \in \mathcal{N}_i} \alpha_{i,j}^k W^k h_j \right)$$
- **Output Layer (Averaging):**
  $$h_i^{\text{out}} = \sigma\left( \frac{1}{K} \sum_{k=1}^K \sum_{j \in \mathcal{N}_i} \alpha_{i,j}^k W^k h_j \right)$$

## 6. Tensor Flow Walkthrough
Let's trace tensors through a GAT layer for $N=1000$ nodes, initial feature dimension $F=1433$, output dimension per head $F'=8$, number of attention heads $K=8$.

1. **Linear Feature Projection:**
   - Node Features $h$: `(1000, 1433)`
   - $K=8$ Projection Matrices $W^k$: `(8, 1433, 8)` $\to W h$: `(1000, 8, 8)` (Nodes, Heads, Feature_Dim)
2. **Attention Score Computation (over $E$ edges):**
   - For $E=5000$ edges $(i, j)$:
   - Source $W h_i$: `(5000, 8, 8)`, Target $W h_j$: `(5000, 8, 8)`
   - Concat $[W h_i \,\|\, W h_j] \to$ `(5000, 8, 16)` $\xrightarrow{\text{Dot with } \mathbf{a}} e_{i,j}$: `(5000, 8)`
   - Apply Softmax over neighbors $\to \alpha_{i,j}$: `(5000, 8)`
3. **Multi-Head Aggregation & Concatenation:**
   - Weighted Sum $\sum_{j} \alpha_{i,j}^k W^k h_j \to$ `(1000, 8, 8)`
   - Concat 8 Heads along feature dim $\to h^{\text{new}}$: `(1000, 64)`.

## 7. Mathematical Foundations

### 1. GAT Single-Head Attention Formula
For an edge $(i, j)$ connecting target node $i$ and neighbor node $j$:

$$\alpha_{i,j} = \frac{\exp\left( \text{LeakyReLU}\left( \mathbf{a}^T \left[ W h_i \;\Vert\; W h_j \right] \right) \right)}{\sum_{k \in \mathcal{N}_i} \exp\left( \text{LeakyReLU}\left( \mathbf{a}^T \left[ W h_i \;\Vert\; W h_k \right] \right) \right)}$$

where $\mathbf{a} \in \mathbb{R}^{2F'}$ is the parametrized attention vector, and $\text{LeakyReLU}$ uses negative slope $0.2$.

### 2. Multi-Head Concatenation & Averaging Formulas
- **Concatenation (Intermediate Layers):**
  $$h_i^{(l+1)} = \text{ELU}\left( \|_{k=1}^K \sum_{j \in \mathcal{N}_i} \alpha_{i,j}^k W^k h_j^{(l)} \right) \in \mathbb{R}^{K \cdot F'}$$

- **Averaging (Final Prediction Layer):**
  $$h_i^{(l+1)} = \text{Softmax}\left( \frac{1}{K} \sum_{k=1}^K \sum_{j \in \mathcal{N}_i} \alpha_{i,j}^k W^k h_j^{(l)} \right) \in \mathbb{R}^{C}$$

## 8. Training Procedure
- Input node features $H \in \mathbb{R}^{N \times F}$ and graph edge index tensor `(2, E)`.
- Forward pass through GAT multi-head attention layers.
- Compute Cross-Entropy loss over labeled nodes.
- Update projection weights $W^k$ and attention vectors $\mathbf{a}_k$ using Adam optimizer ($\text{lr} = 0.005$).

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of the **GAT Multi-Head Attention Layer**.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class GATLayer(nn.Module):
    """ Graph Attention Network (GAT) Multi-Head Layer """
    def __init__(self, in_features, out_features, num_heads=8, concat=True, dropout=0.6, leaky_relu_slope=0.2):
        super().__init__()
        self.in_features = in_features
        self.out_features = out_features
        self.num_heads = num_heads
        self.concat = concat
        
        # Linear Transformation Matrix W: (K, in_features, out_features)
        self.W = nn.Parameter(torch.empty(num_heads, in_features, out_features))
        # Attention Parameter Vector a: (K, 2 * out_features)
        self.a = nn.Parameter(torch.empty(num_heads, 2 * out_features))
        
        self.leaky_relu = nn.LeakyReLU(leaky_relu_slope)
        self.dropout = nn.Dropout(dropout)
        
        nn.init.xor_normal_(self.W, gain=1.414)
        nn.init.xor_normal_(self.a.unsqueeze(-1), gain=1.414)

    def forward(self, x, edge_index):
        """
        x:          (N, in_features)
        edge_index: (2, E) Edge indices [src_nodes, dst_nodes]
        """
        N = x.shape[0]
        src_nodes, dst_nodes = edge_index[0], edge_index[1] # (E,)
        
        # 1. Linear Projection: Wh -> (N, K, out_features)
        # x_expanded: (N, 1, in_features) * W: (K, in_features, out_features)
        h_prime = torch.einsum('ni,kif->nkf', x, self.W) # (N, K, out_features)
        
        # 2. Extract Source and Target Vectors for Edges
        h_src = h_prime[src_nodes] # (E, K, out_features)
        h_dst = h_prime[dst_nodes] # (E, K, out_features)
        
        # Concatenate Source and Target for Attention Input
        cat_embeds = torch.cat([h_src, h_dst], dim=-1) # (E, K, 2 * out_features)
        
        # 3. Pairwise Unnormalized Attention Scores
        e = self.leaky_relu(torch.einsum('ekf,kf->ek', cat_embeds, self.a)) # (E, K)
        
        # Softmax over incoming edges (simulated via scatter softmax or dense mask)
        # Simplified dense Softmax for verification:
        alpha = F.softmax(e, dim=0) # (E, K)
        alpha = self.dropout(alpha)
        
        # 4. Attention Weighted Aggregation
        msg = h_src * alpha.unsqueeze(-1) # (E, K, out_features)
        
        # Scatter add messages to destination nodes
        out = torch.zeros(N, self.num_heads, self.out_features, device=x.device)
        out.index_add_(0, dst_nodes, msg) # (N, K, out_features)
        
        if self.concat:
            return F.elu(out.view(N, self.num_heads * self.out_features))
        else:
            return F.elu(out.mean(dim=1))

if __name__ == "__main__":
    N, E, in_dim, out_dim, heads = 100, 500, 1433, 8, 8
    gat_layer = GATLayer(in_features=in_dim, out_features=out_dim, num_heads=heads, concat=True)
    
    x = torch.randn(N, in_dim)
    edge_index = torch.stack([
        torch.randint(0, N, (E,)),
        torch.randint(0, N, (E,))
    ])
    
    out = gat_layer(x, edge_index)
    
    print(f"GAT Multi-Head Output Shape: {out.shape}")
    assert out.shape == (N, heads * out_dim)
    print("GAT verification successful!")
```

## 10. Strengths
- **Anisotropic Attention Aggregation:** Learns dynamic feature-dependent edge weights $\alpha_{i,j}$ for different neighbors.
- **Multi-Head Attention Stability:** Parallel attention heads stabilize learning and capture diverse relationship types.
- **Inductive & Transductive Generalization:** Operates seamlessly on both fixed graphs and unseen dynamic graphs.

## 11. Weaknesses
- **Static Attention Limitation:** Computes attention using a static inner product $a^T [Wh_i \parallel Wh_j]$, where attention ranking is monotonic relative to target node $i$ (addressed by GATv2).

## 12. Research Evolution
GAT established attention-based graph neural networks, directly inspiring **GATv2**, **Graph Transformer**, and **Graphormer**.

## 13. Interview Questions

**Q1: What is the main difference between GCN and GAT?**
**A1:** GCN uses **isotropic** aggregation: neighbor messages are weighted by static node degree numbers ($\frac{1}{\sqrt{d_i d_j}}$). GAT uses **anisotropic** aggregation: neighbor messages are weighted by dynamic, feature-dependent self-attention coefficients $\alpha_{i,j}$ learned end-to-end.

**Q2: Write out the GAT attention coefficient formula.**
**A2:** $\alpha_{i,j} = \frac{\exp\left( \text{LeakyReLU}\left( \mathbf{a}^T [W h_i \parallel W h_j] \right) \right)}{\sum_{k \in \mathcal{N}_i} \exp\left( \text{LeakyReLU}\left( \mathbf{a}^T [W h_i \parallel W h_k] \right) \right)}$.

**Q3: How does Multi-Head Attention work in GAT for intermediate layers vs. the final output layer?**
**A3:** In **intermediate layers**, outputs from $K$ independent attention heads are **concatenated**: $h_i' = \|_{k=1}^K \sigma\left( \sum \alpha_{i,j}^k W^k h_j \right) \in \mathbb{R}^{K \cdot F'}$. In the **final prediction layer**, multi-head outputs are **averaged**: $h_i^{\text{out}} = \sigma\left( \frac{1}{K} \sum_{k=1}^K \sum \alpha_{i,j}^k W^k h_j \right) \in \mathbb{R}^C$.

**Q4: Does GAT require expensive matrix inversions or global graph Laplacian decompositions?**
**A4:** No. GAT operates purely on local 1-hop edge pairs $(i, j)$, requiring $O(|V| \cdot F \cdot F' + |E| \cdot F')$ time complexity, making it computationally parallelizable on GPUs.

**Q5: What limitation of GAT led to the development of GATv2?**
**A5:** GAT computes score $a^T [W h_i \parallel W h_j] = a_1^T W h_i + a_2^T W h_j$. Because linear projections are applied before concatenation, the attention ranking of neighbors $j$ is strictly monotonic with respect to target node $i$ (static attention). GATv2 applies $W$ after concatenation to achieve dynamic attention.
