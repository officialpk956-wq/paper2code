# Neural Collaborative Filtering (NCF)

## 1. Overview
Neural Collaborative Filtering (NCF), introduced in 2017 by Xiangnan He, Lizi Liao, Hanwang Zhang, Liqiang Nie, Xia Hu, and Tat-Seng Chua (National University of Singapore), addressed a fundamental representation bottleneck in traditional Matrix Factorization: **the linear dot product limitation**. Classical Matrix Factorization models user-item interactions using the dot product of latent vectors $\mathbf{p}_u^T \mathbf{q}_i$. Xiangnan He et al. proved mathematically and empirically that a linear dot product fails to capture complex user-item interaction topologies, leading to severe ranking errors in low-dimensional spaces. NCF replaced or augmented the dot product with a non-linear **Multi-Layer Perceptron (MLP)**. By unifying Generalized Matrix Factorization (GMF) and Multi-Layer Perceptron (MLP) into a dual-stream framework named **NeuMF (Neural Matrix Factorization)**, NCF achieved superior implicit feedback recommendation accuracy across benchmark datasets.

:::note
NCF concept: "Replace simple linear dot product $p_u^T q_i$ with non-linear neural network layers. NeuMF combines Generalized Matrix Factorization (GMF) and Multi-Layer Perceptron (MLP) dual streams."
:::

## 2. Historical Context
In 2017, linear Matrix Factorization (MF) dominated collaborative filtering. However, linear inner products satisfy the Triangle Inequality in latent space, restricting vector geometry.

Xiangnan He et al. presented a famous counter-example demonstrating that linear dot products cannot preserve user similarity orderings across 4 users ($u_1, u_2, u_3, u_4$) in 2D latent space. They introduced Neural Collaborative Filtering, replacing the fixed linear dot product operator $\sum p_{u,f} \cdot q_{i,f}$ with a trainable neural network that learns arbitrary non-linear user-item interactions from implicit feedback data (clicks, views, purchases).

## 3. Problem It Solves
NCF addresses two core representation weaknesses of classical Matrix Factorization:
1. **The Linear Dot Product Bottleneck:** Linear inner products cannot model complex non-linear interaction patterns in low-dimensional spaces. NCF uses a multi-layer perceptron (MLP) to learn non-linear feature interactions.
2. **Implicit Feedback Optimization:** Optimizes for binary implicit feedback (1 for interaction, 0 for non-interaction) using Binary Cross-Entropy (BCE) loss with negative sampling rather than MSE loss.
3. **Linear & Non-Linear Stream Dual Fusion:** NeuMF fuses linear dot products (GMF) and non-linear deep representations (MLP) into a single unified architecture.

## 4. Architecture Diagram Data
Below is the NeuMF (Neural Matrix Factorization) architecture combining GMF and MLP streams.

```text
       [ User ID u ]                             [ Item ID i ]
             |                                         |
             +--------------------+--------------------+
                                  |
                                  v
       +===================================================================+
       | DUAL EMBEDDING LAYER                                              |
       | GMF Embeddings: p_u^G (k), q_i^G (k)                              |
       | MLP Embeddings: p_u^M (d), q_i^M (d)                              |
       +===================================================================+
                                  |
         +------------------------+------------------------+
         |                                                 |
         v                                                 v
  +===========================+                     +===========================+
  | GMF STREAM                |                     | MLP STREAM                |
  | - Element-wise Product    |                     | - Concatenation           |
  |   phi^G = p_u^G (o) q_i^G |                     |   [p_u^M, q_i^M]          |
  | - Output: (B, k)          |                     | - Multi-Layer Perceptron  |
  |                           |                     |   phi^M = MLP(Concat)     |
  +===========================+                     +===========================+
         |                                                 |
         +------------------------+------------------------+
                                  |
                                  v
             +============================================+
             | NEUMF CONCATENATION & PREDICTION LAYER     |
             | phi^NeuMF = Concat( phi^G, phi^M )         |
             | y_hat = Sigmoid( h^T * phi^NeuMF )         |
             +============================================+
```

## 5. Layer-by-Layer Breakdown

**1. Dual Embedding Lookup Layer:**
- **GMF Stream Embeddings:** User vector $p_u^G \in \mathbb{R}^k$, Item vector $q_i^G \in \mathbb{R}^k$.
- **MLP Stream Embeddings:** User vector $p_u^M \in \mathbb{R}^d$, Item vector $q_i^M \in \mathbb{R}^d$.

**2. GMF (Generalized Matrix Factorization) Stream:**
- Computes element-wise Hadamard product:
  $$\phi^G = p_u^G \odot q_i^G \in \mathbb{R}^k$$

**3. MLP (Multi-Layer Perceptron) Stream:**
- Concatenates user and item embeddings: $a^{(0)} = [p_u^M, q_i^M] \in \mathbb{R}^{2d}$.
- Passes through $L$ hidden layers with ReLU activations:
  $$\phi^M = a^{(L)} = \text{ReLU}\left( W_L \dots \text{ReLU}(W_1 a^{(0)} + b_1) \dots + b_L \right)$$

**4. NeuMF Output Layer:**
- Concatenates GMF and MLP outputs: $\phi^{\text{NeuMF}} = \left[ \phi^G, \phi^M \right]$.
- Linear projection to scalar prediction score:
  $$\hat{y}_{u,i} = \sigma \left( \mathbf{h}^T \left[ \phi^G, \phi^M \right] \right)$$

## 6. Tensor Flow Walkthrough
Let's trace tensors through NeuMF for batch size $B=1024$, GMF dim $k=32$, MLP embedding dim $d=32$, MLP hidden dimensions $[64, 32, 16]$.

1. **Embedding Lookups:**
   - GMF User $p_u^G$: `(1024, 32)`, GMF Item $q_i^G$: `(1024, 32)`
   - MLP User $p_u^M$: `(1024, 32)`, MLP Item $q_i^M$: `(1024, 32)`
2. **GMF Stream Pass:**
   - Hadamard Product $\phi^G = p_u^G \odot q_i^G \to$ `(1024, 32)`
3. **MLP Stream Pass:**
   - Concat Embeddings: `(1024, 64)` $\xrightarrow{\text{MLP Layers}} \phi^M$: `(1024, 16)`
4. **NeuMF Concat & Prediction:**
   - Concat $[\phi^G, \phi^M] \to$ `(1024, 48)`
   - Linear Head $\to \sigma(\mathbf{h}^T \phi^{\text{NeuMF}}) \to$ Interaction Probabilities: `(1024, 1)`.

## 7. Mathematical Foundations

### 1. Mathematical Proof of Dot Product Limitation
Let $p_1, p_2, p_3, p_4$ be 2D latent vectors for users $u_1, u_2, u_3, u_4$.
If historical interactions dictate that:
- $u_1$ and $u_2$ are similar ($p_1^T p_2$ high)
- $u_1$ and $u_3$ are similar ($p_1^T p_3$ high)
- Then in 2D geometric space, $p_2$ and $p_3$ MUST be close together ($p_2^T p_3$ high).

If a 4th user $u_4$ is similar to $u_2$ and $u_3$, but dissimilar to $u_1$, linear dot products CANNOT place $p_4$ in 2D space without violating prior similarities. Non-linear MLPs resolve this topological conflict.

### 2. Binary Cross-Entropy Objective with Negative Sampling
NCF treats implicit feedback recommendation as binary classification. The objective function is:

$$\mathcal{L}_{\text{NCF}} = -\sum_{(u, i) \in \mathcal{Y} \cup \mathcal{Y}^-} \left( y_{u,i} \log \hat{y}_{u,i} + (1 - y_{u,i}) \log(1 - \hat{y}_{u,i}) \right)$$

where $\mathcal{Y}$ is positive interaction pairs ($y=1$), and $\mathcal{Y}^-$ is randomly sampled unobserved negative interaction pairs ($y=0$).

## 8. Training Procedure
- Sample 1 positive user-item pair $(u, i)$ and $N=4$ negative pairs $(u, j)$ where $j$ is an unobserved item.
- Perform forward pass through GMF and MLP streams.
- Minimize Binary Cross-Entropy loss $\mathcal{L}_{\text{NCF}}$ using Adam optimizer.
- Pre-training strategy: Optionally pre-train GMF and MLP streams independently, then initialize NeuMF parameters.

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of **NeuMF (Neural Collaborative Filtering)**.

```python
import torch
import torch.nn as nn

class NeuMF(nn.Module):
    """ Neural Matrix Factorization (NeuMF) combining GMF and MLP """
    def __init__(self, num_users, num_items, gmf_dim=32, mlp_embed_dim=32, mlp_hidden_dims=[64, 32, 16]):
        super().__init__()
        # 1. GMF EMBEDDINGS
        self.user_embed_gmf = nn.Embedding(num_users, gmf_dim)
        self.item_embed_gmf = nn.Embedding(num_items, gmf_dim)
        
        # 2. MLP EMBEDDINGS
        self.user_embed_mlp = nn.Embedding(num_users, mlp_embed_dim)
        self.item_embed_mlp = nn.Embedding(num_items, mlp_embed_dim)
        
        # MLP Layers
        mlp_layers = []
        in_dim = mlp_embed_dim * 2
        for h_dim in mlp_hidden_dims:
            mlp_layers.append(nn.Linear(in_dim, h_dim))
            mlp_layers.append(nn.ReLU())
            in_dim = h_dim
        self.mlp = nn.Sequential(*mlp_layers)
        
        # Final NeuMF Linear Projection Head
        final_in_dim = gmf_dim + mlp_hidden_dims[-1]
        self.prediction_head = nn.Linear(final_in_dim, 1)
        
        # Initializations
        nn.init.normal_(self.user_embed_gmf.weight, std=0.01)
        nn.init.normal_(self.item_embed_gmf.weight, std=0.01)
        nn.init.normal_(self.user_embed_mlp.weight, std=0.01)
        nn.init.normal_(self.item_embed_mlp.weight, std=0.01)

    def forward(self, user_ids, item_ids):
        """
        user_ids: (B,)
        item_ids: (B,)
        """
        # GMF Stream
        p_u_gmf = self.user_embed_gmf(user_ids) # (B, k)
        q_i_gmf = self.item_embed_gmf(item_ids) # (B, k)
        phi_gmf = p_u_gmf * q_i_gmf              # (B, k)
        
        # MLP Stream
        p_u_mlp = self.user_embed_mlp(user_ids) # (B, d)
        q_i_mlp = self.item_embed_mlp(item_ids) # (B, d)
        phi_mlp = self.mlp(torch.cat([p_u_mlp, q_i_mlp], dim=-1)) # (B, mlp_hidden_dims[-1])
        
        # Fuse GMF + MLP Streams
        neumf_vector = torch.cat([phi_gmf, phi_mlp], dim=-1)
        logits = self.prediction_head(neumf_vector)
        probs = torch.sigmoid(logits)
        return probs

if __name__ == "__main__":
    B, num_users, num_items = 1024, 50000, 10000
    neumf_model = NeuMF(num_users=num_users, num_items=num_items, gmf_dim=32, mlp_embed_dim=32)
    
    users = torch.randint(0, num_users, (B,))
    items = torch.randint(0, num_items, (B,))
    
    probs = neumf_model(users, items)
    
    print(f"NeuMF Interaction Probability Output Shape: {probs.shape}")
    assert probs.shape == (B, 1)
    print("NCF / NeuMF verification successful!")
```

## 10. Strengths
- **Breaks Dot Product Limit:** Non-linear MLP captures complex interaction topologies.
- **Dual Stream Architecture (NeuMF):** Retains linear dot-product strengths (GMF) while adding deep non-linear capacity (MLP).
- **Implicit Feedback Native:** Optimized for binary interactions using BCE loss with negative sampling.

## 11. Weaknesses
- **Increased Serving Latency:** Concatenating user and item embeddings into an MLP prevents fast separate indexing during retrieval (addressed by Two-Tower Models).

## 12. Research Evolution
NCF established neural collaborative filtering, directly influencing **Two-Tower Candidate Retrieval**, **NGCF (Neural Graph Collaborative Filtering)**, and **LightGCN**.

## 13. Interview Questions

**Q1: What is the fundamental flaw of the linear dot product in classical Matrix Factorization according to the NCF paper?**
**A1:** The linear dot product $p_u^T q_i$ satisfies geometric triangle constraints in latent space. In low dimensions, it cannot represent complex non-linear user similarity topologies (e.g., placing a 4th user $u_4$ similar to $u_2$ and $u_3$ but dissimilar to $u_1$). Non-linear MLPs resolve these geometric conflicts.

**Q2: What is NeuMF, and how does it combine GMF and MLP?**
**A2:** NeuMF (Neural Matrix Factorization) is a dual-stream architecture. The **GMF Stream** computes element-wise Hadamard products $p_u^G \odot q_i^G$. The **MLP Stream** passes concatenated embeddings $[p_u^M, q_i^M]$ through deep FC layers. NeuMF concatenates both stream outputs before passing them to a final Sigmoid prediction layer.

**Q3: How does NCF perform negative sampling for implicit feedback training?**
**A3:** For every positive user-item interaction $(u, i)$ ($y=1$), NCF randomly samples $N$ unobserved items $(u, j)$ ($y=0$, typically $N \in [4, 8]$) that the user has not interacted with.

**Q4: Write out the NeuMF output prediction formula.**
**A4:** $\hat{y}_{u,i} = \sigma \left( \mathbf{h}^T \left[ (p_u^G \odot q_i^G), \; \text{MLP}([p_u^M, q_i^M]) \right] \right)$.

**Q5: Why can't NCF's MLP stream be easily used for fast Approximate Nearest Neighbor (ANN) retrieval over 10 million items?**
**A5:** In the MLP stream, user and item embeddings are concatenated at layer 0 and passed through non-linear layers together. Item vectors cannot be pre-computed independently of the user vector, requiring executing the full MLP for all 10 million items for every query (solved by Two-Tower models).
