# BigGAN

## 1. Overview
BigGAN, introduced in 2018 by Andrew Brock, Jeff Donahue, and Karen Simonyan (DeepMind), demonstrated that scaling GANs in parameter count, batch size, and channel capacity dramatically improves class-conditional image generation quality and diversity. Trained on ImageNet at resolutions up to $512 \times 512$, BigGAN scaled model parameters to 158M and batch sizes to **2048** (8x larger than prior models), achieving an unprecedented Inception Score (IS) of 166.4 and Frechet Inception Distance (FID) of 7.4. BigGAN introduced three major technical innovations:
1. **Hierarchical Latent Spaces (Shared Latent Embeddings):** Latent noise vector $z$ is split into chunks and fed into multiple resolution blocks via class-conditional BatchNorm.
2. **The Truncation Trick:** Enables explicit user trade-off between sample fidelity and sample variety by sampling $z$ from a truncated Gaussian at inference time.
3. **Orthogonal Regularization:** Enforces strict 1-Lipschitz condition on weights to prevent generator collapse at huge scales.

:::tip
BigGAN's lesson: "GANs benefit tremendously from scale. Increasing batch size by 8x and channel count by 2x, combined with Orthogonal Regularization and the Truncation Trick, unlocks state-of-the-art class-conditional generation."
:::

## 2. Historical Context
In 2018, GANs were viewed as difficult to scale compared to autoregressive models or VAEs. Training GANs with large batch sizes often caused catastrophic training collapse mid-way through optimization.

Andrew Brock et al. at DeepMind set out to test the scaling boundaries of class-conditional GANs on ImageNet $128 \times 128, 256 \times 256,$ and $512 \times 512$. They discovered that expanding batch size from 256 to 2048 quadrupled training stability and performance, while doubling channel capacity boosted IS scores. To control training collapse at enormous scale, they engineered **Orthogonal Regularization** and introduced **Class-Conditional Projection Discriminators**.

## 3. Problem It Solves
BigGAN resolves three key bottlenecks in large-scale class-conditional GANs:
1. **Catastrophic Training Collapse at Large Scale:** Large-scale training causes singular values of generator weight matrices to explode. BigGAN introduces **Orthogonal Regularization** to enforce bounded spectral norms.
2. **Fidelity vs. Diversity Trade-Off:** Standard GANs cannot adjust sample quality post-training. BigGAN introduces **The Truncation Trick**, allowing users to trade sample diversity for higher perceptual sharpness.
3. **Class Conditioning Information Bottleneck:** Passing class vector $y$ only to the first layer limits multi-scale class modulation. BigGAN uses **Hierarchical $z$-split connections**, injecting $y$ into every residual block via Shared Class Embeddings.

      | Block 3 (16x16->32x32): Conditional BatchNorm( [z_2, Emb(y)] )        |

      +========================================================================+

## 5. Layer-by-Layer Breakdown

**1. Hierarchical Latent Splitting ($z$-split):**
- Latent noise $z \in \mathbb{R}^{128}$ is split into equal chunks $[z_0, z_1, z_2, z_3]$.
- $z_0$ is fed to the initial linear layer to form the base $4 \times 4$ spatial feature map.
- $z_1, z_2, z_3$ are concatenated with the Shared Class Embedding $\text{Emb}(y) \in \mathbb{R}^{128}$ and fed as conditioning inputs to **Class-Conditional BatchNorm (CBN)** layers at each resolution stage.

**2. Class-Conditional BatchNorm (CBN):**
- Standard BatchNorm normalizes features: $\hat{h} = \frac{h - \mu}{\sigma}$.
- CBN predicts scale $\gamma(c)$ and shift $\beta(c)$ parameters as a linear function of $[z_i, \text{Emb}(y)]$:
  $$\text{CBN}(h, c) = \gamma(c) \cdot \hat{h} + \beta(c)$$

**3. Projection Discriminator:**
- Uses Spectral Normalization on all layers.
- Incorporates class label $y$ via an inner product:
  $$D(x, y) = f_{\text{score}}(x) + \langle \phi(x), v_y \rangle$$
  where $\phi(x)$ is the final feature vector before classification, and $v_y$ is the class embedding.

## 6. Tensor Flow Walkthrough
Let's trace tensors through BigGAN for batch size $B=4$, noise $z \in \mathbb{R}^{128}$, $C=1000$ ImageNet classes, image size $64 \times 64 \times 3$.

1. **Latent Splitting:**
   - Noise $z$: `(4, 128)` $\to$ Chunks $z_0, z_1, z_2, z_3$ each `(4, 32)`.
   - Shared Class Embedding $\text{Emb}(y)$: `(4, 128)`.
   - Conditioning vectors for blocks: $[z_i, \text{Emb}(y)] \to$ `(4, 160)`.
2. **Generator ResNet Blocks:**
   - Linear Project $z_0 \to$ `(4, 512, 4, 4)`
   - ResBlock 1 ($4 \to 8$) + CBN([$z_1$, Emb]) $\to$ `(4, 512, 8, 8)`
   - ResBlock 2 ($8 \to 16$) + CBN([$z_2$, Emb]) $\to$ `(4, 256, 16, 16)`
   - ResBlock 3 ($16 \to 32$) + CBN([$z_3$, Emb]) $\to$ `(4, 128, 32, 32)`
   - ResBlock 4 ($32 \to 64$) + CBN([$z_3$, Emb]) $\to$ `(4, 64, 64, 64)`
   - Final Conv $\to$ Generated Image $G(z, y)$: `(4, 3, 64, 64)`.

## 7. Mathematical Foundations

### 1. The Truncation Trick
During training, noise is sampled from standard Gaussian $z \sim \mathcal{N}(0, \mathbf{I})$. During inference, $z$ is sampled from a **Truncated Gaussian** where values exceeding threshold $\psi$ are re-sampled:

$$z \sim \text{Truncated\_Gaussian}(\psi), \quad \text{where } |z_i| \le \psi$$

- **Small $\psi$ (e.g., $\psi = 0.04$):** High fidelity, crisp details, low diversity.
- **Large $\psi$ (e.g., $\psi = 1.0$):** High sample variety, lower fidelity.

```text
  Truncation Threshold Psi Effect:
  Psi = 1.0  ---> Wide distribution, max sample variety, potential visual artifacts.
  Psi = 0.5  ---> Optimal trade-off between realism and diversity.
  Psi = 0.1  ---> Extremely high photorealism, near-identical repeated outputs.
```

### 2. Orthogonal Regularization
To prevent singular values of weight matrices $W$ from exploding at large scale, BigGAN adds an Orthogonal Regularization term to the Generator loss:

$$\mathcal{L}_{\text{ortho}}(W) = \beta \left\| W^T W - \mathbf{I} \right\|_F^2$$

To prevent over-constraining the network, BigGAN removes diagonal elements from the penalty:

$$\mathcal{L}_{\text{ortho\_variant}}(W) = \beta \left\| W^T W \odot (\mathbf{1} - \mathbf{I}) \right\|_F^2$$

## 8. Training Procedure
- **Batch Size:** 2048 (achieved across 128 to 512 TPU v3 cores).
- **Hinge Loss:**
  $$\mathcal{L}_D = -\mathbb{E}_{(x,y)} [\min(0, -1 + D(x, y))] - \mathbb{E}_{(z,y)} [\min(0, -1 - D(G(z, y), y))]$$
  $$\mathcal{L}_G = -\mathbb{E}_{(z,y)} [D(G(z, y), y)]$$
- Optimizer: Adam ($\text{lr}_G = 0.0001, \text{lr}_D = 0.0004$).

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of **BigGAN's Truncated Gaussian Sampling** and **Class-Conditional Projection Discriminator**.

```python
import torch
import torch.nn as nn
from scipy.stats import truncnorm

def sample_truncated_noise(batch_size, z_dim, truncation=0.5, device="cpu"):
    """ Generates noise sampled from a Truncated Gaussian """
    # Generate truncated normal samples using scipy
    values = truncnorm.rvs(-truncation, truncation, size=(batch_size, z_dim))
    return torch.tensor(values, dtype=torch.float32, device=device)

class BigGANProjectionDiscriminator(nn.Module):
    """ Class-Conditional Projection Discriminator """
    def __init__(self, num_classes=1000, in_channels=3, ndf=64):
        super().__init__()
        self.class_emb = nn.Embedding(num_classes, ndf * 8)
        
        self.features = nn.Sequential(
            nn.Conv2d(in_channels, ndf, 4, 2, 1),
            nn.LeakyReLU(0.2, True),
            nn.Conv2d(ndf, ndf * 2, 4, 2, 1),
            nn.LeakyReLU(0.2, True),
            nn.Conv2d(ndf * 2, ndf * 4, 4, 2, 1),
            nn.LeakyReLU(0.2, True),
            nn.Conv2d(ndf * 4, ndf * 8, 4, 2, 1),
            nn.LeakyReLU(0.2, True)
        )
        self.linear_score = nn.Linear(ndf * 8, 1)

    def forward(self, x, labels):
        # x: (B, 3, 64, 64), labels: (B,)
        h = self.features(x)                  # (B, ndf*8, 4, 4)
        h_flat = torch.sum(h, dim=[2, 3])      # Global Sum Pool -> (B, ndf*8)
        
        # 1. Unconditional Real/Fake Score
        out_score = self.linear_score(h_flat) # (B, 1)
        
        # 2. Conditional Inner Product Score: <phi(x), Emb(y)>
        c_emb = self.class_emb(labels)         # (B, ndf*8)
        proj_score = torch.sum(h_flat * c_emb, dim=1, keepdim=True) # (B, 1)
        
        return out_score + proj_score

if __name__ == "__main__":
    B = 4
    num_classes = 1000
    disc = BigGANProjectionDiscriminator(num_classes=num_classes)
    
    trunc_z = sample_truncated_noise(B, z_dim=128, truncation=0.5)
    fake_imgs = torch.randn(B, 3, 64, 64)
    labels = torch.randint(0, num_classes, (B,))
    
    scores = disc(fake_imgs, labels)
    
    print(f"Truncated Noise Shape:  {trunc_z.shape}")
    print(f"Projection Score Shape: {scores.shape}")
    assert trunc_z.shape == (B, 128)
    assert scores.shape == (B, 1)
    print("BigGAN Truncation and Projection Discriminator verification successful!")
```

## 10. Strengths
- **Unrivaled Class-Conditional Quality:** Achieved state-of-the-art IS (166.4) and FID (7.4) on ImageNet.
- **The Truncation Trick:** Provides fine-grained user control over fidelity vs. diversity.
- **Hierarchical Conditioning:** $z$-split connections allow multi-scale class modulation.

## 11. Weaknesses
- **Enormous Compute Requirement:** Requires massive batch sizes (2048) and hundreds of TPU cores for training.

## 12. Research Evolution
BigGAN proved the scaling laws of generative adversarial networks, directly inspiring **StyleGAN2**, **SAGAN**, and **VQGAN**.

## 13. Interview Questions

**Q1: What is the Truncation Trick in BigGAN?**
**A1:** Sampling noise vector $z$ from a Truncated Gaussian ($|z_i| \le \psi$) at inference time rather than a standard Gaussian. Lowering threshold $\psi$ improves visual fidelity and perceptual sharpness at the cost of reduced sample variety.

**Q2: How does a Projection Discriminator incorporate class label $y$?**
**A2:** It computes an unconditioned score $f(x)$ plus the dot product between the pooled feature vector $\phi(x)$ and class embedding vector $v_y$: $D(x, y) = f(x) + \langle \phi(x), v_y \rangle$.

**Q3: What is Hierarchical $z$-split in BigGAN?**
**A3:** Splitting latent noise vector $z$ into multiple chunks $[z_0, z_1, \dots]$ and passing each chunk alongside shared class embedding $\text{Emb}(y)$ to Class-Conditional BatchNorm layers at different resolution blocks of the Generator.

**Q4: Why does BigGAN use Orthogonal Regularization?**
**A4:** Large-scale training causes weight matrix singular values to explode, leading to sudden training collapse. Orthogonal Regularization $\beta \|W^T W \odot (\mathbf{1} - \mathbf{I})\|_F^2$ prevents parameter explosion.

**Q5: Compare BigGAN with DCGAN regarding batch size and parameter scale.**
**A5:** DCGAN used batch size 64 and ~10M parameters. BigGAN scaled batch size to 2048 ($8\times$ increase) and parameters to 158M, proving that GAN performance scales predictably with compute.
