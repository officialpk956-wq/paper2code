# GPT-4V

## 1. Overview
GPT-4V (GPT-4 with Vision), introduced in late 2023 by OpenAI, set the benchmark for **General-Purpose Multimodal Intelligence**. While previous vision-language models were trained on specific academic tasks (like COCO captioning or VQA), GPT-4V extended GPT-4's massive autoregressive language capabilities to accept native visual inputs (single images, multi-image prompts, charts, UI screenshots, handwritten documents, mathematical diagrams). OpenAI designed GPT-4V to process image inputs via a specialized **Visual Encoder Subsystem** that splits input images into high-resolution patches, converts them into visual token sequences, and injects them alongside text BPE tokens into GPT-4's massive Transformer backbone. GPT-4V demonstrated unprecedented spatial reasoning, visual math problem solving, OCR parsing across 50+ languages, and GUI agent interaction capabilities.

:::note
GPT-4V core concept: "Native visual token injection into GPT-4's autoregressive Transformer backbone, supporting multi-image reasoning, visual spatial math, and GUI agent interactions."
:::

## 2. Historical Context
Prior to September 2023, public multimodal models (like LLaVA and BLIP-2) were restricted to low-resolution single-image inputs ($224 \times 224$ or $336 \times 336$) and struggled with dense text, complex mathematical notation, or multi-step visual reasoning.

OpenAI integrated vision directly into GPT-4. By using dynamic image tiling (splitting large images into $512 \times 512$ tile grids) and pre-training on trillions of interleaved text-image web pages, GPT-4V established the industry standard for multimodal frontier models.

## 3. Problem It Solves
GPT-4V resolves three primary operational limits in visual AI:
1. **Single-Image Context Restriction:** Supports multi-image reasoning (e.g., comparing 5 different medical X-rays or analyzing multi-page PDF documents).
2. **Low-Resolution Visual Degradation:** Uses dynamic image tiling ($512 \times 512$ grid tiles) to process ultra-high-resolution images without downsampling artifacts.
3. **Domain Specialization Barrier:** Replaces narrow domain-specific models (OCR parsers, chart plotters, document readers) with a single general-purpose multimodal engine.

## 5. Layer-by-Layer Breakdown

**1. Dynamic Image Tiling & Rescaling Subsystem:**
- Low-Resolution Mode: Rescales image to $512 \times 512$, generating 170 visual tokens.
- High-Resolution Mode: Creates a $512 \times 512$ low-res overview tile, then crops original image into $512 \times 512$ detail tiles. Each detail tile adds 170 visual tokens (+ 85 base tokens).

**2. Visual Feature Encoder:**
- ViT-style encoder mapping each $512 \times 512$ tile to 170 visual token embeddings $H_{\text{tile}} \in \mathbb{R}^{170 \times d_{\text{gpt4}}}$.

**3. GPT-4 Autoregressive Transformer Core:**
- Concatenates visual tokens with text prompt tokens.
- Executes causal multi-head self-attention over the unified sequence.

## 6. Tensor Flow Walkthrough
Let's trace tensors through GPT-4V for batch size $B=1$, high-res image producing 4 detail tiles + 1 overview tile = 5 tiles (850 visual tokens), text prompt length $L=50$.

1. **Tile Generation & Encoding:**
   - 5 Tiles of $512 \times 512 \xrightarrow{\text{Visual Encoder}} H_{\text{vis}}$: `(1, 850, 4096)`
2. **Sequence Assembly:**
   - Text Tokens $T_{\text{prompt}}$: `(1, 50, 4096)`
   - Concat $[H_{\text{vis}} \parallel T_{\text{prompt}}] \to X_{\text{input}}$: `(1, 900, 4096)`
3. **GPT-4 Forward Pass:**
   - Pass through GPT-4 Transformer layers $\to$ Logits: `(1, 900, 100000)` $\to$ Generate answer autoregressively.

## 7. Mathematical Foundations

### 1. High-Resolution Tile Token Count Formula
Let $W, H$ be image width and height. The image is scaled to fit within a $2048 \times 2048$ bounding box while maintaining aspect ratio, then divided into $N_{\text{tiles}}$ of size $512 \times 512$.

The total visual token count $N_{\text{tokens}}$ is:

$$N_{\text{tokens}} = 85 + 170 \times N_{\text{tiles}}$$

where 85 is base overhead and 170 is token cost per $512 \times 512$ tile.

### 2. Autoregressive Multimodal Joint Likelihood
Given $K$ input images $\{I_1, \dots, I_K\}$ and text prompt $X$, GPT-4V maximizes the autoregressive log-likelihood of output sequence $Y = (y_1, \dots, y_M)$:

$$\mathcal{L}_{\text{GPT-4V}} = \sum_{m=1}^M \log P_{\text{GPT-4}}\left( y_m \;\middle|\; y_{<m}, \; \text{VisEnc}(I_1), \dots, \text{VisEnc}(I_K), \; X \right)$$

## 8. Training Procedure
- **Pre-Training Phase:** Pre-trained on massive internet datasets containing trillions of interleaved text, image, document, and video tokens using causal language modeling.
- **Instruction & RLHF Tuning Phase:** Fine-tuned via Reinforcement Learning from Human Feedback (RLHF) to ensure safety, reduce visual hallucinations, and align visual assistance with human preferences.

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of **GPT-4V's Dynamic Image Tiling and Visual Tokenization Pipeline**.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class GPT4VVisualTokenizer(nn.Module):
    """ Dynamic Image Tiling & Visual Tokenizer for GPT-4V """
    def __init__(self, tile_size=512, tokens_per_tile=170, embed_dim=4096):
        super().__init__()
        self.tile_size = tile_size
        self.tokens_per_tile = tokens_per_tile
        self.embed_dim = embed_dim
        
        # Simulated Tile Encoder (maps 512x512 tile -> 170 tokens in embed_dim)
        self.tile_encoder = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=32, stride=32), # (B, 64, 16, 16) -> 256 patches
            nn.Flatten(2)
        )
        self.proj = nn.Linear(256, tokens_per_tile * embed_dim)

    def forward(self, image):
        """ image: (3, H, W) """
        _, H, W = image.shape
        
        # Calculate number of tiles
        num_h_tiles = (H + self.tile_size - 1) // self.tile_size
        num_w_tiles = (W + self.tile_size - 1) // self.tile_size
        num_tiles = num_h_tiles * num_w_tiles + 1 # +1 for low-res overview tile
        
        # Simulate encoding each tile
        tile_embeds = []
        for _ in range(num_tiles):
            dummy_tile = torch.randn(1, 3, self.tile_size, self.tile_size)
            feat = self.tile_encoder(dummy_tile) # (1, 64, 256)
            tokens = self.proj(feat.mean(dim=1)).view(1, self.tokens_per_tile, self.embed_dim)
            tile_embeds.append(tokens)
            
        total_vis_tokens = torch.cat(tile_embeds, dim=1) # (1, num_tiles * 170, 4096)
        return total_vis_tokens

if __name__ == "__main__":
    tokenizer = GPT4VVisualTokenizer(tile_size=512, tokens_per_tile=170, embed_dim=4096)
    
    # 1024 x 1536 Image (2x3 = 6 detail tiles + 1 overview = 7 tiles)
    image = torch.randn(3, 1024, 1536)
    vis_tokens = tokenizer(image)
    
    print(f"GPT-4V Visual Tokens Output Shape: {vis_tokens.shape}")
    assert vis_tokens.shape == (1, 7 * 170, 4096)
    print("GPT-4V verification successful!")
```

## 13. Interview Questions

**Q1: How does GPT-4V process high-resolution input images without downsampling visual detail?**
**A1:** GPT-4V uses **Dynamic Image Tiling**. It generates a $512 \times 512$ low-resolution overview tile, and crops the high-res image into $512 \times 512$ detail tiles, encoding each tile into 170 visual tokens.

**Q2: Write out the total token cost formula for an image in GPT-4V.**
**A2:** $N_{\text{tokens}} = 85 + 170 \times N_{\text{tiles}}$, where $N_{\text{tiles}}$ is the number of $512 \times 512$ detail tiles.

**Q3: Can GPT-4V process multiple images in a single prompt?**
**A3:** Yes. GPT-4V supports multi-image inputs by concatenating visual token sequences for all images alongside text tokens in its autoregressive context window.

**Q4: How does RLHF improve GPT-4V's visual safety?**
**A4:** RLHF aligns the model to refuse hazardous visual queries (such as identifying private individuals, solving CAPTCHAs, or interpreting medical scans for self-diagnosis).

**Q5: Compare GPT-4V with LLaVA 1.5.**
**A5:** LLaVA 1.5 is an open-source 7B/13B model operating at $336 \times 336$ single-image resolution ($N=576$). GPT-4V is a frontier model operating at multi-tile $512 \times 512$ resolution, supporting multi-image prompts and complex spatial reasoning.
