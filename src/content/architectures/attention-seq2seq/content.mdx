# Attention Seq2Seq

## 1. Overview
The Attention Sequence-to-Sequence (Seq2Seq) model, introduced by Dzmitry Bahdanau et al., represents a paradigm shift in how neural networks handle variable-length sequences. Prior to this innovation, standard Seq2Seq models relied on an encoder to compress the entire input sequence into a single, fixed-length "context vector," which a decoder then used to generate the output. This approach created an information bottleneck, particularly crippling for long sentences. The Attention mechanism solves this by allowing the decoder to dynamically "look back" at the encoder's hidden states at every step of generation. Instead of a single static context vector, the decoder computes a set of *attention weights*—a probability distribution over the input sequence—highlighting which source words are most relevant to the word currently being generated. This dynamic alignment allows the model to focus on the right parts of the input at the right time, drastically improving performance on tasks like machine translation, text summarization, and speech recognition, and laying the groundwork for the modern Transformer architecture.

:::tip
Attention not only improves performance but also provides interpretability. By visualizing the attention weights, you can see exactly which input words the model focused on when generating a specific output word.
:::

## 2. Historical Context
In 2014, Sutskever et al. and Cho et al. introduced the foundational Encoder-Decoder Seq2Seq architecture, which achieved impressive results in machine translation by using RNNs to map inputs to outputs via a fixed-length vector. However, researchers quickly noticed a severe degradation in performance as input sentences grew longer; forcing a 50-word sentence into the same size vector as a 5-word sentence inevitably caused information loss. In 2015, Dzmitry Bahdanau, Kyunghyun Cho, and Yoshua Bengio published "Neural Machine Translation by Jointly Learning to Align and Translate," proposing the additive (or Bahdanau) attention mechanism. They argued that translation requires both alignment (mapping words across languages) and translation, and that these should be learned jointly. Their model shattered previous benchmarks, particularly on long sentences, and proved that soft, differentiable attention was the key to unlocking the true potential of sequence models. This paper is widely considered one of the most influential in the history of deep learning for NLP.

## 3. Problem It Solves
The core problem solved by Attention Seq2Seq is the "information bottleneck" of the basic Encoder-Decoder architecture. In a standard Seq2Seq model, the encoder processes the input and produces a single hidden state (usually the final state) that must summarize the entire sequence. The decoder relies entirely on this single vector to generate the whole output. For long sequences, this vector simply cannot hold enough information, leading the decoder to "forget" details from the beginning of the input. Attention solves this by bypassing the bottleneck. The encoder now provides *all* its intermediate hidden states to the decoder. At each decoding step, the decoder calculates a relevance score (attention weight) for each encoder state based on its current internal state. It then takes a weighted sum of the encoder states to create a dynamic, custom-tailored context vector for that specific step. This means the model can dynamically focus on the subject when translating the subject, the verb when translating the verb, and so on, regardless of sentence length.

## 4. Architecture Diagram Data

```text
                                ^    ^    ^

                              +-+-++-+-++-+-+

                              +-^-++-^-++-^-+
                                |    |    |

                     |               |               |
               Context Vector  Context Vector  Context Vector
                    c_1             c_2             c_3

                     |               |               |
                +----+----+     +----+----+     +----+----+
                | Weighted|     | Weighted|     | Weighted|
 Attention      | Sum     |     | Sum     |     | Sum     |
 Mechanism      +----^----+     +----^----+     +----^----+
                     |               |               |
          [a_11, a_12, a_13] [a_21, a_22, a_23] [a_31, a_32, a_33]  <- Alignment Scores
                     |               |               |
             +-------+-------+-------+-------+-------+
             |               |               |
             |               |               |
        +----v----+     +----v----+     +----v----+
        |   h_1   |     |   h_2   |     |   h_3   |  <- Encoder Hidden States
        +----^----+     +----^----+     +----^----+
             |               |               |
           Input 1         Input 2         Input 3
             x_1             x_2             x_3
```
**Components:**
- `x_i`: Input tokens.
- `h_j`: Encoder hidden states (usually from a Bi-RNN).
- `a_ij`: Attention weights (alignment scores) between decoder step `i` and encoder step `j`.
- `c_i`: Dynamic context vector generated for decoder step `i`.
- `s_i`: Decoder hidden state at step `i`.
- `y_i`: Output token at step `i`.

## 5. Layer-by-Layer Breakdown
The Attention Seq2Seq model consists of three tightly integrated components: the Encoder, the Attention Mechanism, and the Decoder.
1. **The Encoder**: Typically a Bi-directional RNN (like a Bi-LSTM or Bi-GRU). It processes the input sequence $x = (x_1, \dots, x_T)$ and generates a sequence of annotations or hidden states $h = (h_1, \dots, h_T)$. Because it is bidirectional, each $h_j$ contains information about both the preceding and following words, providing a strong contextual representation of the $j$-th word.
2. **The Attention Mechanism**: At each decoder time step $i$, a small feedforward neural network calculates an "energy" score $e_{ij}$ between the previous decoder state $s_{i-1}$ and every encoder state $h_j$. These scores are passed through a softmax function to create attention weights $\alpha_{ij}$, which sum to 1. The context vector $c_i$ is then computed as the weighted sum of all encoder states: $c_i = \sum_{j=1}^T \alpha_{ij} h_j$.
3. **The Decoder**: Typically a unidirectional RNN. At step $i$, it receives the previous output $y_{i-1}$, the previous hidden state $s_{i-1}$, and the dynamically generated context vector $c_i$. It uses these to update its hidden state to $s_i$ and generate the predicted output token $y_i$. By having access to $c_i$, the decoder is directly looking at the most relevant parts of the source sentence while generating the current word.

:::warning
The attention mechanism introduces an $O(T_x \times T_y)$ computational complexity, where $T_x$ is input length and $T_y$ is output length, as scores must be calculated for every input-output pair.
:::

## 6. Tensor Flow Walkthrough
Let's trace the tensor shapes for a single step of the decoder.
- `B`: Batch size
- `T`: Source sequence length
- `H`: Encoder hidden dimension (per direction, so $2H$ total for Bi-RNN)
- `D`: Decoder hidden dimension
- `E`: Embedding dimension

1. **Encoder Outputs (`encoder_out`)**: Shape `(B, T, 2H)`. Contains all source hidden states $h$.
2. **Previous Decoder State (`s_prev`)**: Shape `(B, D)`. The decoder state from step $i-1$.
3. **Attention Energy Calculation**: 
   - Expand `s_prev` to `(B, T, D)`.
   - Concatenate/Add with `encoder_out` and pass through a Linear layer + Tanh + Linear to get energies.
   - Output `energy`: `(B, T, 1)`.
4. **Attention Weights (`alpha`)**: `F.softmax(energy, dim=1)`
   - Output `alpha`: `(B, T, 1)`. Probabilities over the source sequence.
5. **Context Vector (`c_i`)**: Batch matrix multiplication of `alpha` and `encoder_out` or sum over sequence dimension: `torch.sum(alpha * encoder_out, dim=1)`
   - Output `c_i`: `(B, 2H)`. The dynamic context vector for the current step.
6. **Decoder Input (`dec_in`)**: Concatenate embedded previous token `y_emb` `(B, E)` with context `c_i` `(B, 2H)`.
   - Shape: `(B, E + 2H)`.
7. **Decoder RNN Step**: `rnn_cell(dec_in, s_prev)`
   - Output `s_i`: `(B, D)`. The new decoder state.
8. **Output Projection**: `linear(s_i)` -> Shape `(B, Vocab_Size)`.

## 7. Mathematical Foundations
The Bahdanau (Additive) Attention mechanism is defined by the following core equations. At decoding step $i$:

**1. Alignment Model (Energy Calculation):**
$$ e_{ij} = v_a^\top \tanh(W_a s_{i-1} + U_a h_j) $$
- $e_{ij}$: The unnormalized alignment score (energy) indicating how well the input at position $j$ matches the output at position $i$.
- $s_{i-1}$: The hidden state of the decoder just before emitting $y_i$.
- $h_j$: The annotation (hidden state) of the encoder at position $j$.
- $W_a, U_a, v_a$: Learnable weight matrices and vector of the attention feedforward network.

**2. Attention Weights:**
$$ \alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k=1}^{T_x} \exp(e_{ik})} $$
- $\alpha_{ij}$: The normalized attention weight. The softmax ensures that $\sum_j \alpha_{ij} = 1$. This represents the probability that the decoder should focus on source word $j$.

**3. Context Vector:**
$$ c_i = \sum_{j=1}^{T_x} \alpha_{ij} h_j $$
- $c_i$: The context vector for decoding step $i$, calculated as the expected value (weighted sum) of all encoder annotations based on the attention distribution.

**4. Decoder State Update:**
$$ s_i = f(s_{i-1}, y_{i-1}, c_i) $$
- The decoder updates its state using the previous state, the previous emitted word, and the newly computed context vector $c_i$. $f$ is typically a GRU or LSTM cell.

## 8. Training Procedure
Training an Attention Seq2Seq model typically uses Teacher Forcing. 
1. **Forward Pass**: The input sequence is passed through the encoder to obtain all hidden states $h$. The decoder is then unrolled step-by-step. During training, instead of feeding the decoder's own prediction back into itself as the next input ($y_{i-1}$), we use the actual ground truth token from the target sequence (Teacher Forcing). At each step, the attention weights are calculated, the context vector is formed, and the decoder produces a probability distribution over the vocabulary for the next word.
2. **Loss Function**: The standard loss function is the cross-entropy loss between the predicted vocabulary distributions and the true target sequence tokens, summed across all time steps of the output sequence.
3. **Backpropagation**: Gradients flow backward from the loss through the decoder, through the attention mechanism (updating the alignment model weights $W_a, U_a, v_a$), and finally through the encoder. Because attention connects the decoder directly to every encoder state, the gradient path is much shorter than in a standard Seq2Seq model, significantly alleviating the vanishing gradient problem and allowing for stable training on long sequences.
4. **Optimization**: Optimizers like Adam are used to update the weights. To stabilize training, gradient clipping is frequently employed to prevent exploding gradients.

## 9. PyTorch Implementation
Here is a minimal, robust implementation of Bahdanau Attention and a Decoder step.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class BahdanauAttention(nn.Module):
    def __init__(self, hidden_size: int):
        super(BahdanauAttention, self).__init__()
        # W_a and U_a from the math formula
        self.Wa = nn.Linear(hidden_size, hidden_size)
        self.Ua = nn.Linear(hidden_size, hidden_size)
        # v_a vector
        self.va = nn.Linear(hidden_size, 1)

    def forward(self, query: torch.Tensor, keys: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
        # query shape: (B, D) -> (B, 1, D) for broadcasting
        # keys shape: (B, T, H)
        query = query.unsqueeze(1)
        
        # Calculate energy: e_ij = v_a * tanh(W_a * s_{i-1} + U_a * h_j)
        # Shape: (B, T, hidden_size)
        energy = torch.tanh(self.Wa(query) + self.Ua(keys))
        
        # Shape: (B, T, 1)
        scores = self.va(energy)
        
        # Calculate attention weights: alpha_ij
        # Shape: (B, T, 1)
        weights = F.softmax(scores, dim=1)
        
        # Calculate context vector: c_i = sum(alpha_ij * h_j)
        # Shape: (B, 1, H) -> (B, H)
        context = torch.bmm(weights.transpose(1, 2), keys).squeeze(1)
        
        return context, weights

class AttentionDecoderStep(nn.Module):
    def __init__(self, vocab_size: int, embed_size: int, hidden_size: int):
        super(AttentionDecoderStep, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.attention = BahdanauAttention(hidden_size)
        # Input to GRU is (embedded_token + context_vector)
        self.gru = nn.GRU(embed_size + hidden_size, hidden_size, batch_first=True)
        self.fc = nn.Linear(hidden_size, vocab_size)

    def forward(self, x: torch.Tensor, hidden: torch.Tensor, encoder_outputs: torch.Tensor):
        # x shape: (B, 1) - single token step
        embedded = self.embedding(x) # (B, 1, E)
        
        # Get context vector using previous hidden state as query
        # context shape: (B, H)
        context, attn_weights = self.attention(hidden.squeeze(0), encoder_outputs)
        
        # Concatenate embedding and context
        # Shape: (B, 1, E + H)
        rnn_input = torch.cat([embedded, context.unsqueeze(1)], dim=2)
        
        # RNN step
        output, hidden = self.gru(rnn_input, hidden) # output: (B, 1, H), hidden: (1, B, H)
        
        # Prediction
        prediction = self.fc(output.squeeze(1)) # (B, Vocab)
        
        return prediction, hidden, attn_weights

# --- Shape Verification Test ---
if __name__ == "__main__":
    BATCH_SIZE, SEQ_LEN = 32, 20
    VOCAB_SIZE, EMBED_SIZE, HIDDEN_SIZE = 1000, 128, 256
    
    decoder = AttentionDecoderStep(VOCAB_SIZE, EMBED_SIZE, HIDDEN_SIZE)
    
    # Dummy inputs for a single decoding step
    target_token = torch.randint(0, VOCAB_SIZE, (BATCH_SIZE, 1)) # (B, 1)
    prev_hidden = torch.randn(1, BATCH_SIZE, HIDDEN_SIZE)        # (1, B, H)
    encoder_outs = torch.randn(BATCH_SIZE, SEQ_LEN, HIDDEN_SIZE) # (B, T, H)
    
    prediction, next_hidden, weights = decoder(target_token, prev_hidden, encoder_outs)
    
    assert prediction.shape == (BATCH_SIZE, VOCAB_SIZE), "Prediction shape mismatch"
    assert next_hidden.shape == (1, BATCH_SIZE, HIDDEN_SIZE), "Hidden state shape mismatch"
    assert weights.shape == (BATCH_SIZE, SEQ_LEN, 1), "Attention weights shape mismatch"
    print("Test passed! Shapes verified.")
```

## 10. Strengths
The introduction of Attention revolutionized sequence modeling by eliminating the fixed-length context vector bottleneck. Its primary strength is the ability to handle extremely long sequences with minimal performance degradation, as the decoder can selectively recall any part of the source input exactly when needed. This leads to dramatically higher BLEU scores in machine translation and significantly more coherent text generation. Furthermore, attention provides a critical layer of interpretability. By extracting and plotting the attention weights $\alpha_{ij}$ as a heatmap, developers can visually verify if the model has learned sensible alignments (e.g., aligning the French word "pomme" with the English word "apple"). This transparency was largely absent in previous black-box neural networks. Finally, attention creates direct gradient paths from the decoder outputs to the encoder inputs, acting similarly to a residual connection and making the model easier and faster to train by mitigating vanishing gradients.

## 11. Weaknesses
Despite its massive advantages, the standard Attention Seq2Seq model has notable weaknesses. First, the computational complexity is high: for an input sequence of length $T_x$ and an output of length $T_y$, the attention mechanism must compute alignment scores $T_x \times T_y$ times. This quadratic scaling makes it slow for very long documents. Second, while attention mitigates the bottleneck, the architecture still fundamentally relies on RNNs (LSTMs or GRUs) as the underlying encoders and decoders. RNNs process tokens sequentially, meaning step $t$ cannot be computed until step $t-1$ is finished. This inherently prevents massive parallelization during training, restricting the model's ability to efficiently utilize modern GPU architectures compared to CNNs or Transformers. Lastly, additive attention (Bahdanau) requires a learned feedforward network for every interaction, which is computationally heavier than the simpler dot-product attention later popularized by Luong and the Transformer.

## 12. Research Evolution
The Bahdanau Attention paper (2015) was the spark that ignited modern NLP. Shortly after, Luong et al. (2015) introduced "multiplicative" or dot-product attention, which simplified the energy calculation by using a dot product instead of a neural network layer, making it significantly faster and more memory-efficient. Researchers quickly realized that attention was not just a tool for translation but a general-purpose mechanism for memory retrieval. It was applied to image captioning (attending to parts of an image), speech recognition, and reading comprehension. The logical conclusion of this evolution occurred in 2017 with Vaswani et al.'s paper "Attention Is All You Need." They proposed the Transformer, an architecture that entirely discarded the sequential RNNs, relying *exclusively* on self-attention mechanisms to draw global dependencies between inputs and outputs. The Attention Seq2Seq model serves as the critical evolutionary bridge between the era of sequential RNNs and the era of parallel Transformers.

## 13. Interview Questions
**Q1: What specific problem with the original Encoder-Decoder architecture does Attention solve?**
**A1:** It solves the "information bottleneck" problem. Original Seq2Seq models compress the entire input sequence into a single, fixed-size vector. For long sequences, this vector loses information. Attention solves this by allowing the decoder to dynamically compute a custom context vector at every step, drawing directly from all encoder hidden states.

**Q2: Differentiate between Bahdanau (Additive) Attention and Luong (Multiplicative) Attention.**
**A2:** Bahdanau attention concatenates the decoder hidden state and the encoder hidden state, and passes them through a single-layer feedforward network with a tanh activation to compute the alignment score. Luong attention, in its simplest form, computes the dot product between the decoder hidden state and the encoder hidden state. Luong is generally faster and more memory-efficient as it leverages optimized matrix multiplication.

**Q3: How do attention weights aid in model interpretability?**
**A3:** Attention weights ($\alpha_{ij}$) represent a probability distribution over the input sequence for each output token. By visualizing these weights as a 2D matrix (heatmap), we can see exactly which source words the model focused heavily on to produce a specific target word. This allows us to verify if the model has learned the correct linguistic alignments and to debug instances where translation fails.

**Q4: Does the Attention mechanism eliminate the vanishing gradient problem entirely?**
**A4:** While it doesn't eliminate it entirely for the underlying RNNs, it dramatically mitigates it. In standard Seq2Seq, gradients for early input tokens must travel through the entire decoder and the entire encoder. With attention, there are direct "shortcut" connections from every decoder step to every encoder step, providing gradients a much shorter path backward and stabilizing training.

**Q5: Why did the field eventually move from Attention-based RNNs to Transformers?**
**A5:** While Attention solved the context bottleneck, the underlying RNNs still required sequential processing (step $t$ waits for step $t-1$). This prevents parallelization during training. Transformers use self-attention to process all tokens in a sequence simultaneously, allowing for massive parallelization on GPUs and the training of vastly larger models on much larger datasets.
