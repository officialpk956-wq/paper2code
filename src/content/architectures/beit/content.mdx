# BEiT

## 1. Overview
BEiT (Bidirectional Encoder representation from Image Transformers), introduced by Microsoft Research in 2021, is a landmark architecture that successfully brought the magic of BERT from natural language processing into computer vision. Before BEiT, Vision Transformers (ViTs) were trained using supervised learning (requiring millions of human-labeled images). BEiT proposed a radical self-supervised pre-training method called **Masked Image Modeling (MIM)**. Drawing direct inspiration from how BERT masks words in a sentence and tries to predict them, BEiT masks out patches of an image and tries to predict the missing visual information. However, predicting raw pixels is chaotic and inefficient. BEiT's stroke of genius was using a discrete Variational Autoencoder (dVAE) to first tokenize the image into a "visual alphabet." The BEiT transformer then learns to predict these discrete *visual tokens* rather than raw pixels. This self-supervised approach allowed BEiT to learn incredibly rich, robust visual representations without a single human label, establishing MIM as the gold standard for pre-training modern vision models.

:::note
"BEiT" is a deliberate homage to "BERT." Just as BERT predicts masked text tokens from a discrete vocabulary, BEiT predicts masked visual tokens from a discrete visual vocabulary.
:::

## 2. Historical Context
In 2018, BERT revolutionized NLP via masked language modeling—hiding words and forcing the model to infer them from context. This self-supervised pre-training was so powerful it eliminated the need for massive labeled datasets. When the Vision Transformer (ViT) was introduced in 2020, researchers desperately tried to replicate BERT's success in vision. The obvious approach was masking image patches and predicting the missing RGB pixels. However, this largely failed. Pixels contain too much high-frequency noise and too little semantic meaning; predicting them forced the model to act like a low-level image restorer rather than learning high-level concepts (like "this is a dog's ear"). Microsoft Research solved this with BEiT by realizing that to do BERT for vision, you first need a "vocabulary" of visual concepts. By adapting a dVAE (borrowed from OpenAI's DALL-E research) to create discrete visual tokens, they provided the ViT with a high-level, semantic target to predict, finally unlocking the power of BERT-style pre-training for images.

## 3. Problem It Solves
BEiT solves the **pixel prediction bottleneck** in self-supervised computer vision. The goal of self-supervised learning is to teach a model the semantic structure of the world without human labels. If you mask an image and ask a network to predict the exact RGB values of the missing pixels, the loss function focuses heavily on getting the exact shade of lighting or texture correct (low-level details). This is computationally expensive and semantically useless; the model learns to be a texture generator, not a conceptual thinker. BEiT solves this by shifting the prediction target from continuous pixels to **discrete visual tokens**. The dVAE tokenizer acts as an abstraction layer, compressing a 16x16 pixel patch into a single integer (e.g., token ID 402, which might roughly represent a "curved furry edge"). Predicting token ID 402 forces the BEiT model to understand the high-level semantic context of the image, rather than wasting capacity guessing the exact RGB values of the fur.

## 5. Layer-by-Layer Breakdown
The BEiT process consists of two distinct components: the Image Tokenizer (dVAE) and the BEiT Transformer.

**1. The Image Tokenizer (dVAE):** This is a pre-trained network (usually borrowed from DALL-E). It takes a full image and compresses it into a grid of discrete integers (Visual Tokens). The vocabulary size is typically 8192. A 224x224 image is tokenized into a 14x14 grid of tokens. *Crucially, these tokens are the "ground truth" labels for the pre-training task.*

**2. Masking the Input:** The original image is also divided into 14x14 visual patches (16x16 pixels each). BEiT uses **Blockwise Masking**: instead of randomly masking individual patches, it masks contiguous blocks of patches (roughly 40% of the image in total). The unmasked patches are linearly projected into embeddings. The masked patches are replaced by a learnable `[MASK]` embedding.

**3. The BEiT Transformer:** The sequence of embeddings (unmasked patches + `[MASK]` tokens) is fed into a standard Vision Transformer (identical to the ViT architecture with Multi-Head Attention and MLPs).

**4. The Prediction Head:** At the output of the Transformer, a linear classifier is applied *only to the positions that were masked*. This classifier has an output size of 8192 (the vocabulary size of the visual tokens). 

**5. The Loss:** The model calculates a standard Cross-Entropy loss between the predicted logits and the true discrete Visual Tokens generated by the dVAE. The model is penalized if it cannot correctly guess the visual token that belongs in the masked region.

## 6. Tensor Flow Walkthrough
Let's trace the tensor flow during BEiT pre-training. Assume Batch `B=16`, Image `224x224`, Patch Size `16x16`, `D_model=768`, Vocab Size `V=8192`.
Number of patches $N = (224/16)^2 = 196$.

1.  **Image Input:** `(B, C, H, W)` -> `(16, 3, 224, 224)`
2.  **dVAE Tokenization (Target Generation):**
    *   Image passes through dVAE encoder.
    *   Outputs discrete token IDs.
    *   Target Shape: `(B, N)` -> `(16, 196)` (integers from 0 to 8191).
3.  **Patch Extraction & Masking:**
    *   Extract patches: `(16, 196, 768)` (flattened pixels).
    *   Generate a boolean mask `M` of shape `(16, 196)`. About 75 patches (~40%) are `True` (masked).
    *   Project unmasked patches to `D_model`. Replace masked patches with a learned `[MASK]` vector of size `(768)`.
    *   Input Shape: `(B, N, D_model)` -> `(16, 196, 768)`
4.  **Transformer Encoder:**
    *   Add positional embeddings. Pass through $L$ Transformer layers.
    *   Output Shape: `(B, N, D_model)` -> `(16, 196, 768)`
5.  **Prediction Head:**
    *   Filter the output tensor to only include the masked positions using mask `M`.
    *   Let $N_m$ be the number of masked patches (e.g., 75).
    *   Filtered Output: `(B * N_m, D_model)` -> `(16 * 75, 768)` -> `(1200, 768)`
    *   Pass through Linear Classifier `(768, 8192)`.
    *   Logits Shape: `(1200, 8192)`
6.  **Loss Calculation:**
    *   Filter the dVAE Targets using mask `M` to get only the true token IDs for the masked regions.
    *   Filtered Targets Shape: `(1200)`
    *   Compute Cross-Entropy between Logits `(1200, 8192)` and Targets `(1200)`.

## 7. Mathematical Foundations
The core mathematical formulation of BEiT is the **Masked Image Modeling (MIM)** objective, maximizing the log-likelihood of the correct visual tokens given the corrupted image.

Let $x$ be the original image.
Let $\mathcal{V}$ be the visual tokenizer (dVAE), generating the true discrete tokens: $z = \mathcal{V}(x)$, where $z = [z_1, z_2, \dots, z_N]$.
Let $\mathcal{M}$ be the set of masked indices.
Let $x^{\setminus \mathcal{M}}$ be the corrupted image (where patches in $\mathcal{M}$ are replaced by the `[MASK]` embedding).
Let $P(z_i | x^{\setminus \mathcal{M}} ; \theta)$ be the probability predicted by the BEiT Transformer with parameters $\theta$ for the $i$-th masked token.

The training objective is to minimize the negative log-likelihood (which is equivalent to Cross-Entropy) over all masked positions:
$$ \mathcal{L}_{MIM} = - \sum_{i \in \mathcal{M}} \log P(z_i | x^{\setminus \mathcal{M}} ; \theta) $$

Unlike standard contrastive self-supervised learning (like MoCo or SimCLR) which operates on the *entire* image representation globally (e.g., $\max \text{Sim}(f(x_1), f(x_2))$), the MIM loss operates *locally* at the patch level. This forces the network to learn fine-grained semantic details and dense representations, which is why BEiT performs exceptionally well on downstream tasks requiring localization, like object detection and semantic segmentation.

## 8. Training Procedure
Training BEiT is a two-stage process. 

**Stage 1: Pre-training (Self-Supervised)**
The model is trained entirely on ImageNet-1K using the MIM objective described above. No class labels (like "dog" or "car") are used. The model simply learns to predict missing dVAE tokens. A crucial detail is **Blockwise Masking**. Instead of masking random individual patches (which would allow the model to cheat by simply looking at the adjacent pixels and interpolating the color), BEiT masks large, contiguous blocks of patches. This forces the model to understand global structure and semantics to guess what is missing in a large empty void. Pre-training runs for up to 800 epochs.

**Stage 2: Fine-tuning (Supervised)**
After pre-training, the MIM linear prediction head is thrown away. The pre-trained BEiT Transformer encoder now possesses a deep understanding of visual semantics. To use it for a specific task (e.g., image classification), a new, randomly initialized linear classification head (e.g., size 1000) is attached. The entire network is then fine-tuned on the labeled ImageNet data for a small number of epochs (e.g., 100 epochs). Because the model is already deeply pre-trained, it converges quickly and achieves significantly higher accuracy than a ViT trained from scratch.

## 9. PyTorch Implementation
Below is a PyTorch implementation illustrating the data preparation and masking logic for the BEiT forward pass during pre-training.

```python
import torch
import torch.nn as nn

class BEiTPretrainBlock(nn.Module):
    def __init__(self, img_size=224, patch_size=16, d_model=768, vocab_size=8192):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2
        
        # Patch projection
        self.patch_embed = nn.Conv2d(3, d_model, kernel_size=patch_size, stride=patch_size)
        
        # Learnable [MASK] token
        self.mask_token = nn.Parameter(torch.zeros(1, 1, d_model))
        
        # Positional embeddings
        self.pos_embed = nn.Parameter(torch.zeros(1, self.num_patches, d_model))
        
        # Dummy Transformer (Standard ViT encoder)
        self.transformer = nn.TransformerEncoderLayer(
            d_model=d_model, nhead=12, dim_feedforward=3072, batch_first=True
        )
        
        # Prediction head predicting dVAE vocabulary size
        self.mim_head = nn.Linear(d_model, vocab_size)

    def forward(self, x, bool_masked_pos):
        """
        x: Images (B, C, H, W)
        bool_masked_pos: Boolean mask (B, N). True means the patch is masked.
        """
        B = x.shape[0]
        
        # 1. Project image to patches (B, N, d_model)
        patches = self.patch_embed(x).flatten(2).transpose(1, 2)
        
        # 2. Replace masked patches with [MASK] token
        mask_tokens = self.mask_token.expand(B, self.num_patches, -1)
        
        # Where bool_masked_pos is True, use mask_token, else use patch embeddings
        # Reshape mask to broadcast over d_model: (B, N, 1)
        w = bool_masked_pos.unsqueeze(-1).type_as(mask_tokens)
        
        # Blend: if w=1 (masked), take mask_token. if w=0 (unmasked), take patch.
        corrupted_input = patches * (1 - w) + mask_tokens * w
        
        # 3. Add position embeddings
        x = corrupted_input + self.pos_embed
        
        # 4. Pass through Transformer
        features = self.transformer(x)
        
        # 5. Extract ONLY the masked positions for the loss calculation
        # features: (B, N, d_model), bool_masked_pos: (B, N)
        # Resulting masked_features will be a 2D tensor of shape (Total_Masked_Patches_In_Batch, d_model)
        masked_features = features[bool_masked_pos]
        
        # 6. Predict dVAE token IDs
        logits = self.mim_head(masked_features)
        
        return logits

# --- Test ---
if __name__ == "__main__":
    B, C, H, W = 2, 3, 224, 224
    N = (224 // 16) ** 2 # 196 patches
    vocab_size = 8192
    
    model = BEiTPretrainBlock(vocab_size=vocab_size)
    x = torch.randn(B, C, H, W)
    
    # Create a random boolean mask simulating 40% masking
    bool_masked_pos = torch.rand(B, N) < 0.4 
    num_masked = bool_masked_pos.sum().item()
    
    logits = model(x, bool_masked_pos)
    
    print(f"Input image shape: {x.shape}")
    print(f"Boolean mask shape: {bool_masked_pos.shape}")
    print(f"Total masked patches across batch: {num_masked}")
    print(f"Output logits shape: {logits.shape}")
    
    assert logits.shape == (num_masked, vocab_size), "Logits shape mismatch!"
    print("Test passed: BEiT masking and MIM prediction evaluated successfully.")
```

## 10. Strengths
BEiT's primary strength is the immense quality of the representations it learns without human labels. Because the Masked Image Modeling (MIM) task forces the network to understand the semantic relationships between patches (to correctly guess the missing visual tokens), the pre-trained BEiT model acts as an incredibly powerful feature extractor. When fine-tuned on downstream tasks, BEiT consistently outperforms models trained entirely via supervised learning. Furthermore, because the MIM task evaluates every single patch (rather than boiling the whole image down to a single class token), BEiT's dense representations are exceptionally strong for pixel-level tasks like semantic segmentation, where standard ViTs historically struggled.

## 11. Weaknesses
BEiT's main weakness is the dependency on the pre-trained dVAE tokenizer. Training a good discrete Variational Autoencoder is notoriously difficult and computationally expensive. By relying on a separate network to generate the "ground truth" labels, the performance of the BEiT transformer is fundamentally upper-bounded by the quality of the dVAE's visual vocabulary. If the dVAE tokenizer fails to capture subtle textures or nuances in an image, the BEiT model will never learn to recognize them, because they won't exist in the target tokens it is trying to predict. Additionally, processing the `[MASK]` tokens through the deep transformer layers consumes significant compute during pre-training for tokens that contain no actual image data.

## 12. Research Evolution
BEiT was the breakthrough that proved BERT-style pre-training was viable for computer vision. It triggered a massive paradigm shift away from contrastive self-supervised learning (like SimCLR and MoCo) towards Masked Image Modeling (MIM). However, the reliance on the complex dVAE tokenizer was quickly recognized as a bottleneck. Shortly after BEiT's publication, He et al. published Masked Autoencoders (MAE), which proved that if you design an asymmetric encoder-decoder architecture, you actually *can* predict raw pixels directly, eliminating the need for the dVAE entirely. Therefore, BEiT holds historical importance as the model that successfully brought the BERT philosophy to vision, paving the way for the more streamlined MIM architectures that followed.

## 13. Interview Questions

**Q1: Why did early attempts to replicate BERT in computer vision (by masking patches and predicting raw RGB pixels) fail, and how did BEiT solve this?**
**A1:** Predicting raw RGB pixels forces the loss function to heavily penalize small deviations in texture, lighting, or high-frequency noise. This forces the network to act like a low-level image restorer, wasting its capacity on details rather than learning high-level semantics. BEiT solved this by using a dVAE to compress patches into discrete "visual tokens." By predicting these abstract, discrete tokens instead of pixels, the model is forced to learn high-level semantic context, exactly like predicting a discrete word in a sentence.

**Q2: What is the role of the dVAE in the BEiT pre-training pipeline?**
**A2:** The discrete Variational Autoencoder (dVAE) acts as the "Image Tokenizer." It is a separate, pre-trained network that takes an image and converts it into a grid of discrete integers (e.g., from a vocabulary of 8192). These integers serve as the ground-truth targets for the BEiT Transformer. The Transformer's job is to look at the unmasked parts of the image and predict the dVAE integers for the masked parts.

**Q3: BEiT utilizes "Blockwise Masking" instead of masking random individual patches. Why is this important?**
**A3:** If you randomly mask a single 16x16 patch, the network can often guess what belongs there simply by looking at the color of the adjacent pixels and smoothing them inward (local interpolation). It doesn't need to understand the image. By masking large, contiguous blocks of patches, local interpolation fails. The model is forced to look at far-away patches and use global semantic understanding (e.g., "I see a dog's tail and paws, so the big missing block in the middle must be a dog's torso") to guess the missing tokens.

**Q4: During the BEiT pre-training phase, how does the input to the Transformer change compared to a standard ViT?**
**A4:** In a standard ViT, the input is simply a sequence of linear embeddings of the image patches. In BEiT pre-training, approximately 40% of those patch embeddings are discarded and replaced with a single, shared, learnable vector called the `[MASK]` token. The Transformer processes this corrupted sequence, treating the `[MASK]` tokens as placeholders that it must fill with information based on the surrounding unmasked patches.

**Q5: Contrastive self-supervised learning (like SimCLR) pulls representations of augmented images closer together. How does Masked Image Modeling (MIM) in BEiT provide a denser learning signal?**
**A5:** Contrastive learning generally operates on a single, global representation vector for the entire image (e.g., the Class Token output). The loss only provides one gradient update per image. MIM, however, operates at the patch level. The BEiT model makes a prediction and calculates a loss for *every single masked patch*. If 75 patches are masked, the model receives 75 distinct gradient signals detailing exactly where its local predictions failed. This density of supervision makes BEiT incredibly strong for dense downstream tasks like semantic segmentation.
