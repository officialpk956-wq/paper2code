# GauGAN / SPADE

## 1. Overview
GauGAN (built on **SPADE: Spatially-Adaptive Denormalization**), introduced in 2019 by Taesung Park, Ming-Yu Liu, Ting-Chun Wang, and Jun-Yan Zhu (NVIDIA & UC Berkeley), revolutionized semantic image synthesis by enabling users to paint photorealistic landscapes from simple segmentation masks. Prior to SPADE, semantic image translation models (like Pix2PixHD) fed segmentation masks into the input layer of an encoder-decoder network, passing features through standard Batch Normalization or Instance Normalization layers. Park et al. discovered that standard normalization layers **completely wash away semantic label information**, especially in regions with uniform semantic labels (e.g., a large blue sky mask). SPADE solved this by discarding input mask injection at the first layer, instead injecting the segmentation layout directly into every normalization layer via **Spatially-Adaptive Scale ($\gamma(m)$) and Shift ($\beta(m)$) maps**.

:::note
SPADE's innovation: "Standard normalization layers wash away semantic mask information. SPADE injects the semantic layout $m$ at EVERY layer by predicting spatially varying scale $\gamma_{c,y,x}(m)$ and shift $\beta_{c,y,x}(m)$ maps."
:::

## 2. Historical Context
In 2018, semantic image synthesis models (e.g., converting a segmentation map of "sky, sea, mountain, grass" into a realistic landscape) used standard conditional encoder-decoder networks (Pix2PixHD). Input segmentation masks were passed into the first convolutional layer and normalized via InstanceNorm or BatchNorm.

Taesung Park et al. noticed a fatal mathematical flaw: Instance Normalization computes zero-mean and unit-variance over spatial regions: $\hat{h}_{c,y,x} = \frac{h_{c,y,x} - \mu_c}{\sigma_c}$. If a region contains a uniform semantic label (e.g., a large rectangular mask for "sky"), the normalized activations $\hat{h}$ in that region become completely zeroed out, destroying all semantic signal!

SPADE introduced Spatially-Adaptive Denormalization, using the segmentation layout $m$ to generate spatially-varying modulation parameters $\gamma(m)$ and $\beta(m)$ at every resolution layer, winning the SIGGRAPH 2019 Real-Time Live! award.

## 3. Problem It Solves
GauGAN / SPADE resolves three core issues in semantic layout image generation:
1. **Semantic Washing in Normalization Layers:** Standard InstanceNorm/BatchNorm layers zero out uniform semantic mask regions. SPADE replaces standard normalization scale/shift parameters with **spatially adaptive 2D maps** $\gamma(m)$ and $\beta(m)$.
2. **Loss of Layout Control at Deep Layers:** Feeding masks only into the first input layer causes layout signals to fade in deeper layers. SPADE injects layout map $m$ at every residual block.
3. **Interactive Multimodal Synthesis:** Allows users to swap semantic brush labels (e.g., painting "water" over "grass") while controlling style via an optional image encoder latent vector $z$.

## 5. Layer-by-Layer Breakdown

**1. SPADE Modulation Layer:**
- Takes input feature map $h \in \mathbb{R}^{B \times C \times H \times W}$ and segmentation layout map $m \in \mathbb{R}^{B \times C_{\text{mask}} \times H_{\text{img}} \times W_{\text{img}}}$.
- Resamples $m$ to match feature spatial resolution $(H, W)$ via nearest-neighbor interpolation.
- Passes $m$ through a 2-layer convolution block: `Conv(3x3) -> ReLU -> Conv_gamma(3x3)` and `Conv_beta(3x3)`.
- Outputs 2D spatial scale map $\gamma_{c,y,x}(m)$ and shift map $\beta_{c,y,x}(m)$.

**2. SPADE Residual Block (SPADE-ResNet):**
- Contains two SPADE layers, two $3 \times 3$ convolutions, and a skip connection.
- Applies SPADE modulation before activations.

**3. GauGAN Generator Architecture:**
- Discards image encoder for unconditional layout generation (or uses a lightweight style encoder to produce $z$).
- Upsamples features progressively ($4 \times 4 \to 8 \times 8 \dots \to 512 \times 512$) using stacked SPADE Residual Blocks.

## 6. Tensor Flow Walkthrough
Let's trace tensors through a SPADE Residual Block for batch size $B=2$, feature map `(2, 128, 64, 64)`, 18 segmentation classes (e.g., sky, grass, river).

1. **Input Map Preparation:**
   - Feature Map $x$: `(2, 128, 64, 64)`
   - Segmentation Mask $m$: `(2, 18, 256, 256)`
   - Downsample Mask $m \to m_{\text{down}}$: `(2, 18, 64, 64)`
2. **SPADE Scale & Shift Generation:**
   - $m_{\text{down}} \xrightarrow{\text{Conv3x3 + ReLU}}$ Hidden: `(2, 128, 64, 64)`
   - $\text{Conv}_{\gamma}(\text{Hidden}) \to \gamma(m)$: `(2, 128, 64, 64)` 2D Scale Map
   - $\text{Conv}_{\beta}(\text{Hidden}) \to \beta(m)$: `(2, 128, 64, 64)` 2D Shift Map
3. **SPADE Modulation:**
   - Normalized Feature $\hat{x} = \text{InstanceNorm}(x)$: `(2, 128, 64, 64)`
   - Modulated Output $= \hat{x} \odot \gamma(m) + \beta(m) \to$ `(2, 128, 64, 64)`
4. **ResNet Pass:**
   - Conv3x3 $\to$ Second SPADE Layer $\to$ ReLU $\to$ Residual Add $\to$ `(2, 128, 64, 64)`.

## 7. Mathematical Foundations

### 1. Spatially-Adaptive Denormalization (SPADE) Formula
Let $h_{c,y,x}^m$ be the activation at channel $c$, vertical position $y$, and horizontal position $x$ for mini-batch sample $m$.
First, Instance Normalization normalizes activations in a spatial feature map to zero mean and unit variance:

$$\hat{h}_{c,y,x}^m = \frac{h_{c,y,x}^m - \mu_c^m}{\sigma_c^m}$$

where $\mu_c^m = \frac{1}{HW} \sum_{y,x} h_{c,y,x}^m$ and $\sigma_c^m = \sqrt{\frac{1}{HW} \sum_{y,x} (h_{c,y,x}^m)^2 - (\mu_c^m)^2}$.

Next, SPADE applies **Spatially-Varying Scale $\gamma_{c,y,x}(m)$ and Shift $\beta_{c,y,x}(m)$ Maps** generated from segmentation mask $m$:

$$\text{SPADE}(h_{c,y,x}^m, m) = \gamma_{c,y,x}(m) \cdot \hat{h}_{c,y,x}^m + \beta_{c,y,x}(m)$$

Notice that unlike standard BatchNorm (where $\gamma_c$ and $\beta_c$ are 1D scalar vectors), $\gamma_{c,y,x}(m)$ and $\beta_{c,y,x}(m)$ are **3D Spatial Feature Tensors** $(C \times H \times W)$ that depend explicitly on local semantic mask layout at coordinate $(y, x)$.

## 8. Training Procedure
- **Multi-Scale PatchGAN Discriminators:** Uses 3 PatchGAN discriminators operating at different resolutions ($1\times, 1/2\times, 1/4\times$).
- **Loss Objective:** Hinge loss + Perceptual Feature Matching Loss ($\mathcal{L}_{\text{FM}}$) + VAE KL Divergence Loss.
- Optimizer: Adam ($\beta_1 = 0, \beta_2 = 0.9$, $\text{lr}_G = 0.0001, \text{lr}_D = 0.0004$).

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of the **SPADE Layer**.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SPADE(nn.Module):
    """ Spatially-Adaptive Denormalization (SPADE) Layer """
    def __init__(self, norm_nc, label_nc, hidden_dim=128):
        super().__init__()
        self.param_free_norm = nn.InstanceNorm2d(norm_nc, affine=False)
        
        # Shared Convolutional Sub-Network for Mask m
        self.mlp_shared = nn.Sequential(
            nn.Conv2d(label_nc, hidden_dim, kernel_size=3, padding=1),
            nn.ReLU(inplace=True)
        )
        # Scale Map Output Conv
        self.mlp_gamma = nn.Conv2d(hidden_dim, norm_nc, kernel_size=3, padding=1)
        # Shift Map Output Conv
        self.mlp_beta = nn.Conv2d(hidden_dim, norm_nc, kernel_size=3, padding=1)

    def forward(self, x, seg_map):
        """
        x: (B, C_in, H, W) - Feature map
        seg_map: (B, C_labels, H_img, W_img) - One-hot segmentation mask
        """
        # 1. Parameter-free Instance Normalization
        normalized = self.param_free_norm(x)
        
        # 2. Resample segmentation map to match feature spatial resolution
        seg_resampled = F.interpolate(seg_map.float(), size=x.shape[2:], mode='nearest')
        
        # 3. Generate 2D Spatial Scale (gamma) and Shift (beta) Maps
        act = self.mlp_shared(seg_resampled)
        gamma = self.mlp_gamma(act) # (B, C_in, H, W)
        beta = self.mlp_beta(act)   # (B, C_in, H, W)
        
        # 4. Spatially-Adaptive Denormalization
        out = normalized * (1.0 + gamma) + beta
        return out

if __name__ == "__main__":
    B, C_in, H, W = 2, 128, 64, 64
    num_classes = 18
    spade_layer = SPADE(norm_nc=C_in, label_nc=num_classes)
    
    x = torch.randn(B, C_in, H, W)
    seg_mask = torch.randn(B, num_classes, 256, 256) # High-res segmentation mask
    
    out = spade_layer(x, seg_mask)
    
    print(f"Input Feature Shape:      {x.shape}")
    print(f"Segmentation Mask Shape:  {seg_mask.shape}")
    print(f"SPADE Modulated Output:   {out.shape}")
    assert out.shape == (B, C_in, H, W)
    print("SPADE layer verification successful!")
```

## 10. Strengths
- **Prevents Semantic Washing:** Preserves semantic label signals across uniform mask regions.
- **Interactive Painting Control:** Enables real-time photorealistic landscape painting from segmentation brushes.
- **Multimodal Style Variations:** Allows swapping style vectors $z$ to render the same layout under different weather, lighting, or artistic styles.

## 11. Weaknesses
- **High Memory Demand:** Generating 2D spatial modulation maps $(\gamma, \beta)$ at every resolution layer consumes significant VRAM.

## 12. Research Evolution
GauGAN / SPADE set the standard for semantic image synthesis, directly inspiring **SEAN**, **OASIS**, and **ControlNet**.

## 13. Interview Questions

**Q1: Why do standard normalization layers (InstanceNorm/BatchNorm) fail for semantic image synthesis?**
**A1:** InstanceNorm normalizes feature activations in a spatial channel to zero mean and unit variance. If a region contains a uniform semantic label (e.g., a large rectangular "sky" mask), InstanceNorm zeroes out all activations in that region, completely washing away semantic layout signals.

**Q2: How does SPADE solve the semantic washing problem?**
**A2:** SPADE discards standard 1D scalar normalization parameters and predicts **2D Spatial Scale ($\gamma_{c,y,x}$) and Shift ($\beta_{c,y,x}$) Maps** generated directly from the segmentation layout $m$ at every resolution block.

**Q3: Write out the SPADE mathematical formula.**
**A3:** $\text{SPADE}(h_{c,y,x}, m) = \gamma_{c,y,x}(m) \cdot \left( \frac{h_{c,y,x} - \mu_c}{\sigma_c} \right) + \beta_{c,y,x}(m)$.

**Q4: How does GauGAN support multimodal image synthesis (generating different styles for the same layout)?**
**A4:** GauGAN incorporates an optional Image Encoder that extracts a style latent vector $z \sim \mathcal{N}(0, \mathbf{I})$ from a reference image. Vector $z$ is injected into the initial layer of the Generator, modulating color and lighting while SPADE controls spatial geometry.

**Q5: Compare GauGAN/SPADE with Pix2PixHD.**
**A5:** Pix2PixHD fed segmentation masks into the first layer of an encoder-decoder network using standard InstanceNorm. GauGAN/SPADE feeds masks into EVERY layer via spatially-adaptive denormalization, achieving higher realism and preventing label washing.
