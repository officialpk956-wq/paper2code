# RetinaNet

## 1. Overview
RetinaNet, introduced in 2017 by Tsung-Yi Lin, Priya Goyal, Ross Girshick, Kaiming He, and Piotr Dollár (FAIR), solved one of the central mysteries in computer vision: **Why were single-stage object detectors (like YOLO and SSD) consistently less accurate than two-stage detectors (like Faster R-CNN)?** The authors discovered that the root cause was NOT network architecture, but an extreme **Class Imbalance** during training. Single-stage detectors evaluate $100,000+$ candidate anchor locations per image, over 99.9% of which are easy background negatives. Standard cross-entropy loss allows the vast volume of easy negative gradients to completely overwhelm the small number of informative positive object gradients. To solve this, FAIR introduced **Focal Loss**—a dynamically scaled cross-entropy loss that down-weights the loss assigned to easy, well-classified examples, focusing training on hard, ambiguous objects. Powered by Focal Loss and a Feature Pyramid Network (FPN) backbone, RetinaNet matched the speed of single-stage detectors while surpassing the accuracy of all state-of-the-art two-stage detectors on MS COCO.

:::tip
RetinaNet's core discovery: "Extreme class imbalance ($100,000:1$ background-to-foreground ratio) is the single barrier preventing single-stage detectors from matching two-stage accuracy. Focal Loss solves this mathematically by dynamically modulating loss based on confidence $p_t$."
:::

## 2. Historical Context
By 2017, object detection was split between single-stage speed and two-stage accuracy. Two-stage detectors (Faster R-CNN) achieved top accuracy on COCO because Stage 1 (RPN) filtered out millions of background proposals to ~2,000 candidates, and Stage 2 (Fast R-CNN) used heuristics (e.g., 1:3 positive-to-negative sampling) to maintain balance.

Single-stage detectors (YOLO, SSD) skipped proposal filtering, evaluating dense anchor grids directly. However, SSD used crude Hard Negative Mining (sorting losses and keeping a 3:1 ratio), which was non-differentiable and discarded useful background context.

FAIR researchers realized that two-stage detectors succeeded because RPN's coarse filtering implicitly handled class imbalance. They asked: *Can we design a loss function that natively handles $100,000+$ anchors without hard negative mining or two-stage filtering?* They formulated **Focal Loss** and built RetinaNet—a single-stage architecture comprising a ResNet-FPN backbone and two decoupled subnetworks for classification and box regression—setting a new benchmark on COCO (39.1 AP at 5 FPS).

## 3. Problem It Solves
RetinaNet addresses two major limitations:
1. **Extreme Foreground-Background Class Imbalance:** Dense single-stage detectors evaluate $\sim 100,000$ anchors per image. Over 99.9% are background. Standard cross-entropy loss assigns small loss values (e.g., 0.1) to easy negatives, but summed over 100,000 anchors, these easy negatives overwhelm the positive object gradients. Focal Loss dynamically scales easy negative loss toward zero.
2. **Heuristic Sampling Instability:** Replaces non-differentiable Hard Negative Mining (SSD) with a continuous, end-to-end differentiable loss function.

## 5. Layer-by-Layer Breakdown
RetinaNet consists of a ResNet-FPN backbone and two task-specific subnetworks:

**1. ResNet + FPN Backbone:**
- Extracts feature pyramids $\{P_3, P_4, P_5, P_6, P_7\}$ with strides $\{8, 16, 32, 64, 128\}$. All levels have 256 channels.
- $P_3$ to $P_5$ built from ResNet $C_3, C_4, C_5$. $P_6$ is a stride-2 conv on $C_5$. $P_7$ is a stride-2 conv on $P_6$.

**2. Classification Subnet:**
- A small FCN attached to each FPN level (parameters shared across all levels).
- Applies four $3 \times 3$ convolutions (256 filters, ReLU), followed by a $3 \times 3$ convolution with $A \times K$ filters (where $A=9$ anchors per cell, $K$ classes).
- Outputs Sigmoid class probabilities.

**3. Bounding Box Regression Subnet:**
- Parallel FCN attached to each FPN level (parameters shared across all levels).
- Applies four $3 \times 3$ convolutions (256 filters, ReLU), followed by a $3 \times 3$ convolution with $A \times 4$ filters.
- Predicts class-agnostic bounding box deltas relative to anchors.

   - Total Anchors = $(75\times100 + 38\times50 + 19\times25 + 10\times13 + 5\times7) \times 9 = \mathbf{90,099}$ anchors per image!

## 7. Mathematical Foundations

### 1. Focal Loss Derivation
Standard Cross-Entropy (CE) loss for binary classification ($y \in \{\pm 1\}$):

$$\text{CE}(p, y) = \begin{cases} -\log(p) & \text{if } y = 1 \\ -\log(1-p) & \text{if } y = -1 \end{cases}$$

Define $p_t$ as the model's estimated probability for the true class:
$$p_t = \begin{cases} p & \text{if } y = 1 \\ 1 - p & \text{if } y = -1 \end{cases} \quad \implies \quad \text{CE}(p_t) = -\log(p_t)$$

#### The Focal Loss Equation
Focal Loss adds a modulating factor $(1 - p_t)^\gamma$ with focusing parameter $\gamma \ge 0$:

$$\text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$$

where $\alpha_t \in [0, 1]$ is an $\alpha$-balanced parameter addressing class frequency imbalance.

### 2. Focal Loss Curve & Behavior ($\gamma$ Impact)

```text
  Loss
   |
3.0|  \
   |   \  Standard Cross Entropy (gamma = 0)
2.0|    \
   |     \
1.0|      \================== FL (gamma = 0.5)
   |       \----------------- FL (gamma = 1.0)
0.0|________\________________ FL (gamma = 2.0, Easy Negatives Loss -> 0)
   +---------------------------------------+
   0.0       0.2       0.5       0.8      1.0  pt (Probability of Ground-Truth)
             [Hard Examples]    [Easy Examples]
```

#### Key Behaviors of Focal Loss:
1. **When $p_t$ is small (Hard Example, e.g., $p_t = 0.1$):**
   - The modulating factor $(1 - p_t)^\gamma = (0.9)^2 = 0.81$.
   - The loss is barely affected ($0.81 \times \text{CE}$).
2. **When $p_t$ is large (Easy Well-Classified Example, e.g., $p_t = 0.9$):**
   - The modulating factor $(1 - p_t)^\gamma = (0.1)^2 = 0.01$.
   - The loss is suppressed by **$100\times$**!
3. **Impact of Focusing Parameter $\gamma = 2.0$:**
   - Suppresses easy background negatives ($p_t \ge 0.5$) so severely that their cumulative sum across 100,000 anchors is negligible compared to the loss of hard positive objects.

## 8. Training Procedure
- **Prior Initialization Trick:** To prevent $\sim 100,000$ background anchors from causing loss explosion at step 1 of training, the final classification conv layer bias is initialized to $b = -\log((1 - \pi) / \pi)$ with $\pi = 0.01$. This forces the network to output $p \approx 0.01$ for all anchors at iteration 0, ensuring initial background losses are near zero.
- **Focal Loss Parameters:** $\gamma = 2.0, \alpha = 0.25$.
- **Optimizer:** SGD with momentum 0.9, weight decay $10^{-4}$, initial learning rate 0.01.

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of the **Focal Loss** module.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FocalLoss(nn.Module):
    def __init__(self, alpha=0.25, gamma=2.0, reduction='mean'):
        super().__init__()
        self.alpha = alpha
        self.gamma = gamma
        self.reduction = reduction

    def forward(self, inputs, targets):
        """
        inputs: (N, C) logits
        targets: (N,) long tensor of ground-truth indices
        """
        # Convert targets to one-hot encoding
        num_classes = inputs.size(1)
        targets_one_hot = F.one_hot(targets, num_classes=num_classes).float()
        
        # Compute Sigmoid probabilities p
        p = torch.sigmoid(inputs)
        
        # Calculate p_t (probability of target class)
        p_t = p * targets_one_hot + (1 - p) * (1 - targets_one_hot)
        
        # Calculate alpha_t
        alpha_t = self.alpha * targets_one_hot + (1 - self.alpha) * (1 - targets_one_hot)
        
        # Calculate Modulating Factor (1 - p_t)^gamma
        modulating_factor = (1.0 - p_t) ** self.gamma
        
        # Calculate Focal Loss: -alpha_t * (1 - p_t)^gamma * log(p_t)
        # Smooth log for numerical stability
        log_p_t = torch.log(p_t + 1e-8)
        loss = -alpha_t * modulating_factor * log_p_t
        
        loss = loss.sum(dim=1) # Sum across classes
        
        if self.reduction == 'mean':
            return loss.mean()
        elif self.reduction == 'sum':
            return loss.sum()
        return loss

if __name__ == "__main__":
    N_anchors = 1000
    num_classes = 80
    focal_loss = FocalLoss(alpha=0.25, gamma=2.0)
    
    # Simulating predictions for 1000 anchors
    dummy_logits = torch.randn(N_anchors, num_classes)
    # 990 background (class 0), 10 foreground objects
    dummy_targets = torch.zeros(N_anchors, dtype=torch.long)
    dummy_targets[:10] = torch.randint(1, num_classes, (10,))
    
    loss_val = focal_loss(dummy_logits, dummy_targets)
    print(f"Calculated Focal Loss: {loss_val.item():.4f}")
    assert not torch.isnan(loss_val)
    print("Focal Loss verification successful!")
```

## 10. Strengths
- **Solves Class Imbalance:** Natively handles 100,000+ candidate anchors without hard negative mining.
- **Single-Stage Speed with Two-Stage Accuracy:** Matches or exceeds Faster R-CNN accuracy (39.1 AP on COCO) at single-stage speeds.
- **Differentiable & Robust:** Replaces non-differentiable sampling with an elegant end-to-end loss function.

## 11. Weaknesses
- **Hyperparameter Sensitivity:** Requires tuning $\alpha$ and $\gamma$ parameters simultaneously.
- **Anchor Box Dependency:** Retains legacy anchor box constraints (fixed aspect ratios, scales).

## 12. Research Evolution
RetinaNet's Focal Loss revolutionized dense object recognition. It directly inspired modern anchor-free single-stage detectors like **FCOS**, **VarifocalNet**, and **GFL (Generalized Focal Loss)**.

## 13. Interview Questions

**Q1: What is the primary mathematical purpose of the modulating factor $(1 - p_t)^\gamma$ in Focal Loss?**
**A1:** The modulating factor down-weights the loss generated by easy, well-classified examples ($p_t \ge 0.5$). When an easy background anchor has $p_t = 0.9$ and $\gamma = 2.0$, $(1 - 0.9)^2 = 0.01$, suppressing its loss by $100\times$. This prevents 100,000 easy background anchors from overwhelming gradients from hard positive objects.

**Q2: Why did RetinaNet initialize the bias of the final classification layer to $b = -\log((1 - \pi)/\pi)$ with $\pi = 0.01$?**
**A2:** At iteration 0, randomly initialized weights output $p \approx 0.5$ for all 100,000 anchors, generating a massive initial loss spike that destabilizes training. Setting initial bias $b \approx -4.59$ forces the network to output $p \approx 0.01$ for all anchors at step 1, ensuring initial background losses are near zero.

**Q3: Compare Focal Loss with Hard Negative Mining (used in SSD).**
**A3:** Hard Negative Mining is a non-differentiable heuristic that sorts anchor losses and keeps only the top negatives to maintain a 3:1 ratio, discarding the rest. Focal Loss is a smooth, continuous, end-to-end differentiable loss that evaluates ALL anchors simultaneously, dynamically scaling their contributions.

**Q4: What are the typical optimal values for $\alpha$ and $\gamma$ in RetinaNet?**
**A4:** $\gamma = 2.0$ (focusing parameter) and $\alpha = 0.25$ (alpha-balancing parameter for background vs. foreground).

**Q5: Why does RetinaNet use separate subnetworks for classification and box regression instead of a shared head?**
**A5:** Classification (predicting category semantics) and localization (predicting spatial boundary offsets) require different feature representations. Using decoupled subnetworks prevents gradient interference between the two tasks.
