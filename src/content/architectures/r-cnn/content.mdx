# R-CNN

## 1. Overview
R-CNN (Region-based Convolutional Neural Network), introduced in 2013 by Ross Girshick, Jeff Donahue, Trevor Darrell, and Jitendra Malik from UC Berkeley, was the breakthrough paper that brought deep learning to 2D object detection. Before R-CNN, object detection relied on hand-crafted visual descriptors such as HOG (Histogram of Oriented Gradients) and SIFT paired with Deformable Part Models (DPM) or Support Vector Machines (SVMs). R-CNN proved that deep Convolutional Neural Networks (AlexNet) trained on ImageNet could be transferred to object detection, boosting mean Average Precision (mIoU/mAP) on PASCAL VOC 2012 by a staggering 30% relative margin (from 40.5% to 53.3%). R-CNN established a multi-stage pipeline: (1) Proposal Generation via CPU-based Selective Search (~2,000 region proposals per image); (2) Feature Extraction by warping each proposal to a fixed $227 \times 227$ resolution and passing it through AlexNet; (3) Classification using class-specific linear SVMs; and (4) Bounding Box Regression via linear ridge regression.

:::note
R-CNN initiated the modern era of deep object detection by proving that high-capacity CNN feature extractors trained on classification datasets transfer extraordinarily well to object detection when combined with region proposals.
:::

## 2. Historical Context
### The R-CNN → Fast R-CNN → Faster R-CNN Story: Eliminating Bottlenecks (Part 1)
The evolution of two-stage object detection is the story of systematically identifying and eliminating computational bottlenecks in a multi-stage pipeline.

In 2013, R-CNN proved for the first time that deep convolutional features could replace hand-engineered SIFT/HOG descriptors for object detection. However, R-CNN suffered from a colossal computational bottleneck: **It ran the CNN forward pass independently for all 2,000 region proposals per image.** 

Because every single image generated ~2,000 proposals, processing one image required 2,000 separate forward passes through AlexNet on the GPU. This forced each proposal to be warped to a fixed $227 \times 227$ size, destroying aspect ratios. Furthermore, R-CNN was not an end-to-end network: it stored feature vectors on disk (hundreds of gigabytes for PASCAL VOC), trained SVM classifiers offline, and subsequently trained bounding box regressors separately.

Processing a single image took **47 seconds** on a GPU. This immense latency motivated Ross Girshick to invent **Fast R-CNN** (2015), which eliminated the 2,000-pass bottleneck by running the CNN *once* over the full image and using RoI Pooling to share feature maps across proposals. Later, **Faster R-CNN** (2015) eliminated the remaining CPU proposal bottleneck (Selective Search) by introducing the Region Proposal Network (RPN).

## 3. Problem It Solves
R-CNN solved three primary challenges in early computer vision:
1. **Dethroning Hand-Crafted Features:** Traditional object detectors (HOG + DPM) hit an accuracy wall (~40% mAP). R-CNN demonstrated that supervised pre-training on ImageNet followed by domain-specific fine-tuning on object detection datasets acts as a universal feature representation engine.
2. **Localizing Variable-Aspect Objects:** Sliding window detectors required evaluating millions of bounding boxes at hundreds of scales, making deep CNN evaluation impossible. R-CNN restricted evaluation to ~2,000 high-quality candidate regions generated by Selective Search.
3. **Bounding Box Coarseness:** Selective Search proposals were often imprecise. R-CNN introduced a post-hoc linear bounding box regression stage that learned continuous offsets $(\Delta x, \Delta y, \Delta w, \Delta h)$ to tightly snap proposals to ground-truth objects.

## 5. Layer-by-Layer Breakdown
R-CNN is structured as four distinct, sequentially trained components:

**1. Selective Search Proposal Generator (CPU):**
- Groups pixels based on color, texture, size, and shape compatibility.
- Generates approximately 2,000 candidate bounding box coordinates $(x_1, y_1, x_2, y_2)$ per image.

**2. Image Warping Preprocessor:**
- Adds a small padding boundary ($P=16$ pixels) around each proposed bounding box.
- Dilates/squashes the cropped image patch to fit AlexNet's strict input shape: $227 \times 227 \times 3$.

**3. CNN Feature Extractor (AlexNet):**
- Passes each warped $227 \times 227$ image through 5 convolutional layers followed by 2 fully connected layers (`fc6` and `fc7`).
- Extracts a 4,096-dimensional feature vector per proposal from the `fc7` layer.

**4. Binary SVM Classifier Array:**
- Evaluates $K$ separate binary linear Support Vector Machines (one per class, e.g., $K=20$ for PASCAL VOC).
- Takes the $(N_{\text{proposal}}, 4096)$ feature matrix and outputs an $(N_{\text{proposal}}, K)$ classification matrix.

**5. Bounding Box Regressor:**
- A class-specific linear regression model that takes the `fc5` feature map (or `fc7` vector) and predicts spatial adjustment deltas $(\Delta x, \Delta y, \Delta w, \Delta h)$ to refine proposal coordinates toward ground-truth boxes.

## 6. Tensor Flow Walkthrough
Let's trace a single image producing $N_{\text{prop}} = 2000$ region proposals for $K = 20$ classes.

1. **Input Image:** `(3, H, W)` where $H=500, W=375$.
2. **Selective Search Output:** `(2000, 4)` bounding box coordinates $(x_1, y_1, x_2, y_2)$.
3. **Anisotropic Warping:**
   - 2,000 crops of varying aspect ratios resized to `(2000, 3, 227, 227)`.
4. **AlexNet Forward Passes (2,000 Iterations or Batches):**
   - Conv1: `(2000, 96, 55, 55)`
   - Pool1: `(2000, 96, 27, 27)`
   - Conv2 to Pool5: `(2000, 256, 6, 6)`
   - FC6 + Dropout: `(2000, 4096)`
   - FC7 + Dropout: `(2000, 4096)`
5. **Offline Feature Saving:**
   - Saves `(2000, 4096)` array of float32 values to disk (~32 MB per image).
6. **Class SVM Predictions:**
   - Matrix multiplication `(2000, 4096) @ (4096, 20)` $\rightarrow$ Scores: `(2000, 20)`.
7. **Bounding Box Regression:**
   - Matrix multiplication `(2000, 4096) @ (4096, 80)` $\rightarrow$ Offsets: `(2000, 80)` (4 deltas for each of the 20 classes).

## 7. Mathematical Foundations

### Bounding Box Regression Formulation
Let a proposed bounding box be $P = (P_x, P_y, P_w, P_h)$ where $(P_x, P_y)$ is the center coordinate, and $P_w, P_h$ are width and height.
Let the ground-truth box be $G = (G_x, G_y, G_w, G_h)$.

The goal is to learn continuous transformation functions $d_x(P), d_y(P), d_w(P), d_h(P)$ such that the predicted box $\hat{G} = (\hat{G}_x, \hat{G}_y, \hat{G}_w, \hat{G}_h)$ closely approximates $G$:

$$\hat{G}_x = P_w d_x(P) + P_x$$
$$\hat{G}_y = P_h d_y(P) + P_y$$
$$\hat{G}_w = P_w \exp(d_w(P))$$
$$\hat{G}_h = P_h \exp(d_h(P))$$

The target regression values $(t_x, t_y, t_w, t_h)$ derived from ground-truth are:
$$t_x = \frac{G_x - P_x}{P_w}, \quad t_y = \frac{G_y - P_y}{P_h}$$
$$t_w = \log\left(\frac{G_w}{P_w}\right), \quad t_h = \log\left(\frac{G_h}{P_h}\right)$$

Each transformation function $d_k(P)$ (where $k \in \{x, y, w, h\}$) is modeled as a linear function of the `fc7` feature vector $\phi_5(P)$:
$$d_k(P) = w_k^T \phi_5(P)$$

The objective is optimized via Ridge Regression (L2-regularized MSE):
$$w_k = \arg\min_{\hat{w}_k} \sum_{i=1}^{N_{\text{pos}}} \left( t_k^i - \hat{w}_k^T \phi_5(P^i) \right)^2 + \lambda \|\hat{w}_k\|^2$$

Regression targets are evaluated **only** on positive proposals that have an IoU overlap $\ge 0.6$ with a ground-truth box.

## 8. Training Procedure
R-CNN's training procedure is complex, un-unified, and performed in three separate offline steps:

1. **CNN Pre-training:** AlexNet is pre-trained on ImageNet 1000-way classification.
2. **Domain-Specific Fine-Tuning:** The classification layer is replaced with a $(K+1)$-way softmax layer. Proposals with $\text{IoU} \ge 0.5$ with any ground-truth box are treated as positive for that class; all others are negative. Trained using SGD with a mini-batch size of 128 (32 positive, 96 background).
3. **SVM Training:** Offline linear SVMs are trained for each class using `fc7` features. Unlike CNN fine-tuning, SVM training uses a stricter positive threshold ($\text{IoU} = 1.0$) and treats proposals with $\text{IoU} < 0.3$ as negative. Hard Negative Mining is used to handle class imbalance.
4. **Bounding Box Regressor Training:** Ridge regression parameters $w_k$ are fitted offline on positive proposal feature vectors ($\text{IoU} \ge 0.6$).

## 9. PyTorch Implementation
Here is a minimal PyTorch implementation of the R-CNN pipeline showing crop warping, AlexNet feature extraction, SVM classification, and Bounding Box regression heads.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torchvision.models import alexnet, AlexNet_Weights

class RCNNPipeline(nn.Module):
    def __init__(self, num_classes=20):
        super().__init__()
        # Load AlexNet backbone
        base_alexnet = alexnet(weights=AlexNet_Weights.DEFAULT)
        self.features = base_alexnet.features
        self.avgpool = base_alexnet.avgpool
        
        # FC Layers up to fc7 (4096 dimensions)
        self.fc_layers = nn.Sequential(
            nn.Dropout(p=0.5),
            nn.Linear(256 * 6 * 6, 4096),
            nn.ReLU(inplace=True),
            nn.Dropout(p=0.5),
            nn.Linear(4096, 4096),
            nn.ReLU(inplace=True)
        )
        
        # Linear SVM Classifiers (K binary linear heads)
        self.svm_classifiers = nn.Linear(4096, num_classes)
        
        # Bounding Box Regressors (4 deltas per class)
        self.bbox_regressors = nn.Linear(4096, num_classes * 4)

    def extract_features(self, warped_crops):
        # warped_crops shape: (N_roi, 3, 227, 227)
        x = self.features(warped_crops) # (N_roi, 256, 6, 6)
        x = self.avgpool(x)
        x = torch.flatten(x, 1)        # (N_roi, 9216)
        phi_7 = self.fc_layers(x)      # (N_roi, 4096)
        return phi_7

    def forward(self, image, roi_boxes):
        """
        image: (3, H, W)
        roi_boxes: Tensor of shape (N_roi, 4) in (x1, y1, x2, y2)
        """
        N_roi = roi_boxes.shape[0]
        warped_crops = []
        
        # Crop and Warp each proposed RoI box
        for box in roi_boxes:
            x1, y1, x2, y2 = box.int()
            # Crop proposal from full image
            crop = image[:, y1:y2, x1:x2].unsqueeze(0) # (1, 3, crop_h, crop_w)
            # Anisotropic Warp to (227, 227)
            warped = F.interpolate(crop, size=(227, 227), mode='bilinear', align_corners=False)
            warped_crops.append(warped)
            
        warped_tensor = torch.cat(warped_crops, dim=0) # (N_roi, 3, 227, 227)
        
        # Extract FC7 features
        phi_7 = self.extract_features(warped_tensor) # (N_roi, 4096)
        
        # Predict Class Scores & Box Deltas
        svm_scores = self.svm_classifiers(phi_7)    # (N_roi, num_classes)
        bbox_deltas = self.bbox_regressors(phi_7)   # (N_roi, num_classes * 4)
        
        return svm_scores, bbox_deltas

if __name__ == "__main__":
    num_rois = 5
    num_classes = 20
    model = RCNNPipeline(num_classes=num_classes)
    
    # Dummy Image (3, 500, 375)
    dummy_image = torch.randn(3, 500, 375)
    # Dummy RoI Proposals (x1, y1, x2, y2)
    dummy_rois = torch.tensor([
        [10, 10, 100, 100],
        [50, 50, 200, 200],
        [30, 80, 150, 300],
        [120, 150, 300, 350],
        [200, 200, 350, 360]
    ], dtype=torch.float32)
    
    scores, deltas = model(dummy_image, dummy_rois)
    
    print(f"SVM Class Scores Shape: {scores.shape}")
    print(f"BBox Deltas Shape:      {deltas.shape}")
    
    assert scores.shape == (num_rois, num_classes), f"Expected ({num_rois}, {num_classes}), got {scores.shape}"
    assert deltas.shape == (num_rois, num_classes * 4), f"Expected ({num_rois}, {num_classes * 4}), got {deltas.shape}"
    print("R-CNN Pipeline verification successful!")
```

## 10. Strengths
- **Historical Milestone:** First model to successfully apply deep learning to 2D object detection, breaking a decade-long stagnation of hand-crafted features.
- **High Transfer Capacity:** Demonstrated that ImageNet pre-training transfers remarkably well to dense detection tasks via fine-tuning.
- **Accurate Localization:** Bounding box regression drastically improved localization quality over raw Selective Search proposals.

## 11. Weaknesses
- **Extreme Training Latency:** Training is a complex 3-stage offline pipeline (CNN fine-tuning, SVM training, Ridge regression).
- **Gigantic Storage Requirement:** Features extracted from 2,000 proposals per image must be written to disk, requiring hundreds of GBs of storage.
- **Slow Inference (47 seconds/image):** Running 2,000 independent GPU forward passes per image makes real-time deployment impossible.
- **Anisotropic Distortion:** Forcing arbitrary bounding boxes to warp into $227 \times 227$ distorts aspect ratios, losing spatial shape context.

## 12. Research Evolution
R-CNN defined the two-stage paradigm. Its severe speed and disk storage bottlenecks directly motivated **SPP-Net** (He et al., 2014) and **Fast R-CNN** (Girshick, 2015), which introduced feature map sharing via RoI Pooling.

## 13. Interview Questions

**Q1: What was the primary computational bottleneck of R-CNN that Fast R-CNN subsequently fixed?**
**A1:** R-CNN ran the full AlexNet CNN forward pass independently for every one of the ~2,000 region proposals per image (requiring 2,000 GPU forward passes per image). Fast R-CNN fixed this by running the CNN *once* on the entire image to generate a global feature map, then using RoI Pooling to crop proposal features directly from that feature map.

**Q2: Why did R-CNN use offline linear SVMs instead of softmax cross-entropy for final classification?**
**A2:** In early experiments, fine-tuning the CNN with softmax cross-entropy achieved 50.9% mAP, whereas training offline SVMs achieved 54.2% mAP. This performance gap occurred because SVM training used a stricter definition of positive examples ($\text{IoU} = 1.0$) and utilized hard negative mining, which the simple softmax SGD training setup lacked.

**Q3: How does R-CNN's bounding box regression target derivation work?**
**A3:** The target deltas $(t_x, t_y, t_w, t_h)$ compute scale-invariant center translation: $t_x = (G_x - P_x)/P_w$, $t_y = (G_y - P_y)/P_h$, and log-space width/height scaling: $t_w = \log(G_w/P_w)$, $t_h = \log(G_h/P_h)$. Linear regression models $d_k(P) = w_k^T \phi_5(P)$ predict these target deltas.

**Q4: What is "anisotropic warping" in R-CNN, and why is it problematic?**
**A4:** Anisotropic warping crops a proposed region of arbitrary aspect ratio (e.g., $300 \times 50$) and directly resizes it to AlexNet's fixed input dimension ($227 \times 227$). This distorts the object's geometric shape and aspect ratio, making tall objects look wide and squished.

**Q5: What IoU thresholds were used for fine-tuning the CNN vs. training the SVMs in R-CNN?**
**A5:** 
- **CNN Fine-Tuning:** Positive if proposal $\text{IoU} \ge 0.5$ with any ground-truth box; negative otherwise.
- **SVM Training:** Positive only for ground-truth boxes ($\text{IoU} = 1.0$); negative if $\text{IoU} < 0.3$. Proposals with $0.3 \le \text{IoU} < 1.0$ are ignored.
