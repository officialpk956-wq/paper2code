# MaxViT

## 1. Overview
Multi-Axis Vision Transformer (MaxViT), introduced by Google Research and UT Austin in 2022, addresses the fundamental scalability problem of standard Vision Transformers (ViTs). Standard ViTs use global self-attention, meaning every patch in an image attends to every other patch. This results in an $O(N^2)$ computational complexity, making it impossible to process high-resolution images. Previous solutions, like Swin Transformer, restricted attention to small local windows, achieving $O(N)$ complexity but losing the global receptive field (the ability to see the whole image at once). MaxViT brilliantly solves this dichotomy by introducing **Multi-Axis Attention**. In every block, it alternates between Block Attention (which looks at local neighborhoods, just like Swin) and Grid Attention (which looks at a sparse, dilated grid spanning the entire image). This combination maintains $O(N)$ linear computational complexity while providing a true global receptive field at every single layer of the network. MaxViT scales seamlessly from mobile sizes to massive models, achieving state-of-the-art accuracy on ImageNet while being highly efficient for high-resolution dense prediction tasks like object detection and segmentation.

:::note
MaxViT is a "hybrid" architecture. It doesn't throw away convolutions; it actually uses an MBConv (Mobile Inverted Bottleneck Convolution) layer at the start of every block to handle local feature extraction before applying its revolutionary Multi-Axis Transformer attention.
:::

## 2. Historical Context
By 2022, the computer vision community was acutely aware of the limitations of the original Vision Transformer. ViT's quadratic complexity restricted it to low resolutions (e.g., 224x224). To process high resolutions needed for autonomous driving or medical imaging, the Swin Transformer became the standard. Swin achieved linear complexity by restricting attention to local 7x7 windows. To communicate across windows, Swin "shifted" the windows in the next layer. While effective, it meant information took many layers to travel from one side of the image to the other (a restricted receptive field). Google researchers recognized that local attention was insufficient for complex contextual reasoning. They needed a way to look at the entire image without calculating $N^2$ interactions. Drawing inspiration from dilated convolutions, they formulated Grid Attention, which, when paired with local Block Attention, created MaxViT: the first architecture to offer linear complexity with an infinite (global) receptive field in a single block.

## 3. Problem It Solves
MaxViT solves the **Quadratic Complexity vs. Global Context tradeoff**. 
If you use global attention (ViT), you get global context, but memory and compute explode quadratically as image resolution increases. You cannot run it on high-res images.
If you use local attention (Swin), compute scales linearly (problem solved!), but the model can only see a small patch of the image at a time. It loses global context.
MaxViT solves this by decoupling the spatial axes. Instead of attending to all pixels, **Block Attention** attends to a dense, localized 7x7 square (capturing fine details). Immediately after, **Grid Attention** attends to a sparse 7x7 grid of pixels scattered evenly across the *entire* image (capturing global context). Because both operations operate on fixed size sets (e.g., 49 pixels), the complexity is strictly $O(N)$. By stacking them, every pixel gathers information locally and globally in every single layer.

## 5. Layer-by-Layer Breakdown
MaxViT uses a hierarchical macro-structure (like ResNet or Swin), meaning it operates in 4 stages, progressively halving the spatial resolution and doubling the channel dimension. The magic happens inside the individual blocks of these stages.

**1. MBConv Layer:** Every block begins with a convolutional layer. Specifically, it uses the MBConv block from EfficientNet, complete with a depthwise 3x3 convolution and Squeeze-and-Excitation (SE). This injects strong convolutional inductive biases (translation invariance and early local feature grouping) into the network, making the subsequent transformer layers much more effective.

**2. Block Attention (Local):** The feature map is partitioned into non-overlapping windows of size $P \times P$ (typically 7x7). Standard Multi-Head Self-Attention is applied *independently* within each window. This step captures high-frequency local details (edges, textures). Complexity is linear with respect to the whole image because the attention matrix is always $P^2 \times P^2$, regardless of the total image size.

**3. Grid Attention (Global):** The feature map is partitioned into a sparse grid. Instead of taking a contiguous 7x7 block, it takes pixels that are spaced $G$ pixels apart, forming a sparse $G \times G$ grid (typically also 7x7) that covers the entire image from edge to edge. Self-attention is computed across these sparse grid points. This allows a pixel in the top-left corner to communicate directly with a pixel in the bottom-right corner. Again, because the attention matrix is bounded by $G^2 \times G^2$, complexity remains strictly $O(N)$.

Both attention mechanisms utilize standard LayerNorm and MLPs (Feed-Forward Networks) in their residual paths.

## 6. Tensor Flow Walkthrough
Let's trace the tensor flow to understand how Block and Grid partitioning is achieved via reshaping. Assume Feature Map `X` has shape `(B, C, H, W) = (2, 64, 56, 56)`. Block size `P = 7`, Grid size `G = 7`. 

*(Note: In MaxViT, if P=7 and G=7, the image must be $49 \times 49$, but for flexibility, G dynamically scales as $H/P$. Let's assume $P=7$, so $G = 56/7 = 8$ for this specific resolution).*

1.  **Input to Block Attention:** `(2, 64, 56, 56)` -> Permute to `(B, H, W, C)` -> `(2, 56, 56, 64)`.
2.  **Block Partitioning (Reshape magic):**
    *   Reshape: `(B, H//P, P, W//P, P, C)` -> `(2, 8, 7, 8, 7, 64)`
    *   Transpose and flatten to group by blocks: `(B * H//P * W//P, P * P, C)`
    *   Result: `(2 * 8 * 8, 7 * 7, 64)` -> `(128, 49, 64)`
    *   *We now have 128 independent blocks, each containing 49 tokens.*
3.  **Block Attention Execution:**
    *   Standard MHA on shape `(128, 49, 64)`.
    *   Reverse the reshape to get back to `(2, 56, 56, 64)`.
4.  **Grid Partitioning (Reshape magic):**
    *   To get a sparse grid, we reshape differently. We want to group pixels that are $P$ steps apart.
    *   Reshape: `(B, G, P, G, P, C)` (where G is the grid size, $G=H//P=8$).
    *   Transpose to group the grid points together: `(B, P, P, G, G, C)`
    *   Flatten: `(B * P * P, G * G, C)`
    *   Result: `(2 * 7 * 7, 8 * 8, 64)` -> `(98, 64, 64)`
    *   *We now have 98 independent sparse grids, each containing 64 tokens covering the whole image.*
5.  **Grid Attention Execution:**
    *   Standard MHA on shape `(98, 64, 64)`.
    *   Reverse the reshape to get back to `(2, 56, 56, 64)`.
    *   Permute back to `(B, C, H, W)`.

## 7. Mathematical Foundations
The primary mathematical achievement of MaxViT is reducing the complexity of self-attention from $O(N^2)$ to $O(N)$ while preserving global reach.

Let an image have dimensions $H \times W$. The total number of tokens is $N = H \times W$.
Standard Self-Attention complexity is $O(N^2 C)$.

**Block Attention Complexity:**
We divide the image into patches of size $P \times P$.
The number of tokens per block is $P^2$. The complexity of attention within one block is $O((P^2)^2 C) = O(P^4 C)$.
There are $\frac{H \times W}{P^2}$ total blocks.
Total Block Attention complexity: $\frac{HW}{P^2} \times O(P^4 C) = O(HW P^2 C) = O(N P^2 C)$.
Since $P$ is a constant (usually 7), the complexity is **$O(N)$**.

**Grid Attention Complexity:**
We divide the image into sparse grids of size $G \times G$. To perfectly tile the image, $G = \frac{H}{P}$ and $\frac{W}{P}$.
The number of tokens per grid is $G^2$. The complexity within one grid is $O((G^2)^2 C) = O(G^4 C)$.
There are $P \times P = P^2$ total grids.
Total Grid Attention complexity: $P^2 \times O(G^4 C)$.
Substitute $G^2 = \frac{HW}{P^2} = \frac{N}{P^2}$:
Complexity is $P^2 \times O((\frac{N}{P^2})^2 C) = O(\frac{N^2}{P^2} C)$.

*Wait, is this $O(N^2)$?*
In the original paper formulation, the authors use a fixed uniform grid size $G$ (e.g., $G=7$) regardless of image size, and scale $P$ accordingly (or interpolate). By fixing both $P$ and $G$ to small constants and adding pooling layers between stages to reduce $H$ and $W$, the effective computational complexity for the attention operations at any given stage remains strictly linear $O(N)$ with respect to the input resolution of that stage, providing a massive computational advantage over dense $O(N^2)$ attention.

## 8. Training Procedure
MaxViT is trained using a standard supervised learning pipeline, but heavily benefits from modern training recipes designed for Transformers.

**Data Augmentation:** Like all advanced ViTs, it is prone to overfitting if trained solely on ImageNet-1K without regularization. The training relies heavily on RandAugment, Mixup, CutMix, and random erasing to artificially expand the dataset's diversity.

**Optimization:** MaxViT utilizes the AdamW optimizer with a cosine learning rate decay and a linear warmup phase. Heavy weight decay is applied to regularize the network.

**Scaling:** Google evaluated MaxViT by scaling it from a tiny mobile version (MaxViT-T, 31M parameters) up to an extra-large version (MaxViT-XL, 475M parameters). For the larger variants, they utilized pre-training on the massive, proprietary JFT-300M dataset before fine-tuning on ImageNet-1K, proving that the architecture scales beautifully with massive data volume.

## 9. PyTorch Implementation
Below is a simplified PyTorch implementation demonstrating the clever tensor reshaping required to achieve Block and Grid Attention.

```python
import torch
import torch.nn as nn

class MultiAxisAttention(nn.Module):
    def __init__(self, dim, num_heads, window_size=7):
        super().__init__()
        self.dim = dim
        self.num_heads = num_heads
        self.window_size = window_size
        
        # Two separate attention mechanisms for Block and Grid
        self.block_attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        self.grid_attn = nn.MultiheadAttention(dim, num_heads, batch_first=True)
        
        self.norm1 = nn.LayerNorm(dim)
        self.norm2 = nn.LayerNorm(dim)

    def forward(self, x):
        """ x shape: (B, C, H, W) """
        B, C, H, W = x.shape
        P = self.window_size
        
        # Ensure dimensions are divisible by window_size
        assert H % P == 0 and W % P == 0, "H and W must be divisible by window_size"
        G_h, G_w = H // P, W // P # Grid sizes
        
        # Change to (B, H, W, C)
        x = x.permute(0, 2, 3, 1)
        
        # --- 1. BLOCK ATTENTION (Local) ---
        x_norm = self.norm1(x)
        
        # Partition into blocks: (B, G_h, P, G_w, P, C)
        x_block = x_norm.view(B, G_h, P, G_w, P, C)
        # Transpose and flatten to group by blocks: (B * G_h * G_w, P * P, C)
        x_block = x_block.permute(0, 1, 3, 2, 4, 5).reshape(B * G_h * G_w, P * P, C)
        
        # Apply Self-Attention
        attn_out_block, _ = self.block_attn(x_block, x_block, x_block)
        
        # Reverse partition
        attn_out_block = attn_out_block.reshape(B, G_h, G_w, P, P, C).permute(0, 1, 3, 2, 4, 5).reshape(B, H, W, C)
        
        # Residual connection
        x = x + attn_out_block
        
        # --- 2. GRID ATTENTION (Global) ---
        x_norm = self.norm2(x)
        
        # Partition into grids: (B, G_h, P, G_w, P, C)
        x_grid = x_norm.view(B, G_h, P, G_w, P, C)
        # Transpose and flatten to group by sparse grids: (B * P * P, G_h * G_w, C)
        x_grid = x_grid.permute(0, 2, 4, 1, 3, 5).reshape(B * P * P, G_h * G_w, C)
        
        # Apply Self-Attention
        attn_out_grid, _ = self.grid_attn(x_grid, x_grid, x_grid)
        
        # Reverse partition
        attn_out_grid = attn_out_grid.reshape(B, P, P, G_h, G_w, C).permute(0, 3, 1, 4, 2, 5).reshape(B, H, W, C)
        
        # Residual connection
        x = x + attn_out_grid
        
        # Return to (B, C, H, W)
        return x.permute(0, 3, 1, 2)

# --- Test ---
if __name__ == "__main__":
    B, C, H, W = 2, 64, 56, 56 # 56 is divisible by 7
    window_size = 7
    num_heads = 4
    
    model = MultiAxisAttention(dim=C, num_heads=num_heads, window_size=window_size)
    x = torch.randn(B, C, H, W)
    
    out = model(x)
    
    print(f"Input shape: {x.shape}")
    print(f"Output shape: {out.shape}")
    assert out.shape == (B, C, H, W), "Shape mismatch!"
    print("Test passed: MaxViT Multi-Axis (Block + Grid) Attention evaluated.")
```

## 10. Strengths
MaxViT's unparalleled strength is its combination of linear complexity and a global receptive field. Unlike Swin Transformer, where information takes multiple layers to shift across the image, MaxViT allows pixels on opposite corners of the image to communicate in every single block via Grid Attention. This makes it exceptionally powerful for dense prediction tasks like semantic segmentation or object detection, where understanding the global context (e.g., "the sky is at the top of the image") helps classify local pixels correctly. Furthermore, the inclusion of the MBConv block at the start of every layer provides a robust convolutional inductive bias, meaning MaxViT trains faster and requires less data augmentation to converge compared to pure ViTs.

## 11. Weaknesses
The primary weakness of MaxViT is its implementation complexity and memory access patterns. While it is theoretically $O(N)$ in computational complexity (FLOPs), the continuous, massive tensor reshaping (permuting memory dimensions to switch between blocks and grids) is highly unfriendly to GPU memory bandwidth. On modern GPUs, moving data around in memory (memory-bound operations) is often slower than doing the actual math (compute-bound operations). Consequently, while MaxViT uses fewer FLOPs than standard ViT, it can sometimes have lower throughput (images processed per second) in practice because the GPU spends significant time just reshaping the tensors for the alternating attention mechanisms.

## 12. Research Evolution
MaxViT represents the maturation of the "Hybrid" vision architecture paradigm. Early models were purely convolutional (ResNet). ViT tried to be purely transformer-based, suffering from data inefficiency. Swin introduced hierarchical structures (borrowed from CNNs). MaxViT took this a step further by literally embedding MobileNet convolutions (MBConv) into the transformer block, proving that convolutions and attention are highly complementary. Its formulation of sparse Grid Attention was highly influential, demonstrating that you can decouple the spatial axes of an image to achieve global attention without the quadratic cost, paving the way for further research into sparse and linear attention mechanisms for high-resolution vision.

## 13. Interview Questions

**Q1: What is the primary limitation of standard Global Attention in a Vision Transformer (ViT) that MaxViT seeks to solve?**
**A1:** Standard global attention has a computational and memory complexity of $O(N^2)$, where $N$ is the number of image patches. If you double the image resolution, the number of patches quadruples, and the computational cost increases by a factor of 16. This makes standard ViTs completely unusable for high-resolution images common in medical imaging or autonomous driving.

**Q2: How does the Swin Transformer achieve $O(N)$ complexity, and what does it sacrifice to do so?**
**A2:** Swin achieves $O(N)$ complexity by restricting attention to small, local windows (e.g., 7x7 patches). Because the window size is fixed regardless of image size, the complexity scales linearly. However, it sacrifices the *global receptive field*. A pixel in one window cannot see a pixel in another window in the same layer; it relies on "shifted windows" in subsequent layers for information to slowly propagate across the image.

**Q3: Explain how MaxViT achieves a global receptive field in a single block while maintaining $O(N)$ complexity.**
**A3:** MaxViT alternates two mechanisms. First, Block Attention looks at a local 7x7 patch (just like Swin). Second, Grid Attention looks at a sparse 7x7 grid of pixels dilated across the *entire* image. Because both mechanisms only compute attention on fixed sets of 49 pixels at a time, the complexity is $O(N)$. Because the sparse grid spans the entire image, every pixel gathers global context in every single layer.

**Q4: Why does MaxViT include a convolutional layer (MBConv) at the beginning of every Transformer block?**
**A4:** Transformers lack "inductive biases"—they don't inherently understand that pixels close together form edges and shapes. This makes them data-hungry and slow to train. Convolutions inherently understand this local spatial relationship. By including an MBConv block, MaxViT explicitly captures translation-invariant, local features immediately, freeing up the Transformer attention layers to focus purely on complex, higher-order relationships.

**Q5: In practical deployment on a GPU, why might MaxViT sometimes run slower than expected despite having lower theoretical FLOPs?**
**A5:** To perform Block and Grid attention, the massive input tensors must be continuously reshaped, permuted, and transposed in memory. GPUs are heavily bottlenecked by memory bandwidth. Moving gigabytes of data around in memory to set up the attention calculations takes time. This "memory-bound" overhead can offset the computational "compute-bound" savings of the $O(N)$ attention mechanism.
