# YOLO v2

## 1. Overview
YOLO v2 (also published as **YOLO9000: Better, Faster, Stronger**), introduced in 2016 by Joseph Redmon and Ali Farhadi, addressed the major criticisms of YOLO v1—specifically high localization errors and low recall. Instead of abandoning the single-stage paradigm, Redmon systematically incorporated modern deep learning techniques to make YOLO v2 **Better** (higher accuracy), **Faster** (Darknet-19 backbone), and **Stronger** (joint training on 9,000 object categories via WordTree). Key innovations include:
1. **Anchor Boxes via k-means Clustering:** Replaced YOLO v1's unconstrained FC box regression with anchor boxes whose initial dimensions are discovered automatically via k-means clustering on bounding box training data.
2. **Direct Location Prediction:** Constrained bounding box center predictions to grid cell boundaries using sigmoid activation, eliminating training instability.
3. **High-Resolution Classifier & Passthrough Layer:** Added fine-grained feature passthrough (resembling identity skip connections) to combine $13 \times 13$ deep features with $26 \times 26$ high-resolution features for small object detection.

:::tip
YOLO v2 proved that single-stage detectors could match the accuracy of Faster R-CNN (69.0% mAP on VOC 2007 at 67 FPS) while maintaining real-time processing speeds.
:::

## 2. Historical Context
### The YOLO Evolution Story: Linear Progression (Part 2 - Fixing Localization & Scaling Classes)
The transition from YOLO v1 to YOLO v2 represents a methodical response to specific architectural failure modes.

While YOLO v1 (2015) proved that single-stage real-time detection was possible, it had significant flaws:
- **High Localization Error:** Unconstrained linear regression from FC layers struggled to converge to precise object bounds.
- **Low Recall:** Each grid cell could only predict $B=2$ boxes with a single shared class probability vector, resulting in low recall for overlapping or small objects.
- **Coarse Resolution:** Downsampling to $7 \times 7$ destroyed spatial detail.

To fix these flaws in YOLO v2 (2016), Joseph Redmon made major structural changes:
- **Adopted Anchor Boxes:** Inspired by Faster R-CNN, YOLO v2 removed fully connected layers and switched to convolutional anchor box predictions. But instead of picking hand-crafted anchor ratios (1:1, 1:2, 2:1), YOLO v2 used **k-means clustering** on the training set to discover optimal anchor shapes.
- **Added Batch Normalization:** Added BN to every convolutional layer, boosting mAP by over 2% and eliminating the need for dropout.
- **Introduced Darknet-19:** Replaced VGG-like 24-layer backbone with Darknet-19 (requiring only 5.58 billion operations vs. VGG's 30.6 billion), accelerating inference.
- **WordTree Hierarchy (YOLO9000):** Created a hierarchical tree combining ImageNet classification labels and COCO detection labels, enabling YOLO9000 to detect over 9,000 object categories in real time.

This set the foundation for **YOLO v3** (2018), which would later introduce multi-scale feature pyramids (FPN-like heads) to solve small object detection once and for all.

## 3. Problem It Solves
YOLO v2 solves three major weaknesses of YOLO v1:
1. **Arbitrary Hand-Crafted Anchor Ratios:** Faster R-CNN used arbitrary anchor shapes ($128^2, 256^2, 512^2$). YOLO v2 uses k-means clustering on bounding box ground-truths, finding prior shapes that better match real object aspect ratios.
2. **Unconstrained Box Divergence:** Unconstrained offset regression in early training causes anchor boxes to drift randomly across the image. YOLO v2 applies a sigmoid function to bound center predictions $(\sigma(t_x), \sigma(t_y))$ strictly within the local grid cell $[0, 1]$.
3. **Small Object Information Loss:** Deep downsampling ($13 \times 13$) erases small objects. YOLO v2's **Passthrough Layer** concatenates high-resolution $26 \times 26$ features directly into the $13 \times 13$ feature map.

## 5. Layer-by-Layer Breakdown
YOLO v2 uses Darknet-19 as its backbone and a fully convolutional head:

**1. Darknet-19 Backbone:**
- Consists of 19 convolutional layers and 5 max-pooling layers.
- Uses $3 \times 3$ convolutions interspersed with $1 \times 1$ bottleneck reduction convolutions.
- Every convolutional layer is followed by Batch Normalization and LeakyReLU ($\alpha=0.1$).

**2. High-Resolution Passthrough Layer:**
- Extracts the $26 \times 26 \times 512$ feature map from the 2nd-to-last max-pooling stage.
- Applies a **Reorg (Passthrough)** operation that splits $26 \times 26 \times 512$ spatially into four $13 \times 13 \times 512$ blocks, concatenating them along channels to yield $13 \times 13 \times 2048$.

**3. Feature Fusion & Final Convolution:**
- Concatenates the reorganized passthrough features ($13 \times 13 \times 2048$) with the final Darknet-19 feature map ($13 \times 13 \times 1024$), producing a 3,072-channel tensor.
- Processes fused features through a $3 \times 3$ convolution (1024 filters).

**4. Convolutional Anchor Prediction Head:**
- Replaces YOLO v1's FC layers with a single $1 \times 1$ convolution.
- For $k=5$ anchors per cell and $C=20$ classes, the output channels are: $k \times (5 + C) = 5 \times (5 + 20) = 125$.
- Final output tensor shape: $(B, 125, 13, 13)$, reshaped to $(B, 13, 13, 5, 25)$.

## 6. Tensor Flow Walkthrough
Let's trace tensors through YOLO v2 for batch size $B=2$, input $416 \times 416$, $k=5$ anchors, $C=20$ classes.

1. **Input Tensor:** `(2, 3, 416, 416)`
2. **Darknet-19 Processing:**
   - At Layer 13 (Stride 16): Feature map $F_{\text{pass}} \rightarrow$ `(2, 512, 26, 26)`
   - At Layer 19 (Stride 32): Feature map $F_{\text{deep}} \rightarrow$ `(2, 1024, 13, 13)`
3. **Passthrough Reorganization:**
   - Reorg($F_{\text{pass}}$): Spatial $26 \times 26 \rightarrow 13 \times 13$, channels $512 \rightarrow 2048$.
   - Tensor shape: `(2, 2048, 13, 13)`
4. **Channel Concatenation:**
   - Concat(Reorg($F_{\text{pass}}$), $F_{\text{deep}}$) along channel dim $\rightarrow$ `(2, 3072, 13, 13)`
5. **Head Conv Layers:**
   - Conv3x3(3072 $\rightarrow 1024$) + BN + LeakyReLU $\rightarrow$ `(2, 1024, 13, 13)`
   - Conv1x1(1024 $\rightarrow 125$) $\rightarrow$ `(2, 125, 13, 13)`
6. **Output Reshaping:**
   - Reshape `(2, 125, 13, 13)` $\rightarrow$ `(2, 13, 13, 5, 25)`
   - Each cell predicts 5 anchors $\times$ $[t_x, t_y, t_w, t_h, t_o, p_1 \dots p_{20}]$.

## 7. Mathematical Foundations

### 1. Bounding Box Anchor priors via k-means Clustering
Instead of hand-picking anchor box aspect ratios, YOLO v2 runs **k-means clustering** on the training set bounding box dimensions $(w, h)$. Standard Euclidean distance favors large boxes, so YOLO v2 uses a distance metric based on Intersection-over-Union (IoU):

$$d(\text{box}, \text{centroid}) = 1 - \text{IoU}(\text{box}, \text{centroid})$$

By running k-means with $k=5$, YOLO v2 discovers 5 optimal cluster centroids (prior anchor shapes):

```text
    k-means Clusters (k=5) on VOC/COCO:
    1. Small Square:    (1.19, 1.19)
    2. Medium Tall:     (2.79, 4.59)
    3. Medium Wide:     (4.50, 2.69)
    4. Large Tall:      (4.14, 8.52)
    5. Large Wide:      (10.85, 9.00)
```
*(Dimensions relative to 13x13 grid units)*. $k=5$ provided an optimal trade-off between recall and model complexity.

### 2. Direct Location Prediction & Parameterization
Standard anchor offset parameterization (Faster R-CNN) uses $x = (t_x \cdot w_a) + x_a$. If $t_x$ is unconstrained, an anchor can jump anywhere in the image, causing unstable training.

YOLO v2 constrains center prediction to the local grid cell $(c_x, c_y)$ using a Sigmoid function $\sigma(\cdot)$:

$$b_x = \sigma(t_x) + c_x$$
$$b_y = \sigma(t_y) + c_y$$
$$b_w = p_w e^{t_w}$$
$$b_h = p_h e^{t_h}$$
$$P(\text{Object}) \cdot \text{IoU}(b, \text{Object}) = \sigma(t_o)$$

where:
- $(c_x, c_y)$ is the top-left cell grid coordinate offset (e.g., $(3, 5)$).
- $(p_w, p_h)$ are the pre-defined k-means anchor width and height.
- $\sigma(t_x), \sigma(t_y) \in (0, 1)$ bounds the center point strictly inside cell $(c_x, c_y)$.
- $(b_x, b_y, b_w, b_h)$ are final box coordinates in grid units.

```text
                  +-----------------------+
                  |  Grid Cell (cx, cy)   |
                  |   +---------------x   |
                  |   | (bx, by)      |   |
                  |   |  *            |   |
                  |   |               |   |
                  |   y---------------+   |
                  +-----------------------+
                  bx = sigmoid(tx) + cx
                  by = sigmoid(ty) + cy
```

## 8. Training Procedure
- **Multi-Scale Training:** To make YOLO v2 robust to varying input resolutions, the training image size changes dynamically every 10 batches. The network randomly samples image sizes from $\{320, 352, 384, \dots, 608\}$ (multiples of 32).
- **High-Resolution Classifier Fine-Tuning:** Darknet-19 is pre-trained on ImageNet at $224 \times 224$, then fine-tuned on ImageNet at $448 \times 448$ for 10 epochs before detection fine-tuning.
- **Optimizer:** SGD with momentum 0.9, weight decay $5 \times 10^{-4}$. Trained for 160 epochs on VOC.

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of YOLO v2's **Passthrough Reorg Layer** and Convolutional Anchor Prediction Head.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ReorgLayer(nn.Module):
    """Passthrough layer: converts (B, C, H, W) -> (B, C*stride^2, H/stride, W/stride)"""
    def __init__(self, stride=2):
        super().__init__()
        self.stride = stride

    def forward(self, x):
        B, C, H, W = x.shape
        s = self.stride
        # Reshape to split spatial H, W into blocks
        x = x.view(B, C, H // s, s, W // s, s)
        # Permute to bring stride blocks into channel dimension
        x = x.permute(0, 3, 5, 1, 2, 4).contiguous()
        # Reshape to final channel-expanded tensor
        x = x.view(B, C * s * s, H // s, W // s)
        return x

class YOLOv2Head(nn.Module):
    def __init__(self, in_channels_deep=1024, in_channels_pass=512, num_anchors=5, num_classes=20):
        super().__init__()
        self.num_anchors = num_anchors
        self.num_classes = num_classes
        
        # Passthrough reorganizer (26x26x512 -> 13x13x2048)
        self.reorg = ReorgLayer(stride=2)
        
        # Fused Conv Layer (2048 + 1024 = 3072 channels)
        self.conv_fuse = nn.Sequential(
            nn.Conv2d(3072, 1024, kernel_size=3, padding=1, bias=False),
            nn.BatchNorm2d(1024),
            nn.LeakyReLU(0.1, inplace=True)
        )
        
        # 1x1 Conv Anchor Prediction Head
        out_channels = num_anchors * (5 + num_classes) # 5 * (5 + 20) = 125
        self.conv_pred = nn.Conv2d(1024, out_channels, kernel_size=1)

    def forward(self, f_deep, f_pass):
        """
        f_deep: (B, 1024, 13, 13) - Deep stage 5 features
        f_pass: (B, 512, 26, 26)  - Passthrough stage 4 features
        """
        # Reorganize passthrough features: (B, 512, 26, 26) -> (B, 2048, 13, 13)
        f_pass_reorg = self.reorg(f_pass)
        
        # Concatenate along channels
        f_concat = torch.cat([f_pass_reorg, f_deep], dim=1) # (B, 3072, 13, 13)
        
        # Fuse and Predict
        fused = self.conv_fuse(f_concat)     # (B, 1024, 13, 13)
        out = self.conv_pred(fused)           # (B, 125, 13, 13)
        
        # Reshape output to (B, 13, 13, num_anchors, 5 + num_classes)
        B, _, H, W = out.shape
        out = out.permute(0, 2, 3, 1).contiguous()
        out = out.view(B, H, W, self.num_anchors, 5 + self.num_classes)
        return out

if __name__ == "__main__":
    B = 2
    head = YOLOv2Head(in_channels_deep=1024, in_channels_pass=512, num_anchors=5, num_classes=20)
    
    dummy_f_deep = torch.randn(B, 1024, 13, 13)
    dummy_f_pass = torch.randn(B, 512, 26, 26)
    
    output = head(dummy_f_deep, dummy_f_pass)
    
    print(f"Deep Feature Shape:        {dummy_f_deep.shape}")
    print(f"Passthrough Feature Shape: {dummy_f_pass.shape}")
    print(f"Prediction Output Shape:   {output.shape}")
    
    assert output.shape == (B, 13, 13, 5, 25), f"Expected (B, 13, 13, 5, 25), got {output.shape}"
    print("YOLO v2 Passthrough & Anchor Head verification successful!")
```

## 10. Strengths
- **Optimal Anchor Priors:** Uses k-means clustering to discover bounding box anchors tailored directly to training data distributions.
- **Stable Training:** Sigmoid-bounded center prediction ($\sigma(t_x), \sigma(t_y)$) prevents anchor box divergence.
- **Enhanced Small Object Detection:** Passthrough layer recovers fine $26 \times 26$ spatial features for small object recognition.
- **Multi-Scale Flexibility:** Dynamically resizes input resolution during training, allowing a single model to trade speed for accuracy during inference.

## 11. Weaknesses
- **Single Scale Head Output:** All predictions are made from a single $13 \times 13$ spatial grid (unlike modern multi-scale heads like FPN).
- **Struggles on Extremely Small Objects:** Downsampling to $13 \times 13$ still limits performance on tiny objects compared to Feature Pyramid Networks.

## 12. Research Evolution
YOLO v2 proved that anchor boxes combined with k-means clustering and direct location prediction vastly improved detection accuracy. To solve the remaining multi-scale feature limitation, Joseph Redmon released **YOLO v3** (2018), which introduced a Darknet-53 backbone and an FPN-like head predicting at 3 distinct scales.

## 13. Interview Questions

**Q1: How does YOLO v2 use k-means clustering to generate anchor boxes, and what distance metric does it use?**
**A1:** Instead of hand-crafted anchor ratios, YOLO v2 runs k-means clustering on the ground-truth training box dimensions $(w, h)$. Standard Euclidean distance favors larger boxes, so YOLO v2 uses an IoU-based distance metric: $d(\text{box}, \text{centroid}) = 1 - \text{IoU}(\text{box}, \text{centroid})$. Clustering identified $k=5$ optimal anchor shapes.

**Q2: Why does YOLO v2 apply a Sigmoid function to box center predictions $(t_x, t_y)$?**
**A2:** Unconstrained linear center predictions (as in Faster R-CNN) can cause an anchor to drift to any location in the image during early training, leading to instability. YOLO v2 applies a Sigmoid activation $\sigma(t_x), \sigma(t_y) \in (0, 1)$ to restrict the predicted center $(b_x, b_y)$ strictly inside the local grid cell $(c_x, c_y)$.

**Q3: Explain the operation of YOLO v2's Passthrough (Reorg) Layer.**
**A3:** The Passthrough layer extracts high-resolution $26 \times 26 \times 512$ feature maps from an earlier layer, reshapes adjacent spatial locations into channels ($26 \times 26 \times 512 \rightarrow 13 \times 13 \times 2048$), and concatenates them with the deep $13 \times 13 \times 1024$ feature map. This provides fine-grained spatial features for small object detection.

**Q4: What is Multi-Scale Training in YOLO v2?**
**A4:** Every 10 training batches, the network randomly changes its input resolution to a new size sampled from $\{320, 352, 384, \dots, 608\}$ (multiples of 32). Because YOLO v2 is fully convolutional, this forces the model to generalize across different resolutions.

**Q5: What is YOLO9000 and how does WordTree enable joint classification and detection?**
**A5:** YOLO9000 is a variant trained jointly on COCO (detection) and ImageNet (classification). It uses **WordTree**—a hierarchical tree structure based on WordNet concepts—to predict conditional probabilities at concept nodes, enabling the model to detect over 9,000 categories without explicit bounding box annotations for all classes.
