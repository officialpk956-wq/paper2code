# InstructBLIP

## 1. Overview
InstructBLIP, introduced in 2023 by Wenliang Dai, Junnan Li, Dongxu Li, Anthony Meng Huat Tiong, Junqi Zhao, Weisheng Wang, Boyang Li, Pascale Fung, and Steven Hoi (Salesforce Research & HKUST), introduced **Instruction-Aware Visual Feature Extraction for Vision-Language Models**. Standard BLIP-2 Q-Former extracted static visual features from images using 32 query tokens, regardless of the user's downstream text instruction. For example, given an image of a complex street scene and the instruction *"Count the number of red cars"*, standard BLIP-2 extracted generic visual summaries without paying specific attention to red cars. InstructBLIP solved this by feeding the user's **Text Instruction directly into the Q-Former** alongside the 32 query tokens. By enabling self-attention between query tokens and instruction text tokens, InstructBLIP extracts **Task-Aware Visual Features** tailored specifically to answer the user's specific prompt.

:::note
InstructBLIP innovation: "Instruction-Aware Q-Former: feeds user text instruction into Q-Former self-attention alongside 32 query tokens, extracting task-specific visual features for frozen LLM."
:::

## 2. Historical Context
In early 2023, Instruction Tuning (FLAN, Alpaca, Vicuna) revolutionized NLP by demonstrating that models trained on diverse task instructions generalized effortlessly to unseen zero-shot tasks.

Dai et al. recognized that visual feature extraction in vision-language models was non-instruction-aware. In BLIP-2, the Q-Former extracted visual tokens purely based on image content, ignoring what the user was asking. InstructBLIP introduced instruction conditioning into the visual feature extraction bottleneck itself.

## 3. Problem It Solves
InstructBLIP resolves three core limitations in multimodal instruction following:
1. **Instruction-Agnostic Visual Extraction:** Eliminates static visual summaries by conditioning Q-Former query tokens directly on text instructions.
2. **Zero-Shot Task Generalization:** Fine-tunes vision-language models on 26 diverse instruction datasets, achieving state-of-the-art zero-shot performance on 13 held-out tasks.
3. **Task-Specific Attention Allocation:** Enables the 32 query tokens to focus dynamically on specific objects or regions mentioned in the prompt (e.g., counting, OCR, spatial reasoning).

## 5. Layer-by-Layer Breakdown

**1. Frozen Vision Encoder:**
- Encodes input image $I$ into visual patch features $Z_v \in \mathbb{R}^{N \times d_v}$ using a frozen EVA-CLIP ViT-g/14.

**2. Instruction-Aware Q-Former:**
- Takes two input token sets into its self-attention layer: $N_q = 32$ learnable query tokens $Q$ and user instruction text tokens $T_{\text{inst}}$.
- **Instruction-Aware Self-Attention:**
  $$\text{Input}_{\text{self}} = \left[ Q \;\Vert\; T_{\text{inst}} \right]$$
  Query tokens attend to instruction text tokens, modifying query vectors based on prompt intent.
- **Cross-Attention:** Instruction-conditioned query tokens attend to frozen visual features $Z_v$ via cross-attention.

**3. Frozen LLM Decoder:**
- Concatenates output 32 visual prefix tokens $Z_{\text{prefix}}$ with user text instruction $T_{\text{inst}}$ in frozen LLM (Flan-T5 or Vicuna) for autoregressive answer generation.

## 6. Tensor Flow Walkthrough
Let's trace tensors through InstructBLIP for batch size $B=4$, 32 queries, 20 instruction text tokens, ViT patch count $N=257$, Q-Former dim $d=768$, LLM dim 4096.

1. **Instruction-Aware Concatenation:**
   - 32 Learned Queries: `(4, 32, 768)`, Instruction Tokens: `(4, 20, 768)`
   - Concat Inputs $\to$ `(4, 52, 768)`
2. **Instruction-Aware Self-Attention Pass:**
   - Self-Attention over 52 tokens $\to$ Extract 32 Instruction-Conditioned Queries: `(4, 32, 768)`
3. **Cross-Attention over Visual Features:**
   - Cross-Attention($Q=32\text{ Conditioned Queries}, K=Z_v, V=Z_v$) $\to Z_q$: `(4, 32, 768)`
4. **Linear Projection & LLM Generation:**
   - Linear Projection $Z_q W_{\text{proj}} \to Z_{\text{prefix}}$: `(4, 32, 4096)`
   - Feed $Z_{\text{prefix}} + T_{\text{inst}}$ to Frozen LLM $\to$ Generated Answer.

## 7. Mathematical Foundations

### 1. Instruction-Aware Self-Attention Mechanism
Let $Q \in \mathbb{R}^{32 \times d}$ be the 32 query tokens and $T \in \mathbb{R}^{L \times d}$ be the tokenized user instruction text.
The input matrix to Q-Former self-attention is $H = [Q \parallel T] \in \mathbb{R}^{(32 + L) \times d}$.

The attention matrix $A$ is evaluated over both query tokens and instruction text tokens:

$$A = \text{Softmax}\left( \frac{(H W_Q) (H W_K)^T}{\sqrt{d}} \right)$$

$$\hat{Q} = A_{[:32, :]} \left( H W_V \right) \in \mathbb{R}^{32 \times d}$$

Because $A_{[:32, :]}$ includes attention weights between queries and instruction tokens $T$, the updated queries $\hat{Q}$ are explicitly conditioned on the text instruction.

### 2. Task-Aware Visual Cross-Attention
The updated instruction-conditioned queries $\hat{Q}$ extract targeted visual features $Z_v \in \mathbb{R}^{N \times d_v}$ from the frozen ViT:

$$Z_{\text{task}} = \text{Softmax}\left( \frac{(\hat{Q} W_Q^{\text{cross}}) (Z_v W_K^{\text{cross}})^T}{\sqrt{d}} \right) \left( Z_v W_V^{\text{cross}} \right) \in \mathbb{R}^{32 \times d}$$

## 8. Training Procedure
- **Dataset Preparation:** Collect 26 public vision-language datasets categorized into 11 task types (Image Captioning, VQA, Reading Comprehension, Visual Reasoning).
- **Instruction Formatting:** Convert all datasets into unified instruction prompts (e.g., *"Based on the image, answer the question: {question}"*).
- **Hold-Out Split:** Train on 13 task clusters; hold out 13 task clusters for zero-shot evaluation.
- **Optimization:** Freeze ViT and LLM. Train Q-Former and linear projection layer using cross-entropy loss over response tokens.

## 9. PyTorch Implementation
Here is a complete PyTorch implementation of the **InstructBLIP Instruction-Aware Q-Former**.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class InstructBLIPQFormer(nn.Module):
    """ InstructBLIP Instruction-Aware Q-Former Module """
    def __init__(self, visual_dim=1408, query_dim=768, num_queries=32, llm_dim=4096, vocab_size=30522):
        super().__init__()
        self.num_queries = num_queries
        self.query_dim = query_dim
        
        # 32 Learnable Query Vectors
        self.query_tokens = nn.Parameter(torch.randn(1, num_queries, query_dim))
        self.text_embed = nn.Embedding(vocab_size, query_dim)
        
        # Shared Self-Attention Layer for Queries + Instruction Text
        self.self_attn = nn.MultiheadAttention(embed_dim=query_dim, num_heads=8, batch_first=True)
        
        # Cross-Attention: Queries attend to Visual Features
        self.vis_proj = nn.Linear(visual_dim, query_dim)
        self.cross_attn = nn.MultiheadAttention(embed_dim=query_dim, num_heads=8, batch_first=True)
        
        # LLM Projection
        self.llm_proj = nn.Linear(query_dim, llm_dim)

    def forward(self, visual_feats, instruction_tokens):
        """
        visual_feats:       (B, N_patches, visual_dim)
        instruction_tokens: (B, L_inst) User text instruction tokens
        """
        B = visual_feats.shape[0]
        L_inst = instruction_tokens.shape[1]
        
        # 1. Prepare Inputs: [ 32 Queries || Instruction Text Embeddings ]
        queries = self.query_tokens.repeat(B, 1, 1)            # (B, 32, 768)
        inst_embeds = self.text_embed(instruction_tokens)       # (B, L_inst, 768)
        concat_inputs = torch.cat([queries, inst_embeds], dim=1) # (B, 32 + L_inst, 768)
        
        # 2. Instruction-Aware Self-Attention
        h_self, _ = self.self_attn(concat_inputs, concat_inputs, concat_inputs) # (B, 32 + L_inst, 768)
        q_inst = h_self[:, :self.num_queries, :]                                # (B, 32, 768)
        
        # 3. Task-Aware Cross-Attention over Visual Features
        v_proj = self.vis_proj(visual_feats) # (B, N_patches, 768)
        q_cross, _ = self.cross_attn(query=q_inst, key=v_proj, value=v_proj) # (B, 32, 768)
        
        # 4. Project to LLM Embedding Dimension
        z_prefix = self.llm_proj(q_cross) # (B, 32, 4096)
        return z_prefix

if __name__ == "__main__":
    B, N_patches, L_inst, vis_dim, llm_dim = 4, 257, 20, 1408, 4096
    instruct_qformer = InstructBLIPQFormer(visual_dim=vis_dim, query_dim=768, num_queries=32, llm_dim=llm_dim)
    
    vis_feats = torch.randn(B, N_patches, vis_dim)
    inst_tokens = torch.randint(0, 30522, (B, L_inst))
    
    llm_prefix = instruct_qformer(vis_feats, inst_tokens)
    
    print(f"InstructBLIP Visual Prefix Output Shape: {llm_prefix.shape}")
    assert llm_prefix.shape == (B, 32, llm_dim)
    print("InstructBLIP verification successful!")
```

## 10. Strengths
- **Instruction-Aware Visual Feature Extraction:** Dynamically extracts visual features tailored to the user's specific prompt.
- **State-of-the-Art Zero-Shot Generalization:** Outperforms BLIP-2 and LLaVA on 13 held-out vision-language benchmarks.
- **Diverse Instruction Tuning:** Trained on 26 structured vision-language datasets across 11 task types.

## 11. Weaknesses
- **Instruction Length Bottleneck:** Very long text prompts can dilute Q-Former cross-attention capacity.

## 12. Research Evolution
InstructBLIP established instruction-aware visual extraction, directly inspiring **InstructBLIP-Video**, **LLaVA 1.5**, and **mPLUG-Owl**.

## 13. Interview Questions

**Q1: What is the main difference between BLIP-2 and InstructBLIP?**
**A1:** BLIP-2's Q-Former extracts visual features independently of the text prompt (instruction-agnostic). InstructBLIP feeds the user text instruction directly into Q-Former self-attention alongside the 32 query tokens, extracting **instruction-aware visual features** tailored to the prompt.

**Q2: How does self-attention in InstructBLIP's Q-Former enable instruction conditioning?**
**A2:** By concatenating 32 query tokens with instruction text tokens $[Q \parallel T_{\text{inst}}]$ as input to Q-Former self-attention. Queries directly attend to instruction tokens, modifying query representations based on task intent before cross-attending to image patches.

**Q3: How was InstructBLIP evaluated for zero-shot performance?**
**A3:** 26 vision-language datasets were grouped into 11 task categories. InstructBLIP was trained on 13 datasets and evaluated zero-shot on 13 held-out datasets (such as GQA, VizWiz, TextVQA).

**Q4: Does InstructBLIP update the LLM or ViT weights during instruction tuning?**
**A4:** No. Both the Vision Encoder (ViT-g) and the LLM (Flan-T5 / Vicuna) remain **completely frozen**. Only Q-Former and linear projection parameters are updated.

**Q5: Compare InstructBLIP with LLaVA.**
**A5:** InstructBLIP uses an **Instruction-Aware Q-Former** to extract 32 compact visual tokens conditioned on the prompt. LLaVA projects all $N=257$ visual patch tokens directly into the LLM prefix via a linear/MLP layer.
