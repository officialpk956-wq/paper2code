# AI Engineer Roadmap

The complete path from programming foundations to production AI systems. Each phase links directly to the architectures, papers, math topics, problems, and system design cases in the Paper2Code library.

## How to Use This Roadmap

1. Work through phases in order — prerequisites are enforced by the roadmap engine.
2. Every concept node links its **paper** (theory), **math** (foundations), **problem** (practice), and **system design** (application).
3. Don't skip the problems. Reading about attention and implementing attention are different skills; interviews test the second one.

:::tip
The fastest path through this roadmap is *implementation-first*: skim the concept, attempt the linked problem, then return to the theory with concrete questions.
:::

## Phase Overview

| Phase | Focus | Output |
| --- | --- | --- |
| Foundations | Python, NumPy, complexity | Implement core ops from scratch |
| Mathematics | Linear algebra, probability | Read any architecture paper |
| Transformers & LLMs | Attention, BERT/GPT | Implement attention; explain it cold |
| AI Systems | Inference, RAG, serving | Design LLM products end-to-end |
