CLIP (Contrastive Language-Image Pretraining) trains two separate encoders—one for text and one for images—to map their inputs into a shared embedding space using a contrastive loss.

Let's build the core components of the CLIP model.

<Milestone title="1. Dual Encoders">
CLIP uses a Vision Transformer (ViT) or ResNet for images, and a Transformer for text. Both encoders project their final representations into a shared latent space of the same dimension.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CLIP(nn.Module):
    def __init__(self, embed_dim=512):
        super().__init__()
        # In practice, these are full ViT and Text Transformer models.
        # We mock them here for clarity on the contrastive loop.
        self.visual_encoder = MockVisionTransformer(output_dim=embed_dim)
        self.text_encoder = MockTextTransformer(output_dim=embed_dim)
        
        # Learnable temperature parameter, initialized to log(1 / 0.07)
        self.logit_scale = nn.Parameter(torch.ones([]) * np.log(1 / 0.07))

    def forward(self, image, text):
        # 1. Extract features
        image_features = self.visual_encoder(image) # (B, d_model)
        text_features = self.text_encoder(text)     # (B, d_model)
        
        # 2. L2 Normalize the features
        image_features = F.normalize(image_features, p=2, dim=-1)
        text_features = F.normalize(text_features, p=2, dim=-1)
        
        # 3. Compute scaled cosine similarities
        logit_scale = self.logit_scale.exp()
        logits_per_image = logit_scale * image_features @ text_features.t()
        logits_per_text = logits_per_image.t()
        
        return logits_per_image, logits_per_text
```

<Milestone title="2. Contrastive Loss (InfoNCE)">
The loss function maximizes the similarity between the correct image-text pairs (the diagonal of the similarity matrix) while minimizing the similarity between all other pairs in the batch.

```python
def clip_loss(logits_per_image, logits_per_text):
    batch_size = logits_per_image.shape[0]
    
    # The targets are the indices on the diagonal: [0, 1, 2, ..., B-1]
    targets = torch.arange(batch_size, device=logits_per_image.device)
    
    # Loss for image -> text classification
    loss_i = F.cross_entropy(logits_per_image, targets)
    
    # Loss for text -> image classification
    loss_t = F.cross_entropy(logits_per_text, targets)
    
    # Symmetric average
    return (loss_i + loss_t) / 2
```

:::warning
Because the negative examples are entirely drawn from the other elements in the batch, CLIP requires **massive batch sizes** (e.g., 32,768) to train effectively.
:::

</Milestone>

<Milestone title="3. Full Training Loop">
Putting it all together, a single forward and backward pass for CLIP looks like this:

```python
def train_step(model, optimizer, images, texts):
    optimizer.zero_grad()
    
    # Forward pass
    logits_per_image, logits_per_text = model(images, texts)
    
    # Compute contrastive loss
    loss = clip_loss(logits_per_image, logits_per_text)
    
    # Backward pass
    loss.backward()
    optimizer.step()
    
    return loss.item()
```
