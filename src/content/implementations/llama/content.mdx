The LLaMA architecture is a standard transformer decoder, but it incorporates three key modifications inspired by PaLM, GPT-3, and Chinchilla to improve training stability and inference efficiency.

Let's implement the core LLaMA upgrades.

<Milestone title="1. RMSNorm (Root Mean Square Normalization)">
Instead of standard Layer Normalization, LLaMA uses RMSNorm. It removes the mean-centering step, which speeds up computation while maintaining training stability.

**Shapes:**
* Input: `(batch_size, seq_len, d_model)`
* Output: `(batch_size, seq_len, d_model)`

```python
import torch
import torch.nn as nn

class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.eps = eps
        # Learnable scaling parameter (gamma)
        self.weight = nn.Parameter(torch.ones(dim))

    def _norm(self, x):
        # Calculate RMS: sqrt(mean(x^2))
        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)

    def forward(self, x):
        output = self._norm(x.float()).type_as(x)
        return output * self.weight
```

:::tip
RMSNorm only scales the variance, saving the cost of computing the mean.
:::

</Milestone>

<Milestone title="2. Rotary Position Embeddings (RoPE)">
Instead of adding absolute positional embeddings to the input, LLaMA uses RoPE. RoPE injects positional information at every attention layer by rotating the Query and Key representations in the complex plane.

```python
def precompute_freqs_cis(dim: int, end: int, theta: float = 10000.0):
    # Calculate frequencies
    freqs = 1.0 / (theta ** (torch.arange(0, dim, 2)[: (dim // 2)].float() / dim))
    t = torch.arange(end, device=freqs.device)  # sequence positions
    freqs = torch.outer(t, freqs).float()  # outer product
    # Return complex representations
    return torch.polar(torch.ones_like(freqs), freqs)

def apply_rotary_emb(xq, xk, freqs_cis):
    # Reshape to complex
    xq_ = torch.view_as_complex(xq.float().reshape(*xq.shape[:-1], -1, 2))
    xk_ = torch.view_as_complex(xk.float().reshape(*xk.shape[:-1], -1, 2))
    
    # Broadcast freqs
    freqs_cis = freqs_cis.unsqueeze(0).unsqueeze(2)
    
    # Rotate by multiplying complex numbers
    xq_out = torch.view_as_real(xq_ * freqs_cis).flatten(3)
    xk_out = torch.view_as_real(xk_ * freqs_cis).flatten(3)
    return xq_out.type_as(xq), xk_out.type_as(xk)
```
</Milestone>

<Milestone title="3. SwiGLU Feed Forward Network">
LLaMA replaces the standard ReLU-based FFN with a SwiGLU activation. This requires three weight matrices instead of two.

```python
import torch.nn.functional as F

class SwiGLU_FFN(nn.Module):
    def __init__(self, dim, hidden_dim):
        super().__init__()
        # Standard transformer FFN has 2 matrices (up, down). 
        # SwiGLU needs a 3rd for the gate.
        self.w1 = nn.Linear(dim, hidden_dim, bias=False)
        self.w2 = nn.Linear(hidden_dim, dim, bias=False)
        self.w3 = nn.Linear(dim, hidden_dim, bias=False)

    def forward(self, x):
        # Swish(x * W1) * (x * W3)
        return self.w2(F.silu(self.w1(x)) * self.w3(x))
```

:::note
Because SwiGLU uses three matrices, the `hidden_dim` is typically scaled down (e.g., $2/3 \times 4d$) to keep the parameter count equivalent to a standard FFN.
:::

</Milestone>
