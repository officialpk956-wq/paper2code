# Implement Scaled Dot-Product Attention

The single most important function in modern AI. Implement it correctly — including causal masking — and you understand how every LLM processes context.

## Problem Statement

Implement:

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + M\right)V
$$

where `M` is an optional mask containing `0` (attend) or `-inf` (don't attend).

## Requirements

1. Scale scores by $\sqrt{d_k}$ — explain why in a comment.
2. Numerically stable softmax (max subtraction).
3. Support a causal mask so position $i$ cannot attend to positions $j > i$.
4. Return both the output and the attention weight matrix.

## Test Case

Q = np.array([[1.0, 0.0], [0.0, 1.0]])
